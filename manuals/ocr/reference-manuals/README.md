# FLEX Manual OCR Sources

This folder contains searchable text for the unique FLEX manuals under `manuals/flex`.

- `flex-users-manual-general-pages.md`: non-command pages from the image-only 1979 User’s Manual scan. Command pages are split into individual files under `../commands/`.
- `flex-programmers-manual.md`: FLEX Programmer’s Manual.
- `flex-advanced-programmers-guide.md`: FLEX Advanced Programmer’s Guide.
- `6809-flex-adaptation-guide.md`: 6809 FLEX Adaptation Guide.
- `flex-user-group-faq.md`: FLEX User Group FAQ.

Alternate PDF scans with substantially duplicate content were not transcribed into duplicate Markdown files. The preferred source was selected by text quality and completeness.
