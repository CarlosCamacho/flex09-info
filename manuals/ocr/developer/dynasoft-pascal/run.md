OPT PAG
 NAM RUN.CMD FOR DYNASOFT PASCAL 1.3
 PAG
*	COMMAND FILE TO RUN DYNASOFT PASCAL PROGRAMS
*	VERSION 1.3	APRIL 26, 1981
*	AUTHOR ALLAN G. JOST
*
*
*	MODIFIED JUNE 81 TO CLEAR DP REGISTER ON ENTRY
*	AND JULY 5 81 TO IMBED REDIRECTION FCB'S

*	(C) 1981, DYNASOFT SYSTEMS LIMITED
*
*
*	SYNTAX: RUN FILESPEC(.PCD) OPTIONS	[;FILESPEC OPTIONS]
*	OPTIONS CAN BE ANY OR ALL OF:
*
<INPUT-FILESPEC
*
>OUTPUT-FILESPEC
*
>P	(DIRECTS OUTPUT TO PRINTER)
*
SHHHH (SETS STACK LOCATION TO $HHHH)
*
*	LOADS INTERPRETER AT $0100 AND P-CODE JUST AFTER
*
*	FOLLOWING I/O CHANNELS ARE PREDEFINED IN I/O TABLE:
*
0: KEYBOARD
*
1: DISPLAY OR TERMINAL OUTPUT
*
2: SAME AS 1 (INTENDED FOR ERROR REPORTING)
*
3: PARALLEL PRINTER AT $E012
*
*	THE < OPERATOR REDIRECTS CHANNEL 0, AND > REDIRECTS CH 1
*
*
*	EXTERNAL EQUATES
WARMS EQU $CD03
GETCHR EQU $CD15
PUTCHR EQU $CD18
NXTCH EQU $CD27
PSTRNG EQU $CD1E
PCRLF EQU $CD24
GETFIL EQU $CD2D
SETEXT EQU $CD33
GETHEX EQU $CD42
OUTHEX EQU $CD3C
OUTADR EQU $CD45
FMSCLO EQU $D403
FMS EQU $D406
FCB EQU $C840
MEMEND EQU $CC2B
EOLN EQU $CC02
RPTERR EQU $CD3F
LSTERM EQU $CC11
PPPORT EQU $E012 PARALLEL PRINTER PORT
INTERP EQU $0100
WS EQU $0020
EOI EQU $0022
TMP EQU $0030
STOP EQU $002F STOP FLAG
FMSP EQU $0036 POINTER TO FLEX FMS
*
 ORG $C100 MAIN ENTRY
RUN BRA RUN1
 FCB $60 VERSION NUMBER
PGMORG RMB 2 P-CODE LOCATION
PCRASH RMB 2 FOR LOCATION OF CRASH
XSAVE RMB 2
STDIN FDB GETCHR FCB FOR KEYBOARD
 FCB 3 INPUT DEVICE
STDOUT FDB PUTC FCB FOR DISPLAY
 FCB 4 OUTPUT DEVICE
PRFCB FDB PROUT FCB FOR PRINTER
 FCB 4
SAVNAM RMB 12 SPACE TO SAVE FILE SPEC
*	SUBROUTINE TO SET UP DEFAULT I/O
RUN1 LBRA RUN2
STDIO LDX #STDIN DEFAULT FCB'S
 STX CHAN0
 LDX #STDOUT
 STX CHAN0+2
 STX CHAN0+4
 LDX #PRFCB
 STX CHAN0+6 CHANNEL 3
 LDX #FMS SET UP FMS VECTOR
 STX FMSP
 LBSR PINIT INITIALIZE PRINTER
 RTS
*
*
*	SUBROUTINE TO LOAD A RELOCATABLE FILE
*	ENTER WITH Y->FILE SPEC, U->LOAD POINT
*	RETURN WITH U->FIRST BYTE AFTER LOAD
*
LOADBIN PSHS U SAVE U
 LDX #FCB
 LEAU 3,X LOCATION OF FILE SPEC IN FCB
 BSR MOVNAM MOVE SPEC IN
 PULS U RESTORE U
*	ENTER HERE IF FILESPEC ALREADY IN FCB
LOADIT LDD #$01FF OPEN READ, BINARY FILE
 BSR OPEN OPEN THE FILE
 STU WS
 JSR FMS GET BYTE COUNT
 BNE ERROR
 TFR A,B
 JSR FMS
 BNE ERROR
 EXG A,B
 ADDD WS COMPUTE LAST BYTE+1
 STD EOI
RLOOP JSR FMS GET A BYTE
 BNE ERROR
 STA ,U+
 CMPU EOI LAST BYTE?
 BLO RLOOP NOT YET
*	ENTER HERE TO CLOSE A FILE
CLOSE LDD #$0400
*	ENTER HERE TO OPEN A FILE (MUST SET UP A,B)
OPEN STA ,X
 PSHS B,U SAVE NAME IN CASE OF ERR
 LEAY 3,X
 LDU #SAVNAM
 BSR MOVNAM
 PULS B,U
 JSR FMS
 BNE ERROR
 STB 59,X SET COMPRESSION FLAG
 RTS
*	SUBROUTINE TO MOVE A FILE SPEC
MOVNAM LDB #12 NUMBER OF BYTES
MOV1 LDA ,Y+
 STA ,U+
 DECB
 BNE MOV1
 RTS
*
ERROR JSR RPTERR REPORT ERROR
 LBSR PFIL PRINT OFFENDING FILENAME
NOSAVE JSR FMSCLO CLOSE ALL FILES
ALLDON JMP WARMS RETURN TO FLEX
*
RUN2 CLRA
 TFR A,DP CLEAR DP REG JUST IN CASE
 LDY #INTNAM INTERPRETER FILE NAME
 LDU #INTERP LOAD LOCATION
 BSR LOADBIN LOAD INTERPRETER
 STU PGMORG SAVE LOCATION FOR P-CODE
LDPGM LBSR STDIO SET UP I/O TABLE
 LDX #FCB SYSTEM FCB
 JSR GETFIL GET PROGRAM NAME
 BCS ERROR
 LDD #$5043 FORCE '.PCD'
 STD 12,X
 LDA #'D
 STA 14,X
 LDU PGMORG
 BSR LOADIT LOAD P-CODE
*	NOW CHECK FOR OPERANDS
NXTOPR LDA LSTERM CHECK LAST TERMINATOR
 CMPA #$20 BLANK?
 BNE *+5 NO, CHECK IT OUT
 JSR NXTCH YES, GET ANOTHER FIRST
 CMPA #'< INPUT RE-DIRECTION?
 BEQ DIRIN YES
 CMPA #'> OUTPUT?
 BEQ DIROUT
 CMPA #'S SET STACK?
 BNE GO NO, GO RUN PROGRAM
 JSR GETHEX GET NEW STACK LOCATION
 TFR X,U
 BRA NXTOPR
*	RE-DIRECT INPUT
DIRIN LDX #SYSIN
 LBSR GETTXT GET FILESPEC
 LDD #$0100 OPEN TEXTFILE
 BSR OPEN
 STX CHAN0 VECTOR CH 0
 BRA NXTOPR
*	RE-DIRECT OUTPUT
DIROUT LDX #SYSOUT
 LBSR GETTXT
 LDD 4,X CHECK FOR 'P'
 CMPD #$5000
 BNE FILOUT OUTPUT TO FILE
*	RE-DIRECT OUTPUT TO PRINTER
 LDX #PRFCB
VECOUT STX CHAN0+2
 BRA NXTOPR
FILOUT PSHS U PREPARE TO MAKE OUTPUT FILE
 LEAY 3,X
 LDU #SAVNAM
 LBSR MOVNAM SAVE FILENAME
 LDA #$0C DELETE CODE
 STA ,X
 JSR FMS DELETE OLD FILE
 BEQ DELOK
 LDA 1,X CHECK ERROR
 CMPA #4 THIS ONE OK
 LBNE ERROR
DELOK LDY #SAVNAM RESTORE FILENAME
 LEAU 3,X
 LBSR MOVNAM
 PULS U RESTORE U
 LDD #$0200 OPEN TEXTFILE O/P
 LBSR OPEN
 BRA VECOUT
*	RUN P-CODE PROGRAM (U ALREADY SET UP)
GO JSR PCRLF NEW LINE
 LDY PGMORG IPC
 LDD MEMEND HEAP
 LDX #CHAN0 I/O TABLE
 JSR INTERP RUN PROGRAM
 BMI POK IF NO ERRORS
*	P-CODE PROGRAM BOMBED
 STX XSAVE SAVE X FOR LATER
 TFR Y,D
 SUBD PGMORG COMPUTE OFFSET FOR REPORTING
 STD PCRASH
 JSR PCRLF NEW LINE
 LDX #ERMSG
 JSR PSTRNG
 LDX #STOP
 JSR OUTHEX REPORT STOP CODE
 LDX #ATMSG
 JSR PSTRNG
 LDX #PCRASH
 JSR OUTADR REPORT RELATIVE LOCATION
 JSR PCRLF
 LDA STOP
 CMPA #9 DISK ERROR?
 BNE NODISK
 LDX XSAVE	RESTORE FCB POINTER
 LBRA ERROR REPORT DISK ERROR
NODISK LBRA NOSAVE CLOSE FILES AND EXIT
POK JSR FMSCLO NO ERRORS, CLOSE FILES
 LDA LSTERM CHECK LAST TERMINATOR
 CMPA #'; IF SEMICOLON
 LBEQ LDPGM DO ANOTHER PROGRAM
 LBRA ALLDON ELSE RETURN TO FLEX
*
*	SUBROUTINE TO GET FILENAME, .TXT DEFAULT
GETTXT JSR GETFIL
 LBCS ERROR
 LDA #1 TXT DEFAULT
 JMP SETEXT
*
*	PRINTER DRIVERS
PINIT LDX #PPPORT INITIALIZE
 CLR 1,X
 LDA #$FF SET FOR O/P
 STA ,X DDR
 LDA #$3E SET UP STROBE
 STA 1,X
 CLRA NULL
 BRA POUT1 OUTPUT NULL TO SET UP
*	PRINTER OUTPUT
POUT TST PPPORT+1 PRINTER READY?
 BPL POUT NOT YET
POUT1 TST PPPORT CLEAR OUT INTERRUPT
 STA PPPORT GIVE DATA TO PORT
 LDA #$36 STROBE HI, NO IRQ, LO ACK
 STA PPPORT+1 TO CONTROL REG
 LDA #$3E SET UP STROBE
 STA PPPORT+1
 RTS
*
*	INTERFACE TO FLEX PUTCHR, USES PCRLF
PUTC CMPA #$0D CR?
 BNE *+5 NO, USE PUTCHR
 JMP PCRLF YES, PRINT CR,LF
 JMP PUTCHR
*
*	INTERFACE TO PRINTER DRIVER
*	SUPPLIES LF AFTER CR
PROUT CMPA #$0D CR?
 BNE POUT NO, GO PRINT
 BSR POUT YES, PRINT CR
 LDA #$0A THEN LF
 BRA POUT
*
*	ROUTINE TO PRINT FILENAME FROM SAVNAM
PFIL LDA #$20
 JSR PUTCHR
 LDB #8
 LDU #SAVNAM+1 OFFSET TO NAME
 BSR PRNT
 LDA #'.
 JSR PUTCHR
 LDB #3
 LDU #SAVNAM+9 OFFSET TO EXT
PRNT LDA ,U+ GET CHAR
 BEQ PRDON STOP ON NULL
 JSR PUTCHR PRINT CHAT
 DECB DECREMENT CHAR CNT
 BNE PRNT MORE CHARS
PRDON RTS
*
INTNAM FCC $FF,'INTERP',0,0,'SYS'
ERMSG FCC $D,$A,'ERROR ',4
ATMSG FCC ' AT ',4
*
*	INPUT AND OUTPUT FCB'S FOR REDIRECTION
SYSIN RMB 320
SYSOUT RMB 320
*
*	I/O TABLE
CHAN0 RMB 32 ROOM FOR 16 CHANNELS
*
*
 END RUN
