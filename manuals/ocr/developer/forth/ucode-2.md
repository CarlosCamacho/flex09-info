* TAKES WORD IN INPUT STREAM SETUP BY ADVANCE
* AND SEARCHES FOR IT IN CONTEXT, CURRENT, AND FORTH VOCABULARIES
* RETURNS NE IF FOUND, EQ IF NOT FOUND
