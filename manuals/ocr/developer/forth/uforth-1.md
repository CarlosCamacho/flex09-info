* FAST FIND AND COMPILE
* ( --- CFA TF )
* ( --- FF )

GTFIND FDB *+2
 LDA #$3F
 STA HDRMSK
 CLRD
 STD XSTATU
 LDD XIN
 STD WIN
 LBSR NXTADR
 STX CMPBEG
 PSHS Y
 LDY XDP
GTFND2 LDA #$20
 LBSR ADVANC GET WORD, IS IT NULL?
 BNE GTFND3 NO, GO PROCESS
 PULS D,Y
 NEXT

GTFND3 LBSR XXFIND
 BEQ GTFND4 FOUND?
 CMPB XSTATE+1 NO, COMPILING?
 BHI GTFND9 NO, GO EXECUTE
 STX ,Y++ YES, COMPILE
 LDX WRDEND
 BRA GTFND2 GET NEXT WORD

GTFND4 LDX WRDBEG
 LEAX -1,X
 LBSR XNUMB
 BCS GTFND8 NOT FOUND AND NOT A NUMBER, GO REPORT TO INTERP
 TST XSTATE+1 WORD IS A NUMBER. COMPILE IT?
 BEQ GTFND6 NO, GO LEAVE IT ON THE STACK
 LEAX LIT,PCR YES.
 STX ,Y++
 LDD 2,U
 STD ,Y++
 TST XDPL DOUBLE NUMBER?
 BMI GTFND5
 STX ,Y++ YES, COMPILE HIGH 16 BITS
 LDD 0,U
 STD ,Y++
GTFND5 LEAU 4,U CLEAN UP STACK
 LDX WRDEND
 BRA GTFND2 GET NEXT WORD

GTFND6 TST XDPL INTERPRET NUMBER
 BPL GTFND7 DOUBLE?
 LEAU 2,U NO, DROP 2 BYTES
GTFND7 LDX WRDEND YES, LEAVE ALL FOUR BYTES
 BRA GTFND2 GET NEXT WORD

GTFND8 BSR FIXWIN PREPARE TO REPORT SOME KIND OF ERROR
 LDA #$1F
 STA HDRMSK
 LBSR XXFIND NOT FOUND BECAUSE SMUDGED?
 BNE SMERR YES, GO REPORT
 LEAY ERSTR0,PCR NOT FOUND, REPORT
 LBRA XERR

GTFND9 PSHU X FOUND, PUSH CFA FOR INTERP
GTFNDA STY XDP RESTORE DP AND IP
 PULS Y
 BSR FIXWIN
 NEXT

FIXWIN LDD WRDBEG SET WIN AND WBLK IN CASE OF ERRORS
 SUBD CMPBEG
 ADDD XIN
 STD WIN
 LDD WRDEND ADVANCE IN
 SUBD CMPBEG
 TST [WRDEND] BUT NOT PAST A NULL
 BEQ GTFNDB
 ADDD #1
GTFNDB ADDD XIN
 STD XIN
 LDD XBLK
 STD WBLK
 RTS

SMERR LEAY ERSTR7,PCR REPORT SMUDGED WORD
 LBRA XERR
