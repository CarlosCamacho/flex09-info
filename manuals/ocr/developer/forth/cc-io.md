* PEMIT: EMIT CHARACTER IN ACC A TO TERMINAL

PEMIT CLR $6F
 PSHS DP,B
 CLRB
 TFR B,DP
 JSR [CHROUT]
 PULS DP,B,PC

* PKEY: GET ONE CHARACTER FROM KEYBOARD INTO ACC A

PKEY PSHS DP,B
 CLRB
 TFR B,DP
PKEY1 JSR KEYIN
 BEQ PKEY1
 CMPA #10
 BNE OUT
PKEY2 JSR KEYIN
 BEQ PKEY2
 CMPA #65
 BLO OUT
 SUBA #64
OUT PULS DP,PC,B

* PRINIT: INITIALIZE PRINTER

PRINIT RTS

* POUTCH: OUTPUT CHARACTER TO PRINTER

POUTCH RTS

* PQTERM: TEST IF KEY PRESSED.	RETURNS CARRY SET IF TRUE.

PQTERM PSHS DP
 CLRA
 TFR A,DP
 CLRB
 JSR [POLCAT]
 BEQ QTERM2
 TFR A,B
 ANDB #$7F
QTERM2 CLRA
 PULS DP,PC
