# MNLKP

> Method: FLEX disk extraction

The text below preserves the wording and formatter directives found in the historical source. OCR and media-decoding errors may remain.

TTL MNLKP
 PAG
*
* THIS IS THE MNEMONIC LOOK UP ROUTINE
*
* ON ENTRY DESCRA = ADDR OF MNEMONIC
*
DESCRC = LENGTH OF MNEMONIC
*
* ON EXIT	IF REG A = 00 FOUND MNEMONIC
*	= FF NOT FOUND
*
*	IF FOUND REG B = MACHINE CODE FOR OPCODES
*	( FF FOR PSEUDOS)
*
REG X = ADDR OF PROCESS ROUTINE
*	MNEMONIC TYPE
*
* THE ALGORITHM USED IS A BINARY SEARCH, ERGO
* THE TABLE MUST BE PRESORTED
*
MNLKP LDAA DESCRC
 STAA PCOUNT SAVE LENGTH
 LDAA #CHRTAB-MNTAB/6+1 (# OF ENTRIES+1)
 STAA MP
 CLRA
 STAA LP
MNLKPA LDAA LP
 INCA
 CMPA MP
 BNE MNLKPB
 LDAA #$FF SET ERROR FLAG
 RTS
*
MNLKPB LDAB LP
 ADDB MP
 RORB
 STAB IP
*
* GET 16 BIT ADDRESS OF ENTRY
*
 CLRA
 LDX #ENSIZ GET ENTRY LENGTH
 DECB
 JSR MPY16
 STAA PSTNG1
 STAB PSTNG1+1
 LDX #MNTAB
 STX PSTNG2
 LDX #PSTNG1
 JSR ADD16
 LDX PSTNG1
 STX TBADD
*
* COMPARE MNEMONIC WITH ENTRY IN MNTAB
*
 LDX DESCRA GET MNEMONIC ADDRESS
 STX PSTNG2 INIT PARAM FOR COMPARE
 LDX #PSTNG1 POINT TO PARAMETERS
 JSR COMPAR DO COMPARE
 BCS MNLI ENTRY < MNEMONIC
 BNE MNMI ENTRY > MNEMONIC
*
* ENTRY FOUND
*
 CLRA SET FOUND INDICATOR
 LDX TBADD
 LDAB 5,X GET MACHINE CODE
 LDX 3,X GET ROUTINE ADDR
 RTS
*
* ENTRY < MNEMONIC
*
MNLI LDAA IP
 STAA LP
 BRA MNLKPA TRY AGAIN
*
* ENTRY > MNEMONIC
*
MNMI LDAA IP
 STAA MP
 BRA MNLKPA TRY AGAIN
