TTL SYMBOL TABLE SORT ROUTINE
 OPT PAG
 PAG
*
* THIS ROUTINE WILL SORT THE SYMBOL TABLE
* IN ASCENDING ORDER WHILE PRESERVING THE
* CONCORDANCE LINKAGES.
*
STEND EQU $008B
FILSTR EQU $3000
*
 ORG $7000
*
START BRA BEGIN
VERS FCB 1
*
FIRST FDB $0000
SECOND FDB $0000
FROM FDB $0000
TO FDB $0000
SWPRTN FDB $0000
HOLD RMB 16
HLDPTR FDB $0000
SWPFLG FCB $00
*
BEGIN LDX #FILSTR POINT TO BEGIN OF S.T.
 STX SECOND INIT SECOND
 CLR SWPFLG INIT FLAG
BIGLUP TST SWPFLG DID WE JUST DO A SWAP?
 BEQ BL1 NO - SO CONTINUE
 LDX SWPRTN RESTORE POINTER
 STX SECOND
 CLR SWPFLG CLEAR FLAG
*
BL1 LDX SECOND GET POINTER
 STX FIRST INIT POINTER
 LDAA #$10 ADVANCE OTHER POINTER
 CLRB
 ADDA FIRST+1
 ADCB FIRST
 STAA SECOND+1
 STAB SECOND SAVE OTHER POINTER
 LDX FIRST GET FIRST POINTER
 STX FROM SAVE IN WORK AREA
 LDX SECOND GET SECOND POINTER
 STX TO SAVE IN WORK AREA
 CPX STEND CHECK FOR END
 BEQ SORTEX
*
LTLLUP LDX FROM DO THE INTERNAL COMPARE
 LDAA 0,X
 INX
 STX FROM
 LDX TO
 LDAB 0,X
 INX
 STX TO
 CBA
 BEQ LTLLUP KEEP GOING
 BLS BIGLUP FIRST < SECOND (OK)
 JSR SWAP ELSE DO SWAP
 LDX FIRST
 CPX #FILSTR IS THIS THE FIRST ENTRY?
 BEQ BIGLUP YES - DON'T SET FLAGS
 TST SWPFLG
 BNE LL1
 STX SWPRTN SET RETURN POINTER
 LDAA #$FF
 STAA SWPFLG SET FLAG
LL1 LDAA FIRST+1
 LDAB FIRST
 SUBA #$10 DECREMENT POINTER BY 16
 SBCB #$00
 STAA SECOND+1 PUT IN SECOND SO IT GETS
 STAB SECOND .BACKED UP
 BRA BL1
SORTEX JMP $AD03
*
SWAP LDX FIRST
 STX FROM PUT IN WORK AREA
 LDX SECOND
 STX TO PUT IN WORK AREA
 LDX #HOLD
 STX HLDPTR INIT HOLD POINTER
SWPLP1 LDX FROM MOVE (FROM) TO (HOLD)
 LDAA 0,X
 INX
 STX FROM
 LDX HLDPTR
 STAA 0,X
 INX
 STX HLDPTR
 CPX #HOLD+12
 BNE SWPLP1
*
 LDAB #12 INIT COUNTER
 LDX FIRST
 STX FROM INIT FROM AGAIN
SWPLP2 LDX TO MOVE (TO) TO (FROM)
 LDAA 0,X
 INX
 STX TO
 LDX FROM
 STAA 0,X
 INX
 STX FROM
 DECB
 BNE SWPLP2
*
 LDX SECOND
 STX TO RE-INIT TO
 LDX #HOLD
 STX HLDPTR RE-INIT HLDPTR
SWPLP3 LDAA 0,X MOVE (HOLD) TO (TO)
 INX
 STX HLDPTR
 LDX TO
 STAA 0,X
 INX
 STX TO
 LDX HLDPTR
 CPX #HOLD+12
 BNE SWPLP3
*
 RTS FINISHED WITH SWAP
*
 END START
