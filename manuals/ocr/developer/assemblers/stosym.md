TTL STOSYM
 PAG
*
* STORE A CHARACTER IN THE SYMBOL TABLE :
* ON ENTRY DESCRA CONTAINS THE ADDRESS OF
* THE SYMBOL, AND DESCRC CONTAINS THE LENGTH.
* A STANDARD HASH CODE ALGORITHM IS USED.
*
STOSYM JSR HASH GET HASH KEY
 STX SYMPTR SAVE KEY
*
* SEE IF LOC(HASH KEY) IS EMPTY
*
SYMA LDAA 0,X GET FIRST CHARACTER
 CMPA #$20 IS SPACE?
 BNE SYMB NO - REHASH
*
* EMPTY - SO STORE SYMBOL IN TABLE
*
 STX HSAV2 SAVE TABLE POINTER
 LDX #HSMBL POINT TO HSMBL
 STX HSAV1 SAVE IT
 LDAB #6 SET COUNT
*
* DO THE TRANSFER
*
SYM1 LDX HSAV1 POINT TO HSYMBL
 LDAA 0,X GET CHARACTER
 INX
 STX HSAV1 POINT TO NEXT CHAR
 LDX HSAV2 POINT TO TABLE SPACE
 STAA 0,X STORE CHARACTER
 INX
 STX HSAV2 POINT TO NEXT POS
 DECB COUNT := COUNT - 1
 BNE SYM1 NOT DONE YET.
*
* STORE STORE LC, AND SET INFO BYTE
*
 LDAA LC GET LC
 STAA 0,X
 LDAA LC+1 GET THE REST
 STAA 1,X STORE IT
 LDAA #$40 INFO BYTE:=RELOC DEFINED
 STAA 2,X
 RTS
*
* COMPARE HSMBL WITH ENTRY IN TABLE IF COLLISION
* OCCURS.
*
SYMB JSR SYMCMP COMPARE
 BNE SYMC NO MATCH
*
* ERROR - DUPLICATE SYMBOL (ALREADY ENTERED
* IN THE TABLE).
*
 LDX SYMPTR GET ADDRESS OF ENTRY
 LDAA #$80
 ORAA 8,X SET REDEFINED BIT
 STAA 8,X
 LDX #$0206 LOAD ERROR NUMBER
SYMB1 JSR PRINTE PRINT ERROR
 RTS
*
* FIND ANOTHER SLOT IN SYMBOL TABLE FOR
* THIS SYMBOL (REHASH).
*
SYMC JSR SYMMOD GET NEXT SLOT ADDR
 CPX HKEYA CHECKED ALREADY?
 BEQ *+4 YES - TABLE IS FULL
 BRA SYMA TRY AGAIN
 LDX #$0221 LOAD ERROR NUMBER
 BRA SYMB1
*
* LOOK UP SYMBOL IN SYMBOL TABLE :
*
* ON ENTRY DESCRA = ADDRESS OF SYMBOL
*
DESCRC = SYMBOL LENGTH
*
* ON EXIT	B = VALUE OF INFO BYTE
*
X = VALUE OF SYMBOL
*
* (IF B = FF, SYMBOL NOT FOUND)
*
LKPSYM JSR HASH GET KEY
 STX SYMPTR SAVE IT
LKPSM1 LDAA 0,X GET CHARACTER
 CMPA #$20 IS IT SPACE?
 BNE LKPSM3 NO - CONTINUE
*
* ENTRY NOT IN TABLE
*
LKPSM2 LDAB #$FF LOAD RC
 RTS
*
* COMPARE SYMBOL WITH ENTRY IN TABLE
*
LKPSM3 JSR SYMCMP COMPARE STRINGS
 BNE LKPSM4 NO MATCH - TRY AGAIN
*
* FOUND ENTRY - EXTRACT INFO AND VALUE
*
 LDX SYMPTR POINT TO ENTRY
 LDAB 8,X GET INFO BYTE
 LDX 6,X GET VALUE
 RTS
*
* TRY AGAIN FOR SYMBOL IN SYMBOL TABLE
*
LKPSM4 JSR SYMMOD GET NEXT KEY
 CPX HKEYA ALREADY CHECKED?
 BNE LKPSM1 NO - OK TO TRY AGAIN
 LDAB #$FF SET RC
 RTS
*
* ROUTINE TO COMPARE SYMBOL TO ENTRY
*
SYMCMP STX PSTNG1 SAVE POINTER TO ENTRY
 LDAA #6 SET COUNT
 STAA PCOUNT PCOUNT := LENGTH(SYMBOL)
 LDX #HSMBL
 STX PSTNG2 POINT TO HSMBL
 LDX #PSTNG1 POINT TO PARAM LIST
 JSR COMPAR DO THE COMPARE
 RTS
*
* FIND NEXT SLOT IN SYMBOL TABLE IF COLLISION
* ON ENTRY OR MIS-MSTCH ON SEARCH.
*
SYMMOD LDX SYMPTR GET ADDR(CURRENT SLOT)
 INX
 INX
 INX
 INX
 INX
 INX
 INX
 INX
 INX
*
* CHECK FOR OVERFLOW
*
 CPX SYMEND
 BNE *+5 NO
 LDX SYMTAB POINT TO FIRST ENTRY
 STX SYMPTR SAVE POINTER
 RTS
*
* DELETE LAST SYMBOL ENTERED
*
DELSYM LDX SYMPTR
 LDAA #$20 SET SPACE
 LDAB #9 SET COUNT
DEL1 STAA 0,X
 INX
 DECB
 BNE DEL1 LOOP TILL DONE
 RTS
*
* HASH SYMBOL TO PRODUCE A KEY
*
HASH LDX #$2020 BLANK HSMBL
 STX HSMBL
 STX HSMBL+2
 STX HSMBL+4
*
* MOVE SYMBOL TO HSMBL
*
 LDX #HSMBL POINT TO HSMBL
 STX HSAV2 SAVE IT
 LDX DESCRA POINT TO SYMBOL
 STX HSAV1 SAVE IT ALSO
 LDAB DESCRC GET BYTE COUNT
HASH1 LDX HSAV1 POINT TO SYMBOL
 LDAA 0,X
 INX
 STX HSAV1
 LDX HSAV2 POINT TO HSMBL
 STAA 0,X
 INX
 STX HSAV2
 DECB
 BNE HASH1 LOOP TILL DONE
*
* FOLD HSMBL TO CREATE A KEY
*
 LDX HSMBL
 STX HKEYA
 LDX HSMBL+2
 STX HKEYB
 LDX #HKEYA
 JSR ADD16
 LDX HSMBL+4
 STX HKEYB
 LDX #HKEYA
 JSR ADD16
 LDAA HKEYA
 LDAB HKEYA+1
 LDX NSYM
 STX HKEYB
 LDX #HKEYB
 JSR DIV16
 STX HKEYA
 CLRA
 LDAB #9
 LDX #HKEYA
 JSR MPY16
 STAA HKEYA
 STAB HKEYA+1
*
* ADD IN BASE OF SYMTAB
*
 LDX SYMTAB
 STX HKEYB
 LDX #HKEYA
 JSR ADD16
 LDX HKEYA
 RTS
