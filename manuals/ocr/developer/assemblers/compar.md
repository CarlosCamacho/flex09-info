TTL COMPAR
 PAG
*
* COMPARE TWO STRINGS :
*
* ON ENTRY (X) = ADDR OF PARAMETER LIST
*	2 BYTES - ADDR OF STRING 1
*	2 BYTES - ADDR OF STRING 2
*	1 BYTE	- NUMBER OF BYTES TO BE COMPARED
*
* ON EXIT IF CC Z BIT IS SET THERE IS A MATCH
*	EXAMPLE :
*
LDX #STRING1
*
JSR COMPAR
*
BEQ MATCH
*
*	STRING1 RMB 2
*	STRING2 RMB 2
*	COUNT	RMB 1
*
COMPAR PSHA
 PSHB
 LDAB 4,X GET COUNT
 STX XSAV SAVE PARAM POINTER
CMP1 LDX XSAV GET PARAM POINTER
 LDX 0,X GET STRING1 ADDR
 LDAA 0,X GET CHARACTER
 LDX XSAV GET PARAM POINTER
 INC 1,X PTR SET TO NEXT CHAR
 BNE CMP2
 INC 0,X
CMP2 LDX XSAV GET PARAM POINTER
 LDX 2,X GET ADDR OF STRING2
 CMPA 0,X COMPARE BYTES
 BNE CDONE NOT EQUAL
 LDX XSAV GET PARAM POINTER
 INC 3,X
 BNE CMP3
 INC 2,X
CMP3 DECB DECREMENT COUNTER
 BNE CMP1 TRY AGAIN
CDONE PULB
 PULA
 RTS

 PAG
*
* NEXT TOKEN ROUTINE :
*
* SCANS A LINE OF SOURCE CODE AND RETURNS
* THE NEXT TOKEN, CLASS AND RC IN REGS A,B.
* THE ADDRESS OF THE TOKEN IS RETURNED IN
* DESCRA AND THE NUMBER OF BYTES IS RETURNED
* IN DESCRC.
*
* THE RC AND CLASSESS ARE:
*
*	TYPE	RC(B)	CLASS(A)
*
* NAME	01	02	SUBSTRINGS
* HEX	03	02
* DECIMAL	09	02
*
* #
23	04	DELIMITERS
* ,
2C	04
* '
27	04
*
* *
2A	24	ARITHMETIC
* /
2F	24
* +
2B	24
* -
2D	24
*
* A
41	01	A,B,X REGS
* B
42	01
* X
58	01
*
* CARRET	0D	0D	EOL
*
* ERROR	00	00	ERRORS
*
NXTOK CLR DESCRC
 INC DESCRC DESCRC := 1
NXT0 LDX CUCHAR POINT TO CURRENT CHAR
 STX DESCRA INIT DESCRA
 LDAA 0,X GET CHARACTER
 INX
 STX CUCHAR POINT TO NEXT CHAR
 CMPA #$20 LESS THAN SPACE?
 BEQ NXT0 IF SPACE - SKIP OVER
 BHI NXT1 CHAR > SPACE
*
 CMPA #$0D IS IT CR?
 BNE NXTER NO - UNRECOGNIZABLE
 TAB YES - SET RC
 RTS ALL DONE.
*
NXT1 CMPA #$5F CHAR > $5F?
 BLS NXT3 NO - OK
 BRA NXTER YES - UNRECOGNIZABLE
NXT3 JSR GCHRTB GET BYTE FROM CHARTAB
 BITA #$01 A,B,X REG?
 BEQ NXT4 NO
 LDX CUCHAR YES - CHECK NEXT CHAR
 LDAB 0,X
 CMPB #$20 SPACE?
 BEQ NXT3A YES
 CMPB #$0D CARRET?
 BNE NXT4A NO - DO NSCAN
NXT3A LDX DESCRA GET RC
 LDAB 0,X
 RTS
NXT4 BITA #$80 NAME?
 BEQ NXT5 NO
NXT4A JSR NSCAN SCAN NAME STRING
 RTS
NXT5 BITA #$40 DECIMAL?
 BEQ NXT6 NO
 JSR DSCAN SCAN DECIMAL STRING
 RTS
NXT6 BITA #$20 ARITHMETIC?
 BNE NXT3A YES - GET RC AND RETURN
 BITA #$04 DELIMITERS?
 BEQ NXTER NO - UNRCOGNIZABLE
 LDX DESCRA GET CHARACTER
 LDAB 0,X
 CMPB #$24 IS IT HEX?
 BNE NXT3A NO - GET RC AND RETURN
 JSR HSCAN SCAN HEX STRING
 RTS
NXTER CLRA
 CLRB
 RTS
*
* DSCAN - SCAN DECIMAL STRING AND STOP AT
* FIRST NON-DECMIAL CHARACTER.
*
DSCAN LDX CUCHAR POINT TO NEXT CHAR
 LDAA 0,X GET CHARACTER
 INC DESCRC DESCRC := DESCRC + 1
 INX
 STX CUCHAR POINT TO NEXT CHAR
 JSR GCHRTB GET BYTE IN CHARTAB
 BITA #$40 DECIMAL?
 BNE DSCAN YES - CONTINUE SCAN
 LDAB #$09
 BRA ENDSCN RETURN
*
* NSCAN - SCAN NAME STRING AND STOP AT FIRST
* NON-ALPHANUMERIC CHARACTER.
*
NSCAN LDX CUCHAR POINT TO NEXT CHAR
 LDAA 0,X GET CHARACTER
 INC DESCRC DESCRC := DESCRC + 1
 INX
 STX CUCHAR POINT TO NEXT CHAR
 JSR GCHRTB GET BYTE FROM CHARTAB
 BITA #$80 IS IT ALPHA?
 BNE NSCAN YES - CONTINUE
 BITA #$40 IS IT NUMERIC?
 BNE NSCAN YES - CONTINUE
 LDAB #$07 NAME TO LONG?
 CMPB DESCRC
 BCC NSCANA NO
 STAB DESCRC DESCRC := 7
NSCANA LDAB #$01 LOAD RC
 BRA ENDSCN RETURN
*
* HSCAN - SCAN A STRING OF HEX DATA AND STOP
* AT FIRST NON-HEXADECIMAL CHARACTER.
*
HSCAN CLR DESCRC
 LDX CUCHAR POINT TO NEXT CHAR
 STX DESCRA INIT DESCRA
HSCAN1 LDX CUCHAR POINT TO NEXT CHAR
 LDAA 0,X GET CHARACTER
 INC DESCRC DESCRC := DESCRC + 1
 INX
 STX CUCHAR POINT TO NEXT CHAR
 JSR GCHRTB GET BYTE FROM CHARTAB
 BITA #$02 IS IT HEX?
 BNE HSCAN1 YES - CONTINUE SCAN
 LDAB #$03
ENDSCN DEC DESCRC DESCRC := DESCRC - 1
 LDX CUCHAR
 DEX
 STX CUCHAR ADJUST CUCHAR
 LDAA #$02 LOAD CLASS RC
 RTS
*
* GET A BYTE FROM CHARACTER TABLE INDEXED BY
* VALUE IN A REGISTER.
*
GCHRTB CMPA #$20 IS CHAR VALID?
 BCS GCHRTR NO - SET ERROR
 CMPA #$5F CHECK HI END
 BHI GCHRTR ERROR - SET FLAG
 CLR CHPTR INIT PARAM
 STAA CHPTR+1 SAVE CHARACTER
 LDX #CHPTR POINT TO PARAM
 JSR ADD16 ADD IN BASE OF CHARTAB
 LDX CHPTR GET BYTE IN CHARTAB
 LDAA 0,X
 RTS
GCHRTR CLRA
 RTS
