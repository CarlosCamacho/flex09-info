* PROCESS THE "CMN" PSEUDO CODE TO ALLOCATE
* COMMAON STORAGE AREAS.
*
POCMN JSR ADRINT
 JSR LBLCK

 CMPB #1 OK?
 BEQ POCMN2 YES
POCMN0 LDX #$0216 ERROR
POCMN1 JSR PRINTE PRINT ERROR MESSAGE
 BRA POCMN4

POCMN2 TST PASS

 JSR STOSYM

 BNE POCMN0 NO - ERROR

 JSR NSEVL EVALUATE
 CMPB #$FF OK?

 LDX CMNXS POINT TO ENTRY
 LDAA #$BF
 ANDA 8,X TURN OFF RELATIVE BIT
 ORAA #$10 TURN ON COMMON BIT
 STAA 8,X
 LDAA CMNLC
 STAA 6,X
 LDAA CMNLC+1
 STAA 7,X

* CMNLC := CMNLC + (ADR1,ADR2)
*

 LDAB ADR1
 ADDA CMNLC+1
 ADCB CMNLC
 STAA CMNLC+1
 STAB CMNLC

 LDX SYMPTR POINT TO ENTRY
 LDX 6,X GET COMMON ADDRESS
 STX ADR1 SET UP FOR PRINTL
 COM POP
 COM CMNFLG
 INC MCOUNT
 INC MCOUNT
POCMN4 JSR PRINTL
 JMP MAIN1

* PROCESS "ENTRY" PSEUDO OP:
*
*	DEFINES AN ENTRY POINT FOR REFERENCE
*	BY OTHER MODULES.
*
POENT JSR ADRINT
 JSR LBLCK
 JSR NXTOK GET ENTRY NAME
 CMPB #1 OK?
 BEQ POENT1 YES
 LDX #$0216 NO - ERROR
 JSR PRINTE
 BRA POENT3
*
POENT1 TST PASS
 BEQ POENT4 IF PASS 1
 JSR LKPSYM GET ENTRY ADDRESS
 CMPB #$FF .FROM SYMTAB
 BNE POENT2 IS OK.
 LDX #$0211 NOT OK - ERROR
 JSR PRINTE
 BRA POENT3
*
POENT2 STX ADR1 SAVE ENTRY ADDRESS
 LDX SYMPTR POINT TO ENTRY
 LDAA 8,X GET INFO BYTE
 ORAA #$04 TURN ON "ENTRY" BIT
 STAA 8,X
 JSR PBLOCK OUTPUT LABEL
 LDAB ADR1
 JSR OUTBIN OUTPUT ENTRY ADDRESS
 LDAB ADR2
 JSR OUTBIN
 LDAB #'R RELOCATABLE
 JSR OUTBNR
 LDAB #'N ENTRY
 JSR OUTBNR
POENT3 COM POP
 COM ENTFLG
 INC MCOUNT
 INC MCOUNT
 JSR PRINTL
POENT4 JMP MAIN1

 LDAA #6

* PROCESS THE EQUATE PSEUDO OP
*
POEQU JSR ADRINT
 LDX SYMPTR
 STX EQUXS
 TST LBFLG LABEL?
 BNE EQUB YES - OK
 LDX #$0213 ERROR
EQUA JSR PRINTE
 BRA EQUE
*
EQUB JSR NXTOK GET NEXT TOKEN
 CMPB #$0D EOL?
 BNE EQUC NO - GOOD
 LDX #$0216 ERROR
 BRA EQUA
*
EQUC JSR NSEVL EVALUATE OPERAND
 CMPB #$FF ERRORS?
 BEQ EQUA YES - BAD
 TST PASS
 BNE EQUD IF PASS 2
 LDX EQUXS
 LDAA 8,X
 TST RELFLG RELOCATE?
 BNE EQUF YES
 ANDA #$BF NO - TURN OFF IN INFO
 TST CMNFLG COMMON?
 BEQ EQUF NO
 ORAA #$10 YES - TURN ON IN INFO
EQUF STAA 8,X
 LDAA ADR2 STORE VALUE
 STAA 7,X
 LDAA ADR1
 STAA 6,X
EQUD COM POP
 INC MCOUNT
 INC MCOUNT
EQUE JSR PRINTL
 JMP MAIN1

POEXT JSR ADRINT
 JSR LBLCK
 JSR NXTOK GET EXTERNAL ENTRY NAME
 CMPB #1 OK?
 BEQ POEXT1 YES - GOOD
 LDX #$0216 NO - BAD
 JSR PRINTE
 JSR PRINTL
 BRA POEXT4

 INC LCN
 INC LCN
 TST PASS
 BNE POEXT2

 LDAA 8,X

 STAA 8,X

 JSR PBLOCK OUTPUT NAME

 CLR ADR1
 CLR ADR2
 INC MCOUNT
 INC MCOUNT
 INC MCOUNT

POEXT3 JSR LCLCN
