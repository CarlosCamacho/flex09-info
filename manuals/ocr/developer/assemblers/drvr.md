TTL DRVR
 PAG
*
* INTERFACE ROUTINES TO THE FLEX OPERATING
* SYSTEM.
*
* RESTR	REWIND THE INPUT FILE
* UPDATE	CLOSE ALL FILES AND EXIT
* MONTOR	EXIT TO OPSYS
* GETB	GET A BYTE FROM THE FILE (A)
* OUTB	OUTPUT A BYTE TO THE FILE (A)
* WREOF	OUTPUT AN END OF FILE TO DISK
* INITIO	TAPE STUFF (NOT NEEDED)
*
INITIO RTS DUMMY ROUTINE
*
RESTR STX XTEMP
 PSHB
 LDX #RFCB POINT TO FCB
 LDAA #$05 REWIND FUNCTION
 STAA 0,X
 JSR FMS
 BEQ RWDOK
 JSR RPTERR
 JMP WARMS
RWDOK PULB
 LDX XTEMP
 RTS
*
UPDATE JSR FMSCLS CLOSE FILES
MONTOR JMP WARMS EXIT
*
GETB STX XTEMP
 PSHB
 TST LIBFLG ARE WE IN LIB MODE?
 BEQ NOTLIB NO
*
* DO THIS IF IN LIB MODE
*
 LDX #LIBFCB POINT TO PROPER FCB
 JSR FMS GET BYTE
 BEQ GLOK USE SAME EXIT IF OK
 LDAB 1,X CHECK ERROR CODE
 CMPB #$08 IS IT EOF
 BNE LIBERR HARD ERROR
 LDAA #$04 CLOSE FUNCTION CODE
 STAA 0,X PUT IN FCB
 JSR FMS DO CLOSE
 BNE LIBERR CAN'T DO ANYTHING RIGHT
 CLR LIBFLG ALL'S OK
*
* COME TO HERE IF NOT IN LIB MODE OR
* IF FOUND "EOF" IN LIB FILE
*
NOTLIB LDX #RFCB POINT TO READ FCB
 JSR FMS
 BEQ GLOK
 LDAB 1,X GET ERROR CODE
 CMPB #$08 EOF?
 BEQ GLEOF
*
* DO THIS ON "HARD ERROR"
*
LIBERR JSR RPTERR
 JMP WARMS
*
* GOT EOF IN REGULAR FCB
*
GLEOF SEC
 BRA GLEXIT
*
* EVERYTHING IS "A-OK"
*
GLOK CLC
GLEXIT PULB
 LDX XTEMP
 RTS
*
OUTB STX XTEMP
 PSHB
 LDX #WFCB
 JSR FMS
 BEQ OBOK
 JSR RPTERR
 JMP WARMS
OBOK PULB
 LDX XTEMP
 RTS
*
WREOF PSHB
 STX XTEMP
 LDX #WFCB
 LDAA #$04
 JSR FMS
 BEQ WEOK
 JSR RPTERR
 JMP WARMS
WEOK LDX XTEMP
 PULB
 RTS
*
