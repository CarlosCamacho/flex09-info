TTL MAIN
 OPT PAG
 PAG
*
* MAIN IS THE TOP LEVEL OF THE ASSEMBLER
*	(DRIVER SECTION)
*
MAIN1 JSR RDLINE GET A LINE OF SOURCE
 CLR LBFLG SET FLAG TO NO LABEL
 CLR FCBFLG
 CLR SPCFLG
 LDX LNUM
 INX
 STX LNUM INCR LINE NUMBER
 LDX CULINE POINT TO LINE
 LDAA 0,X GET COLUMN 1
 CMPA #'* IS IT A COMMENT?
 BNE MAIN3 NO
*
* HANDLE COMMENT LINE
*
MAIN1A JSR ADRINT CLEAR PRINT FLAGS
 JSR PRINTL PRINT THE LINE
 BRA MAIN1 GET ANOTHER LINE
*
* HANDLE A NON-COMMENT LINE
*
MAIN3 TST IFFLG ASSEMBLING?
 BNE MAIN3C YES
 CMPA #$20 IS COLUMN 1 A SPACE
 BEQ MAIN3A YES
*
* HANDLE LABEL
*
 JSR NXTOK SCAN OVER LABEL
MAIN3A JSR NXTOK GET MNEMONIC
 LDAA DESCRC GET COUNT
 CMPA #3 <=3?
 BHI MAIN1A NO PRINT THE LINE
*
 JSR MNLKP SEARCH MNEMONIC TABLE
 CPX #POIF IS IT IF?
 BEQ MAIN3B YES
 CPX #PONIF IS IT NIF?
 BNE MAIN1A NO - NEITHER
*
MAIN3B JMP 0,X DO "IF" OR "NIF" PROCESS
*
MAIN3C CMPA #$20 IS COLUMN 1 = SPACE?
 BEQ MAIN5 YES - NO LABEL
 JSR NXTOK GET LABEL
 CMPB #$01 OK?
 BEQ MAIN4 YES
 LDX #$0205 ERROR
 JSR PRINTE
 JSR PRINTL PRINT LINE
 BRA MAIN1
*
MAIN4 INC LBFLG SET LABEL FLAG
 TST PASS
 BNE MAIN5 IF PASS 2
 JSR STOSYM PUT LABEL IN SYMTAB
MAIN5 JSR NXTOK GET MNEMONIC
 CMPB #$01 OK?
 BEQ MAIN7 YES
MAIN6 LDX #$0202 ERROR
 JSR PRINTE PRINT ERROR
 JSR PRINTL PRINT LINE
 BRA MAIN1
MAIN7 JSR MNLKP SEARCH MNEMONIC TABLE
 CMPA #$00 IS IT IN THE TABLE?
 BEQ MAIN9 YES
 JSR LKPSYM IS IT A MACRO NAME?
 CMPB #$FF IN SYMTAB?
 BEQ MAIN8 NO - ERROR
 BITB #$20 IS IT A MACRO NAME?
 BEQ MAIN8 NO - ERROR
 TST MACFLG MACRO MODE?
 BEQ MAIN7A NO
*
* PUSH PRESENT MACRO ONTO MACRO STACK
*
 JSR MACPSH
 TST MACFLG ERRORS?
 BEQ MAIN13 YES
*
MAIN7A STX MACPTR SAVE MACRO LOC IN MACTBL
 JSR PRINTL PRINT THE LINE
 INC MACFLG MODE := MACRO
 JSR NXTOK PARAMETERS?
 CMPB #$0D
 BNE MAIN12 YES - SAVE THEM
 STAB MACPAR NO - CR TO MACPAR
 BRA MAIN13
MAIN9 JMP 0,X GO TO ROUTINE
*
MAIN8 LDX #$0207 ERROR
 JSR PRINTE PRINT ERROR
MAIN10 JSR PRINTL PRINT LINE
MAIN13 JMP MAIN1 PROCESS NEXT LINE
*
* MOVE PARAMS ON MACRO CALL TO MACPAR
*
MAIN12 LDX #MACPAR POINT TO PARM TABLE
 STX MACSAV INIT POINTER
MAIN11 LDX DESCRA POINT TO PARAMS
 LDAA 0,X GET A CHARACTER
 INX
 STX DESCRA SAVE POINTER
 LDX MACSAV GET POINTER
 STAA 0,X
 INX
 STX MACSAV SAVE POINTER
 CMPA #$0D ARE WE DONE?
 BNE MAIN11 NO
 BRA MAIN13 YES
*
