THIS MNEMONIC ASSEMBLER WAS DESIGNED TO BE COMPATIBLE
WITH THE 6800 FLEX OPERATING SYSTEM VERSION 2.0.
AT PRESENT IT IS CAPABLE OF READING SOURCE FILES FROM DISK
AND GENERATING OBJECT FILES TO DISK WITH LISTINGS TO
PRINTER OR CRT.
THERE ARE SEVERAL OPTIONS AVAILABLE THAT ALLOW FOR OUTPUT
DIRECTION.
.SP
THE GENERAL SYNTAX OF THE INPUT COMMAND IS:
.SP
	XASM <FILE SPEC1>[,<FILE SPEC2>][,+<OPTION LIST>]
.SP
WHERE <FILE SPEC1> IS THE FILE NAME TO BE ASSEMBLED AND
DEFAULTS TO THE "TXT" EXTENSION. <FILE SPEC2> IS THE
OUTPUT FILE NAME. IF <FILE SPEC2> IS OMITTED, THE OUTPUT
FILE NAME WILL BE THE SAME AS THE INPUT FILE NAME WITH
THE "BIN" EXTENSION. IF A FILE OF THE SAME NAME AS THE
OUTPUT FILE ALREADY EXITS ON THE DISK SPECIFIED, THE
ASSEMBLER WILL ASK IF IT IS OK TO DELETE THE EXISTING
FILE. IF YOU WANT A NEW OUTPUT FILE TO BE GENERATED,
ANSWER WITH 'Y'. IF ANY OTHER RESPONSE IS GIVEN TO THIS
INQUIRY, THE ASSEMBLER WILL RETURN CONTROL TO THE
OPERATING SYSTEM.
.SP
THE OPTIONS THAT CAN BE SPECIFIED IN THE OPTION LIST ARE
AS FOLLOWS:
.SP
	B	DO NOT CREATE A BINARY FILE.
.SP
	G	GENERATE ONLY ONE LINE OF OUTPUT TO THE LIST

DEVICE FOR EACH LINE OF INPUT.
.SP
	L	TURN OFF LISTING OF OUTPUT.
.SP
	S	DO NOT LIST THE SYMBOL TABLE (CONCORDANCE)
.SP
	N	OUTPUT THE ASSEMBLED LISTING WITH LINE NUMBERS.
.SP
	Y	AUTOMATIC 'OK' TO DELETE THE EXISTING FILE

IF IT ALREADY EXITS.
.SP
IF AN ASSEMBLY ERROR OCCURS DURING PASS 2, THE ASSEMBLER
WILL PRINT THE LINE IN ERROR. AT THE COMPLETION OF PASS 2,
THE NUMBER OF ERRORS ENCOUNTERED IS PRINTED,
FOLLOWED BY THE CONCORDANCE (SYMBOL TABLE) SORTED
IN ASCENDING ORDER.
.PG
THIS ASSEMBLER WILL ALLOW THE USE OF FREE FORM INPUT
WITH THE FOLLOWING RESTRICTIONS: (OUTPUT IS AUTOMATICALLY
FEILDED, THEREFORE ADDITIONAL SPACES BETWEEN FEILDS ARE

THE GENERAL FORMAT OF THE SOURCE LINE IS:
.SP
<LABEL> <MNEMONIC> <OPERAND> <COMMENT> (CARRAIGE RETURN)

.IN 3
1. MAY CONTAIN AN EXPESSION THAT QUALIFIES UNDER THE
.IN 7
REQUIREMENTS FOR AN EXPRESSION LISTED BELOW
.SP
AN EXPESSION CAN BE ANY COMBINATION OF NUMBERS AND
SYMBOLS SEPARATED BY THE ARITHMETIC OPERATORS
+,-,*, OR /. ALL EXPESSIONS ARE CALCULATED AS 16
BIT INTEGERS, FROM LEFT TO RIGHT WITH NO REGARD
TO PRIORITY OF OPERATORS.
ANY 8 BIT RESULTS ARE TAKEN FROM
THE LEAST SIGNIFICANT 8 BITS. NO SPACES ARE ALLOWED
IN THE EXPESSION. AN ASTERIK DENOTES THE CURRENT
PROGRAM COUNTER VALUE WHEN NOT USED AS AN ARITHMETIC
OPERATOR. (**2 WILL RETURN THE PROGRAM COUNTER TIMES 2)
.SP

THE ASSEMBLER REQUIRES A MINIMUM OF 16K BYTES OF MEMORY
TO BE LOCATED FROM $0000 TO $3FFF. THIS WILL ALLOW FOR
THE ASSEMBLY OF SMALL PROGRAMS BECAUSE OF SYMBOL
TABLE USAGE. THE SYMBOL TABLE BEGINS AT $3000 AND GROWS
IN A LINEAR FASHION. THE MORE SYMBOLS USED AND REFERENCED,
THE LARGER THE TABLE GROWS.
THE MORE MEMORY, THE LARGER THE TABLE WILL BE ALLOWED TO GROW.
