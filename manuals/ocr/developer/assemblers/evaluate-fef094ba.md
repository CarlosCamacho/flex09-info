# EVALUATE

The text below preserves the wording and formatter directives found in the historical source. OCR and media-decoding errors may remain.

*
* THIS ROUTINE IS ENTERED WITH THE INDEX
* REGISTER POINTING TO THE STRING TO BE
* EVALUATED.
*
EVAL CLR IEXPRF ILLEGAL EXPRESSION
 LDAA 0,X
 CMPA #'*
 BNE NOTREL NOT PRG CTR REL
 STX FROM
 LDX PRGCTR GET PROGRAM COUNTER
 STX TEMP
 LDX FROM
 INX
 BRA EVLOOP
NOTREL CLR TEMP CLEAR THE PSEUDO ACCUM
 CLR TEMP+1
EVLOOP CLR OPRATN INIT OPERATION FLAG
 DEX FIX FOR LATER INCR
 BRA SETADD SET ADD OPERATION
*
SETMUL INC OPRATN
SETDIV INC OPRATN
SETSUB INC OPRATN
SETADD INX
 STX OPTR
*
EV1 LDX OPTR CURRENT STRING POINTER
 LDAA 0,X GET THE CHAR
 CMPA #'A TEST FOR ALPHA
 BCS EV3 NOT ALPHA
 CMPA #'Z
 BLS EV2 FOUND ALPHA STRING
 CMPA #$61 DO SAME FOR LOWERCASE
 BCS EV3 NOT ALPHA
 CMPA #$7A
 BHI EV3 NOT ALPHA
*
* IF WE DO THIS WE FOUND ALPHA DATA SO
* GET A VALUE FROM SYMTAB.
*
EV2 JSR MOVOPR MOVE TO SYMBOL
 JSR GETSYM POINT TO SYMBOL
 TST UDSFLG
 BNE EVERR
 LDAB 8,X GET HI ORDER BYTE
 LDAA 9,X GET LO ORDER BYTE
 TST PASS
 BEQ EV26
 TST EQUFLG
 BNE EV26
 JSR BLDCNC
 BRA EV26
*
EV25 LDAB XTEMP
 LDAA XTEMP+1
EV26 JSR DOOPRA DO FLAGGED OPERATION
 LDX IRSAVE SET UP POINTER
 BRA EVLOOP AND DO AGAIN
*
* IF WE DO THIS STUFF - THEN WE ARE NOT
* LOOKING AT ALPHABETIC DATA.
*
EV3 CMPA #$20 IS IT SPACE?
 BEQ EVDONE YES-EXIT
 CMPA #$0D IS IT CRTN?
 BEQ EVDONE YES-EXIT
 CMPA #', COMMA?
 BEQ EVDONE YES
 CMPA #$24
 BEQ HEX
 CMPA #$26
 BEQ OCTAL
 CMPA #'+
 BEQ SETADD
 CMPA #'-
 BEQ SETSUB
 CMPA #'/
 BEQ SETDIV
 CMPA #'*
 BEQ SETMUL
 CMPA #$27
 BEQ EV4
 CMPA #'0 IS IT NUMERIC
 BCS ILLEXP N0-ILLEGAL EXPR
 CMPA #'9
 BHI ILLEXP	-ILLEGAL EXPR
*
* IF THIS STUFF GETS EXECUTED, IT'S BECAUSE WE
* FOUND SOME NUMERIC DATA.
*
 JSR MOVOPR
 LDX IRSAVE
 DEX POINT TO LAST CHAR
 LDAA 0,X
 CMPA #'0 IS IT ALSO NUM?
 BCS CKBASE NO-CHECK NUM BASE
 CMPA #'9
 BLS CNVRTD CONVERT ASCII DEC
CKBASE CMPA #'H IS IT HEX?
 BEQ CNVRTH CONVERT ASCII HEX
 CMPA #'O IS IT OCTAL?
 BEQ CNVRTO CONVERT ASCII OCT
*
* ILLEGAL EXPRESSION ENCOUNTERED
*
ILLEXP LDAA #$FF
 STAA IEXPRF SET ILLEGAL EXPR FLAG
EVERR CLR TEMP
 CLR TEMP+1
EVDONE LDAB TEMP
 LDAA TEMP+1
 RTS
*
EV4 LDX OPTR
 INX
 STX OPTR
 JSR MOVOPR
 LDX #SYMBOL
 LDAA 0,X
 CLRB
 RTS
*
CNVRTD JSR DECOPR
 JMP EV25
HEX JSR HOB
CNVRTH JSR HEXOPR
 JMP EV25
OCTAL JSR HOB
CNVRTO JSR OCTOPR
 JMP EV25
*
HOB INX
 STX OPTR
 JSR MOVOPR
 RTS
*
* FOUND A DECIMAL OPERAND TO CONVERT TO HEX
*
DECOPR JSR CNVINT INTIALIZE AND POINT
DO1 LDAB 0,X GET A CHAR
 CMPB #$20
 BEQ DO3
 CMPA #'D
 BEQ DO3
 ANDB #$0F
DO2 PSHB
 LDAA XTEMP
 LDAB XTEMP+1
 JSR LEFT2
 ADDB XTEMP+1
 ADCA XTEMP
 STAB XTEMP+1
 STAA XTEMP
 JSR LEFT1
 PULB
 CLRA
 ADDB XTEMP+1
 ADCA XTEMP
 STAB XTEMP+1
 STAA XTEMP
 INX
 BRA DO1
DO3 RTS
*
* CONVERT ACSII HEX TO HEX (16 BITS).
*
HEXOPR JSR CNVINT
HO1 LDAA 0,X
 CMPA #'H LOOK FOR TERMINATOR
 BEQ HO3 DONE
 CMPA #$20
 BEQ HO3
 SUBA #$30 ADJUST
 CMPA #9
 BLS HO2
 SUBA #7 ADJUST SOME MORE
HO2 JSR LEFT2
 JSR LEFT2
 ADDA XTEMP+1
 STAA XTEMP+1
 INX
 BRA HO1
HO3 RTS
*
* CONVERT OCTAL OPERAND TO HEX DATA
*
OCTOPR JSR CNVINT
OO1 LDAA 0,X
 CMPA #'O
 BEQ OO2
 CMPA #$20
 BEQ OO2
 ANDA #$0F
 JSR LEFT2
 JSR LEFT1
 ADDA XTEMP+1
 STAA XTEMP+1
 INX
 BRA OO1
OO2 RTS
*
* INIT PSEUDO ACC AND POINT TO ASCII NUMBER
*
CNVINT LDX #SYMBOL
 CLR XTEMP
 CLR XTEMP+1
 RTS
*
LEFT2 BSR LEFT1
LEFT1 ASL XTEMP+1
 ROL XTEMP
 RTS
*
* THIS ROUTINE WILL MOVE DATA FEILDS FROM THE
* OPERAND BUFFER TO THE BUFFER "SYMBOL" FOR
* COMPARISON.
*
MOVOPR BSR CLRSYM INIT TO SPACES
 LDX OPTR
 STX IRSAVE
 LDX #SYMBOL
MOLOOP STX TO
 LDX IRSAVE
 LDAA 0,X
 ANDA #$7F
 CMPA #'0
 BCS MOEND
 CMPA #'9
 BLS MO1
 CMPA #'A
 BCS MOEND
 CMPA #'Z
 BLS MO1
 CMPA #$61
 BCS MOEND
 CMPA #$7A
 BHI MOEND
MO1 INX
 STX IRSAVE
 LDX TO
 STAA 0,X
 INX
 CPX #SYMBOL+16
 BNE MOLOOP
MOEND RTS
*
CLRSYM LDX #SYMBOL
 LDAA #$20
CSLOOP STAA 0,X
 INX
 CPX #SYMBOL+16
 BNE CSLOOP
 RTS
*
* THIS TABLE LOOKUP EXECUTES THE CODE
* NECCESSARY TO DO THE MATH OPERATION
* SPECIFIED BY THE FLAG "OPRATN".
*
DOOPRA LDX #OTBL POINT TO TABLE
DOLP TST OPRATN
 BEQ EXOPRA FOUND IT
 DEC OPRATN
 INX
 INX
 BRA DOLP
EXOPRA LDX 0,X
 JSR 0,X GO DO IT
 RTS

* OPERATION TABLE
*
OTBL FDB ADD16
 FDB SUB16
 FDB DIV16
 FDB MUL16
*
ADD16 ADDA TEMP+1
 ADCB TEMP
 STAA TEMP+1
 STAB TEMP
 RTS
*
SUB16 STAA XTEMP+1
 STAB XTEMP
 LDAA TEMP+1
 LDAB TEMP
 SUBA XTEMP+1
 SBCB XTEMP
 STAA TEMP+1
 STAB TEMP
 RTS
*
MUL16 LDX #$0000
 STX XTEMP2 RESULT ACCUM
 LDX #XTEMP2 POINT TO IT
 LDAB #16 BIT COUNT
M162 LDAA 3,X GET MULTIPLIER LSB
 RORA CHECK BIT
 BCC M163 DON'T ADD
 PSHB
 LDAB 5,X GET MULTPICAND
 LDAA 4,X
 ADDB 1,X
 ADCA 0,X
 STAA 0,X
 STAB 1,X
 PULB
M163 LSR 0,X SHIFT MULTIPLIER
 ROR 1,X
 ROR 2,X
 ROR 3,X
 DECB ARE WE DONE?
 BNE M162 NO.
 LDX 2,X GET RESULT
 STX TEMP PUT WHERE IT BELONGS
 RTS
*
DIV16 LDX #$0000
 STX XTEMP2 INIT ACCUM
 LDX XTEMP AND SWAP XTEMP/TEMP
 LDAA TEMP
 STAA XTEMP
 LDAA TEMP+1
 STAA XTEMP+1
 STX TEMP
 LDAB #17 SET COUNTER
 LDX #XTEMP2 POINT
D161 PSHB
 LDAB TEMP+1
 LDAA 1,X
 SBA
 STAA 1,X
 LDAA 0,X
 SBCA TEMP
 STAA 0,X
 ROLA
 EORA #1
 RORA
 BCS D163
 LDAA TEMP
 LDAB TEMP+1
 ADDB 1,X
 ADCA 0,X
 STAB 1,X
 STAA 0,X
 CLC
D163 ROL 3,X
 ROL 2,X
 ROL 1,X
 ROL 0,X
 PULB
 DECB ARE WE DONE?
 BNE D161 NOT YET
 LDX 2,X GET RESULT
 STX TEMP WHERE IT BELONGS
 RTS
*
* THIS WILL BUILD THE CONCORDANCE DURING
* PASS 2.
*
BLDCNC PSHA
 PSHB
 STX BCTEMP
 LDX 10,X
 CPX #$FFFF BEEN HERE BEFORE?
 BNE NOT1ST YES
 LDAA CURPTR FIX FIRST TIME
 LDAB CURPTR+1
 LDX BCTEMP
 STAA 10,X SET UP SYMTAB
 STAB 11,X
FNDEND LDX CURPTR NOW DO CNC TABLE
 LDAA PRGCTR
 LDAB PRGCTR+1
 STAA 0,X
 STAB 1,X
 LDAA #$FF SET BOTTOM OF RUN
 STAA 2,X
 STAA 3,X
 INX
 INX
 INX
 INX
 STX CURPTR
 LDAA CURPTR
 CMPA #$80 CHECK FOR OVERFLOW
 BCS NOTSWI
*
* SYMBOL TABLE OVERFLOW
*
 SWI
*
NOTSWI PULB
 PULA
 RTS
*
NOT1ST STX BCTEMP
 LDX 2,X LOOP TILL HIT BOTTOM
 CPX #$FFFF
 BNE NOT1ST
 LDAA CURPTR HIT END OF RUN
 LDAB CURPTR+1
 LDX BCTEMP
 STAA 2,X
 STAB 3,X
