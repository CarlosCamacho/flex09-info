* OUTPUT TO LIST DEVICE ROUTINES
*
PRINTL LDAA OPTNS GET OPTIONS
 BITA #$80 LIST ON?
 BNE PLEND NO - EXIT
 TST PASS PASS 2
 BEQ PLEND NO - EXIT
 TST MACFLG MACRO FLAG SET?
 BEQ PRINT1 NO - PRINT LINE
 BITA #$10 YES - PRINT MACROS?
 BNE PLEND NO - EXIT
PRINT1 JSR LINCK CHECK LINE NUMBER
 JSR OUTL PRINT THE LINE
PLEND RTS EXIT

* CHECK LINE FOR TOP OF PAGE, ETC.
*
LINCK PSHB
 LDAB LCOUNT
 CMPB #$00 END OF PAGE?
 BNE LINCKA NO
 JSR SPACER YES - SPACE TO TOP
LINCKA INC LCOUNT LCOUNT := LCOUNT + 1
 LDAB LCOUNT
 CMPB #$37 LCOUNT = 55?
 BNE LINCKB NO
 CLR LCOUNT YES - SET UP FOR TOP
LINCKB PULB
 RTS
