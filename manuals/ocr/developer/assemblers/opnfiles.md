# OPNFILES

> Source: `dev/assemblers/RA68NO2 - Assembler Development - Documentation and Examples.zip!RA68NO2.DSK!OPNFILES.TXT`  
> Method: FLEX disk extraction

The text below preserves the wording and formatter directives found in the historical source. OCR and media-decoding errors may remain.

TTL OPNFILES
 PAG
*
* THIS SEGMENT WILL OPEN THE SOURCE FILE
* FOR READ AND A BINARY FILE FOR WRITE
*
OPNFLS LDX #RFCB POINT TO READ FCB
 JSR GETFIL PUT FILE SPEC IN FCB
 BCS ILLFS ILLEGAL FILE SPEC
 LDX #RFCB
 LDAA #$01 SET "TXT" EXT
 JSR SETEXT
 LDX #RFCB+3
 STX FROM
 LDX #WFCB+3
MOVRTW STX TO MOVE READ FILE NAME
 LDX FROM .TO WRITE FILE NAME
 LDAA 0,X
 INX
 STX FROM
 LDX TO
 STAA 0,X
 INX
 CPX #WFCB+15
 BNE MOVRTW DO TILL DONE
*
 CLR WFCB+12 KILL TXT EXT IN WFCB
 LDX #RFCB
 LDAA #$01 OPEN FOR READ
 STAA 0,X
 JSR FMS DO IT
 BNE OPNERR ERROR ON READ OPEN
 JSR TSTTRM TEST TERMINATOR
 BEQ NOTPLS
 BMI GETOPT GET OPTIONS
 LDX #WFCB FOUND COMMA
 JSR GETFIL GET OUTPUT FILE SPEC
 BCC OPNOK
ILLFS LDX #IFSMSG ILLEGAL FILE SPEC
 JSR PSTRNG PRINT IT
 JMP WARMS
*
OPNOK JSR TSTTRM
 BEQ NOTPLS
 BPL NOTPLS
*
GETOPT JSR NXTCH GET NEXT CHAR FROM
 BCS NOTPLS .LINE BUFFER
 CMPA #$0D EOL?
 BEQ NOTPLS YES - DONE
 CMPA #'L LISTING ON?
 BNE OPIN10 NO
 LDAA #$70 YES - SET BIT
 BRA OPIN2
OPIN10 CMPA #'O OBJECT ON?
 BNE OPIN11 NO
 LDAA #$B0 YES SET BIT
 BRA OPIN2
OPIN11 CMPA #'S SYMBOL TABLE?
 BNE OPIN12 NO
 LDAA #$D0 YES - SET BIT
 BRA OPIN2
OPIN12 CMPA #'M MACRO EXPANSION LISTING?
 BNE OPIN13 NO
 LDAA #$E0 YES - SET BIT
 BRA OPIN2
OPIN13 CMPA #'Y
 BNE GETOPT NO - LOOP
 STAA YFLG SET OK TO DELETE
 BRA GETOPT
*
OPIN2 ANDA OPTNS TURN OFF "NOT" BIT
 STAA OPTNS
 BRA GETOPT GET ANOTHER OPTION
*
NOTPLS LDAA OPTNS
 BITA #$40
 BNE NOBJ NO OBJECT
 LDX #WFCB
 LDAA #'L
 STAA 12,X SET UP EXTENSION
 LDAA #'D .AS "LDM" FOR
 STAA 13,X .LOAD MODULE
 LDAA #'M
 STAA 14,X
 LDX #WFCB
 LDAA #$02 OPEN FOR WRITE
 STAA 0,X
 JSR FMS DO IT
 BNE OPNERR
 LDAA #$FF TURN OFF SPC CMPRS
 STAA 59,X
NOBJ RTS
*
OPNERR LDAA 1,X GET ERROR CODE
 CMPA #$03 IS IT "FILE EXISTS"?
 BNE CHKNSF NO-CHK "NO SUCH FILE"
 LDAA YFLG YES=OK TO DELETE
 CMPA #'Y
 BEQ OKTDEL THEN DO IT
 LDAA #$01
 STAA OUTSWT
 LDX #DELMSG
 JSR PSTRNG
 JSR INCH
 CLR OUTSWT
 ANDA #$5F MAKE UPPER CASE
 CMPA #'Y
 BNE EXIT1
*
OKTDEL LDX #WFCB
 LDAA #$0C DEL EXISTING FILE
 STAA 0,X
 JSR FMS DELETE IT
 BNE GIVUP "GIVE IT UP"
 LDAA 36,X
 STAA 4,X FIX FIRST CHAR
 BRA NOTPLS
*
CHKNSF CMPA #$04
 BNE GIVUP
 LDX #NSFMSG "NO SUCH FILE"
 JSR PSTRNG
 BRA EXIT2
*
GIVUP JSR RPTERR
EXIT1 JSR FMSCLS
EXIT2 JMP WARMS
*
TSTTRM LDAA LSTTRM GET LAST TERMINATOR
 CMPA #$0D WAS IT CARET
 BEQ TT4 YES
 CMPA DEOL WAS IT "EOL"?
 BEQ TT4 YES
 CMPA #'+ WAS IT PLUS?
 BNE TT2 NO
TT1 LDAA #$FF
 BRA TT4
TT2 LDX BUFPNT
 LDAA 0,X
 INX
 CMPA #'+
 BNE TT3
 STX BUFPNT (FLEX'S POINTER)
 BRA TT1
TT3 LDAA #$01
TT4 RTS
*
