FCB LDX PBPTR POINT TO LINE
 JSR BACKUP MOVE POINTER BACK
 STX PBPTR SAVE POINTER
 TST PASS
 BNE FCB4 DO PASS 2 STUFF
*
* DO THIS FOR PASS 1 ONLY
*
 CLR FCBCNT CLEAR BYTE COUNT
FCB1 INC FCBCNT INCR BY ONE
FCB2 LDAA 0,X GET CHAR
 INX POINT TO NEXT
 CMPA #', IS IT COMMA?
 BEQ FCB1 INCR COUNT
 CMPA #$20 IS IT SPACE?
 BEQ FCB3 YES - DONE
 CMPA #$0D IS IT CR?
 BNE FCB2 NO - LOOP
FCB3 CLRB
 LDAA FCBCNT GET COUNT
 RTS
*
* DO THIS STUFF FOR PASS 2
*
FCB4 STX OPSAVE FOR "OUTOPR"
 CLR PFLAG
 CLR FCBFLG
 JSR EVAL
 STAA OPCODE+1
 JSR OUTLIN
 BRA FCB5
*
FCBLP TST NOGFLG LISTING OFF =
 BEQ FCB5 .LINE # ON AND
 JSR CLRLBL .NOGEN ON.
 JSR CLRMNM
 JSR CLROPR
 JSR LIST
