Rbasic

Rbasic was written by Bob Jones who resides in Abbotsford BC
Canada.  Bob was a contributor to '68 Micro Journal for a long
period.  He wrote a series on digital logic design that was most
interesting.  Bob realized that TSC Extended BASIC had some
flaws, not the least of which were some errors in the scientific
functions.  Bob set out to fix these and did that and much more
with his RBASIC. (R for Robert, I assume)

Recently Frank Wilson and Don Sommer visited Bob and were given
the source files for RBASIC and for the manual written in
Stylograph.  Bob also released the software to the public domain.

Frank and I both began to work on the manual files reading the
Stylo source and converting them to Word so we could make a .PDF
file out of them.  The result is part of this package,
RBASIC.PDF.  While it is not an exact reproduction of Bob's
original in format, it is quite close.

Frank found that the MON jump in RBASIC was not through the
standard vector and has prepared an overlay patch and text
explaining it. That is part of this package also. We've included
the .PDF file of the instructions for the TSC Pre-compiler. Bob
wrote a clone of that, which is also included here. I've tested
it (Ron) and found it to work quite well. About all it does in
actuality is to allow long variable names and labels, and to
eliminate line numbers.  That doesn't sound like a whole lot, but
it makes for a much more readable program.

This package has two .DSK files which contain the RBASIC source
and .CMD file as well as the pre compiler and all the text files
for the manual.

We thank Bob here for his generous release of this package so we
can all enjoy it.

Ron Anderson
