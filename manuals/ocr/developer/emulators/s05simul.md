************************ S05EQUAT ****************************
* THIS MODULE CONTAINS EQUATE STATEMENTS FOR ALL FLEX
* REFERENCES IN THE PROGRAM.	MUCH OF THE CHANGES TO BE
* PERFORMED IN TRANSFERRING THE PROGRAM TO ANOTHER
* VERSION OF FLEX WOULD BE IN THIS MODULE.
 LIB S05EQUAT
************************ S05INITZ ****************************
* THIS MODULE CONTAINS THE EXTERNAL ADDRESS TABLE,
* THE INITIALIZATION ROUTINES, THE COMMAND INTERPRETER,
* AND A ROUTINE WHICH FIXES ADDRESSES AFTER FLEX CALLS
* SUCH AS ERROR REPORTING AND EXPLICIT FLEX COMMANDS.
 LIB S05INITZ
************************ S05MISCL ****************************
* THIS MODULE CONTAINS SEVERAL UTILITY-TYPE ROUTINES,
* GENERALLY CALLED EXPLICITLY FROM THE COMMAND INTERPRETER.
 LIB S05MISCL
************************ S05AUXIL ****************************
* THIS MODULE CONTAINS THE ROUTINES WHICH CONTROL AUXILIARY
* INPUT AND OUTPUT.	AUXILIARY INPUT IS HANDLED BY FOOLING
* THE CHARACTER INPUT ROUTINE BY MAKING IT READ FROM THE
* AUXILIARY FILE RATHER THAN FROM THE TERMINAL.	AUXILIARY
* OUTPUT IS HANDLED BY FORMATTING A FILE WITH DATA SIMULATING
* COMMAND INTERPRETER INPUT.
 LIB S05AUXIL
************************ S05DMPTB ****************************
* THIS MODULE CONTAINS THE ROUTINE WHICH LISTS THE INTERNAL
* CONTROL TABLES TO THE OUTPUT DEVICE.
 LIB S05DMPTB
************************ S05SHOWC ****************************
* THIS MODULE CONTAINS THE ROUTINES WHICH IMPLEMENT THE FULL
* SCREEN DISPLAY AND MODIFICATION OF THE OBJECT PROGRAM CODE.
* THE SPECIFIC NATURE OF A GIVEN SYSTEM AND TERMINAL IS
* PROVIDED BY OTHER LIBRARY FILES WHICH MUST BE INCLUDED
* BY THE USER TO SUIT A GIVEN SITUATION.
 LIB S05SHOWC
************************ S05INCHR ****************************
* THIS MODULE MUST BE SELECTED BY THE USER TO PROVIDE THE
* DETAILS OF THE INPUT ROUTINE FOR A SPECIFIC SYSTEM AND
* TERMINAL.	THE ROUTINE MUST RETURN THE CURRENT CHARACTER,
* IN ASCII, IN THE A-REGISTER, AND MUST PRESERVE THE
* B-REGISTER AND X-REGISTER.
 LIB S05INCHR
************************ S05DKDSK ****************************
* THIS MODULE PROVIDES THE ROUTINES WHICH OBTAIN THE INPUT
* AND OUTPUT FILE NAMES FROM THE INPUT DEVICE.	FOR PURPOSES
* OF SIZE AND CONVENIENCE, THE STANDARD FLEX INTERFACE IS
* USED AS MUCH AS POSSIBLE.
 LIB S05DKDSK
************************ S05INPUT ****************************
* THIS MODULE PROVIDES A ROUTINE WHICH STORES AN ADDRESS RANGE
* AND TYPE OF RANGE IN A TABLE, A ROUTINE WHICH SCANS AND
* VERIFIES SUCH A RANGE, AND A ROUTINE WHICH OBTAINS AN
* ENTIRE INPUT LINE FROM AN INPUT DEVICE.
 LIB S05INPUT
************************ S05ZAPCD ****************************
* THIS MODULE CONTAINS ROUTINES TO ASSIST IN THE PROCESS OF
* EDITING AND DECODING AN OBJECT MODULE.	TWO ROUTINES ALLOW
* THE INQUIRY AND MODIFICATION OF THE OBJECT PROGRAM CONTENTS.
* THE MODIFICATIONS ARE STORED IN A TABLE, RATHER THAN BEING
* ACTUALLY APPILED TO THE PROGRAM.	ONE ROUTINE ALLOWS THE
* LOCATING OF STRINGS OF HEX CHARACTERS WITHIN THE OBJECT
* PROGRAM.	ANOTHER ROUTINE OUTPUTS A FLEX-FORMATTED OBJECT
* PROGRAM FROM THE CURRENT OBJECT PROGRAM, POSSIBLY WITH
* USER-SPECIFIED MODIFICATIONS.
 LIB S05ZAPCD
************************ S05DISAS ****************************
* THIS MODULE CONTAINS THE ROUTINES WHICH DISASSEMBLE THE
* OBJECT PROGRAM.	THE SOURCE OF THE OBJECT PROGRAM MUST
* ALREADY BE KNOWN.	THE DESTINATION IS DETERMINED BY THESE
* ROUTINES.	ACTUAL FORMATTING OF THE DISASSEMBLED LISTING
* AND DISK OUTPUT IS DONE BY OTHER MODULES.
 LIB S05DISAS
************************ S05GETCD ****************************
* THIS MODULE CONTAINS THE ROUTINES WHICH RETURN THE OBJECT
* PROGRAM BYTE AND TYPE AT A GIVEN ADDRESS.	IF THE ADDRESS
* IS OUTSIDE OF THE SPECIFIED ADDRESS RANGE OR IS IN AN
* IGNORED RANGE OF ADDRESSES, ZERO IS RETURNED.
 LIB S05GETCD
************************ S05IAFCB ****************************
* THIS MODULE CONTAINS ROUTINES USED BY THE SIMULATOR
* ROUTINE TO ASSIST IN THE DISASSEMBLY OF THE OBJECT PROGRAM.
 LIB S05IAFCB
************************ S05MAPDK ****************************
* THIS MODULE MAPS AN INPUT OBJECT PROGRAM ON DISK.	THE
* PROGRAM CODE IS BROUGHT INTO MEMORY FROM DISK.
 LIB S05MAPDK
************************ S05OUTCD ****************************
* THIS MODULE FORMATS THE DISASSEMBLED OUTPUT LISTING.
 LIB S05OUTCD
************************ S05EXECU ****************************
* THIS MODULE CONTAINS THE ROUTINES WHICH CONTROL THE
* INTERPRETIVE EXECUTION OF THE [14]6805 PROGRAM.
 LIB S05EXECU
************************ S05OPCOD ****************************
* THIS MODULE CONTAINS THE INDIVIDUAL SUBROUTINES WHICH
* IMPLEMENT THE OPCODES FOR THE SIMULATOR.
 LIB S05OPCOD
************************ S05XIORT ****************************
* THIS MODULE CONTAINS THE INPUT/OUTPUT HANDLERS WHICH INTERFACE
* WITH THE PRIMITIVE FLEX INPUT/OUTPUT ROUTINES.	THEY ARE
* NECESSARY IN ORDER TO CONTROL THE DIVERSION OF INPUT AND
* OUTPUT FROM AND TO DISK AND TO PRINTER AND TERMINAL.
 LIB S05XIORT
************************ S05CONST ****************************
* THIS MODULE CONSISTS OF MANY OF THE CONSTANTS USED BY THE
* SIMULATOR DURING ITS PROCESSING OF OBJECT CODE.	IT
* ALSO CONTAINS THE TEXT FOR THE MENU AND THE ADDRESS TABLE
* USED BY THE COMMAND INTERPRETER TO VECTOR THE SINGLE-LETTER
* COMMANDS TO THE CORRESPONDING ROUTINES.
 LIB S05CONST
************************ S05PARAM ****************************
* THIS MODULE MUST BE SELECTED BY THE USER TO PROVIDE THE
* DETAILS OF THE TERMINAL TO BE USED.	BECAUSE OF FLEX
* LIMITATIONS, THE SIMULATOR MUST PERFORM ITS OWN INPUT
* FROM THE TERMINAL AND MUST HAVE AVAILABLE CERTAIN ATTRIBUTES
* OF THE TERMINAL TO BE USED.	COMMENTS IN THE MODULE ITSELF
* PROVIDE THE REQUIRED INFORMATION TO BE ENTERED.
 LIB S05PARAM
************************ S05TABLE ****************************
* THIS MODULE CONTAINS THE TABLES USED BY THE SIMULATOR
* IN ORDER TO DECODE THE OPERATION CODES AND TO ASSOCIATE
* THE MNEMONIC NAMES WITH THEM.
 LIB S05TABLE
************************ S05VARBL ****************************
* THIS MODULE CONTAINS THE VARIABLES USED BY THE SIMULATOR
* IN PERFORMING ITS REQUESTED OPERATIONS.	OF THE ENTIRE
* SIMULATOR, THE ONLY PORTIONS WHICH SHOULD VARY DURING
* EXECUTION ARE THE EXTERNAL ADDRESSES AT THE BEGINNING OF
* THE PROGRAM AND THE VARIABLES IN THIS MODULE.
 LIB S05VARBL
************************
 END START
