**
DISKD JSR XCRLF INPUT FILE NAME
 CLR EQUFL CLEAR FLAGS
 JSR MAPRT
 CLR DEFALT
 TST DISIF CHECK INPUT FLAG
 BEQ DIKIA ALREADY OPEN?
 CLR DISIF CLR INPUT FLAG
 LDX #FCBI CLOSE INPUT FILE
 LDAA #FMCLSI
 STAA $00,X
 JSR FMS
DIKIA LDX #DISIM
 JSR XPDAT
 LDX #FCBI
 JSR INBUFR GET FILE NAME TO LINE BUFFER
 LDX BUFPTR
 LDX $00,X
 LDAA $00,X
 CMPA #$0D GET FIRST CHAR IN BUFFER
 BEQ DIKII NO FILE NAME ENTERED
 LDX #FCBI POINT TO INPUT FCB
 JSR GETFSP GET FILE SPEC FROM LINE BUFFER
 BCS DIKIE CHK ERROR
 LDAA #EXTBIN SET ".BIN" AS DEFAULT EXTENSION
 JSR SETXTN
 LDAA #FMOPNI OPEN FILE
 STAA $00,X
 JSR FMS
 BEQ DIKRE CHK ERROR
 JMP RPTERO
DIKRE JSR MAPDK OPEN, MAP IT
 BCC DIKTI CHK ERROR
 JSR FMSCLO CLOSE IT AND EXIT
DIKIE JMP STOPIN TURN OFF AUX INPUT
DIKTI LDAA #$4B DEFAULT TYPE=K
 STAA DEFALT
 INC DISIF
 LDX TYPEE SET MAP ADDR
 STX TYPEM
DIKII RTS
**
DIKNI JSR XCRLF OUTPUT FILE NAME
 CLR DISOF
 LDX #DISOM
 JSR XPDAT
 JSR INBUFR GET FILE NAME INTO LINE BUFFER
 LDX BUFPTR
 LDX $00,X
 LDAA $00,X GET FIRST CHAR IN BUFFER
 CMPA #$0D IS IT CR?
 BEQ DIKNO YES, THEN NO NAME WAS ENTERED
 LDX #FCBO POINT TO OUTPUT FCB
 JSR GETFSP GET FILE SPEC TO FCB
 BCS DIKIE CHK ERROR
 LDAA WORKA SET DEFAULT EXTENSION
 JSR SETXTN
 INC DISOF
DIKNO RTS
