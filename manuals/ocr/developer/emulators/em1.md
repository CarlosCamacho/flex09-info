* MOVE TYPE : MOV R1,R2
*
RT01 LDX #REGS
 LDAA #$06
 CMPA SSS MEM TYPE MOVE OR HALT
 BEQ RM YES = REG TO MEM OR HALT
 CMPA DDD MEMORY TYPE MOVE?
 BEQ MR YES = MEM TO REG
 LDAA SSS GET SOURCE REGISTER
 CMPA #$07
 BNE RT1
 DECA
RT1 STAA RT01A+1 BUILD INSTRUCTION
RT01A LDAB 0,X GET SOURCE DATA
 LDAA DDD GET DEST REGISTER
 CMPA #$07
 BNE RT2
 DECA
RT2 STAA RT01B+1 BUILD INSTRUCTION
RT01B STAB 0,X STORE DATA IN DEST REG
 JMP END
