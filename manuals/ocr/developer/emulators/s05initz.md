 ORG $4000
**
SBMODE EQU $FF SET BINARY MODE IN FCB

FLSEP2 EQU $2E SEPARATES FILE NAME AND EXTENSION

START BRA INITZ STARTING ADDR
VN FCB $00 VERSION NUMBER

JMPBEG EQU * FIRST FLEX JUMP
WARMS JMP WARMST WARM START
INEEE JMP GETCHR INPUT 1 CHAR TO A
INCH1 JMP INCHAR PRIMITIVE INPUT 1
INCH2 JMP INCHA2 PRIMITIVE INPUT 2
OUTEE JMP PUTCHR OUTPUT 1 CHAR FROM A
OTCH1 JMP OUTCHR PRIMITIVE OUTPUT 1
OTCH2 JMP OUTCH2 PRIMITIVE OUTPUT 2
PCRLF JMP PRCRLF PRINT CRLF
ADDBX JMP ADDB2X ADD B TO X
RPTERX JMP RPTERR REPORT ERROR
INBUFR JMP INBUFF INPUT TO FLEX LINE BUFFER
GETFSP JMP GETFIL GET FILE SPEC
SETXTN JMP SETEXT SET DEFAULT EXTENSION
FMSCLO JMP FMSCLS FMS CLOSE
FMS JMP FMSCAL FMS CALL
DOXCOM JMP DOCMND DOS CALL
JMPEND EQU * LAST FLEX JUMP
TABLE FDB ENDPR+7 LABEL TABLE START
FDBBEG EQU * FIRST FLEX FDB
WASN FDB WRKDRV WORK DRIVE
ESCRNT FDB ESCRTN ESCAPE RETURN
INCHRR FDB INCHAR INCH
OTCHRR FDB OUTCHR OUTCH
OTCHR2 FDB OUTCH2 OUTCH2
OTSWTC FDB OUTSWT OUTPUT SWITCH
BUFPTR FDB LNBUFP LINE BUFFER POINTER
TTSDEP FDB TTYDEP TTYSET DEPTH COUNT
TTSWID FDB TTYWID TTYSET WIDTH COUNT
FDBEND EQU * LAST FLEX FDB
ACIA FDB ACIADR PORT ADDR FOR FULL SCREEN

INITZ LDS #MYSTK INIT
 LDX #TEMPS INIT
CLEAR CLR $00,X
 INX
 CPX #ENDALL
 BNE CLEAR
 LDAB INITZ
 CMPB #$10 CHK 6800 VS. 6809
 BNE FIXCD9
 LDX #JMPBEG FIX JUMPS
FIXCD1 CPX #JMPEND CHK FOR END
 BEQ FIXCD2
 LDAA $01,X GET ADDR MSB
 ANDA #$1F FIX IT
 ORAA #$C0
 STAA $01,X PUT IT BACK
 INX
 INX
 INX
 BRA FIXCD1 BACK FOR MORE
FIXCD2 LDX #FDBBEG FIX FDBS
FIXCD3 CPX #FDBEND CHK FOR END
 BEQ FIXCD4
 LDAA $00,X GET ADDR MSB
 ANDA #$1F FIX IT
 ORAA #$C0
 STAA $00,X PUT IT BACK
 INX
 INX
 BRA FIXCD3
FIXCD4 LDAA $00,X CHK PORT ADDR
 CMPA #$80
 BNE FIXCD9
 LDAA #$E0 FIX PORT ADDR
 STAA $00,X
FIXCD9 LDAA #$43 SET 146805 MODEL
 STAA PMODEL
 LDX #$0001 SET CPU TIMER INTERVAL
 STX PTIMER
 LDX #$3FFF SET MAXIMUM MEMORY
 STX MAXMEM
 LDX #TRACEA SET TRACE POINTER
 STX TRACEP
 LDAA #$05 SET 6805 MODE
 STAA PMODE
 LDAA #$0F SET MODE MASK
 STAA MODMSK
 LDX #INTAB5 SET TABLE ADDRESSES
 STX AINTAB
 LDX #OPTAB5
 STX AOPTAB
 LDX #SUFTB5
 STX ASUFTB
 JSR MAPRT FIX ADDRS
 JSR FIXESC FIX ESCAPE ADDR
 INC CONFL SET CRT FLAG
 JSR FMSCLO FORCE FILES CLOSED
 JSR XCRLF PRINT HEADING
 LDX #CLRSCN
 JSR OUTCUR CLEAR THE SCREEN
 LDX #IDLIN
 JSR XPDAT OUTPUT LOGO
 LDAA VN
 ADDA #$30
 JSR XOUTE OUTPUT VERSION
 JSR HELPYU OUTPUT REST OF HEADING

ASKIN LDS #MYSTK LOOK AT INPUT
 JSR ENDE3 RESET FLAGS AND SEND CRLF
 LDX #BEEPS BEEP BELL
 JSR XPDAT
 LDAA #$3F PRINT ?
 JSR XOUTE
ASKIN1 JSR XINEE READ COMMAND
 CMPA #$20 CHK CNTRL CHAR
 BGT ASKIN2
 CMPA #$0D CHK CR
 BNE ASKIN
 TST GETFL CHK GET FLAG
 BNE ASKIN1 IGNORE IF SO
 BRA ASKIN
ASKIN2 LDX #COMAN COMMAND TABLE

 BLT RDJMP
 ANDA #$5F FIX CASE
 STAA COMAND

 BHI RDJMP
 TAB OFFSET
 PSHA
 SUBB #$40
 ASLB
 JSR ADDBX
 PULA
RDJMP LDX $00,X JUMP TO ROUTINE
 JSR $00,X
 BRA ASKIN
