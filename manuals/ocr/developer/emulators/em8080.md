 TTL EM8080
 OPT PAG
 PAG
*
* THIS IS AN 8080 EMULATOR DESIGNED TO RUN
* 8080 CODE ON A 6800 SWTPC COMPATIBLE
* MICROPROCESSOR.
*
* THE ONLY HARDWARE MODIFICATION NECESSARY IS
* TO ENABLE THE ACIA ON THE EMULATED CONTROL
* PORT TO GENERATE AN INTERUPT ON INPUT. THIS
* CAN BE ACCOMPLISHED BY JUMPERING THE "IRQ"
* PAD TO THE "I" PAD ON THE "MP-S" CARD.
*
* THE COMMANDS THAT "EM8080" RECOGNIZES IN THE
* MONITOR MODE AS FOLLOWS:
*
*	AB - SET BREAKPOINT IN EMULATED CODE.
*
*	CB - REMOVE BREAKPOINT SET BY "AB".
*
*	LO - ALOOWS ENTRY OF OCTAL DATA TO MEMORY.
*
*	CR - CLEARS EMULATED REGISTERS.
*
*	RG - DISPLAYS EMULATED REGISTERS.
*
*	SO - ALLOWS SINGLE STEPPING EMULATED CODE.
*
*	SF - TURNS OFF SINGLE STEPPING.
*
*	PC - PERMITS ENTRY OF 8080 PROGRAM COUNTER.
*
*	EO - ENABLES ECHO.
*
*	EF - DISABLES ECHO (NORMAL MODE).
*
*	EX - RETURN TO 6800 MONITOR (OR CNTRL C).
*
*	RU - EXECUTE 8080 CODE (OR SPACE BAR).
*
