* THIS PROGRAM INITIALLY LOADS INTO THE BASIC BUFFER AREA.
* AFTER DETERMINING THE FLEX MEMEND ADDRESS, IT MOVES
* ITSELF TO THE TOP OF MEMORY MINUS 2K FOR ITSELF.	FLEXS'
* MEMEND IS THEN ADJUSTED AND PROGRAM EXECUTION CONTINUES AT
* THE NEW ADDRESS.	UPON EXITING BASIC WITH THE "FLEX" COMMAND,
* THE MEMEND ADDRESS IS RESTORED TO THE ORIGINAL VALUE.
* IF EXITING WITH THE "EXIT" COMMAND, MEMEND IS NOT RE-SET
****************************************************************

* BE OTHER THAN THE ESCAPE CHAR.	RECOMMEND THE DELETE (7F) CHAR
* FOR FLEXS' TTYSET PAUSE.
