*
* THIS ROUTINE TAKES AN ENTRY FROM THE KEYBOARD AND
* STORES IT IN THE RING BUFFER AT THE NEXT AVAILABLE
* LOCATION.
*
PUTCHR	LDB	COUNTR		TEST COUNTER FOR EMPTY
	CMPB	#80
COMMAND BUFFER FULL?
	BEQ	PUT2
YES, SOUND ALARM AND EXIT
	LDX	NXTAVL		LOAD PTR TO NEXT AVAILABLE LOCATION
	TSTB	CHECK FOR OVERRUN
	BEQ	PUT5
ITS OK, BUFFER IS EMPTY
	CMPX	CHRPRT		ARE THEY THE SAME
	BEQ	PUT2
YES, CANNOT ACCEPT CHAR YET
PUT5	LDA	CTLPRT+1	TAKE DATA FROM ACIA DATA BUFFER
*	 ALSO CLEARS INTERRUPT
	STA	,X+
STORE CHARACTER
	LDA	#7

	STA	CTLPRT+1	INDICATE ACCEPTANCE
