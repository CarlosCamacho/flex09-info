EOL EQU $CC02 TTYSET END-OF-LINE CHARACTER
WDRIVE EQU $CC0C WORKING DRIVE NUMBER
DATE EQU $CC0E CURRENT DATE (MONTH-DAY-YEAR)
LASTRM EQU $CC11 LAST NON-ALPHANUMERIC CHARACTER
BUFPNT EQU $CC14 LINE BUFFER POINTER
SCR3D EQU $CC3D SYSTEM SCRATCH
SCR41 EQU $CC41 DITTO
*
WARMS EQU $CD03 FLEX WARM START ENTRY
PUTCHR EQU $CD18 PRINT CHARACTER IN ACCUM. A
PSTRNG EQU $CD1E PRINT STRING POINTED TO BY X
CLASS EQU $CD21 CARRY SET ON RETURN = NOT ALPHANUMERIC
PCRLF EQU $CD24 PRINT CR/LF
NEXTCH EQU $CD27 GET NEXT BUFFER CHARACTER (CLASSIFIED)
GETFIL EQU $CD2D GET FILE SPECIFICATION
OUTDEC EQU $CD39 OUTPUT DECIMAL 2 BYTE NUMBER POINTED TO BY X
OUTHEX EQU $CD3C OUTPUT BYTE POINTED TO BY X
RPTERR EQU $CD3F REPORT DISK ERROR
*
FMS EQU $D406 FILE MANAGEMENT SYSTEM
FCB EQU $C840 SYSTEM FILE CONTROL BLOCK
*

* OUTPUT STRING POINTED TO BY X UNTIL NULL IS FOUND
* MAXIMUM LENGTH IS IN B
PSTRN0 LDA ,X+
 BEQ NULL
 JSR PUTCHR
 DECB
 BNE PSTRN0
NULL CLRB
 RTS

PPAGE LDX #FCB

 STA ,X

 BNE ERRPT
 INC OPEN
NXTLIN JSR PCRLF
NXTENT BSR GETINFO GET NEXT DIRECTORY ENTRY
 BEQ NOERR
 BRA ERRN8
NOERR LDX #FCB

GOTNAM BMI NXTENT DELETED?

 BNE NXTENT
