TTL	RESIDENT BASIC LINE EDITOR

* 8/01/81: LAST REVISION DATE
*
* THIS PROGRAM INITIALLY LOADS INTO THE FLEX TRANSIENT COMMAND
* AREA.	AFTER DETERMINING THE FLEX MEMEND ADDRESS, IT MOVES
* ITSELF DOWN TO THE TOP OF MEMORY MINUS 2K FOR ITSELF.	FLEXS'
* MEMEND IS THEN ADJUSTED AND PROGRAM EXECUTION CONTINUES AT
* THE NEW ADDRESS.	UPON EXITING BASIC WITH THE "FLEX" COMMAND,
* THE MEMEND ADDRESS IS RESTORED TO THE ORIGINAL VALUE.
*
* CONSIDERING THAT THE SEQUENCE OF COMMAND CODES IN THIS PROGRAM
* USE THE ESCAPE CHAR, EITHER THE EDITOR ESCAPE CHARACTER MUST
* BE CHANGED TO ANOTHER OR THE FLEX TTYSET PAUSE CHARACTER MUST
* BE OTHER THAN THE ESCAPE CHAR.	RECOMMEND THE DELETE (7F) CHAR
* FOR FLEXS' TTYSET PAUSE.
