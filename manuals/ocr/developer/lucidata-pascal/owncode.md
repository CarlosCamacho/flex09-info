NAM OWNCODE
 TTL OWNCODE.TXT	V 2.2
*
* EXAMPLE OF INTERFACING A USER FUNCTION
* TO THE P-6800 RUN TIME SYSTEM
* COPYRIGHT C 1980 LUCIDATA
* NIGEL W.BENNEE JAN 1980
* RELEASED 31 JAN 80
* UPDATE 20 JUL 80 2.2:3
*
 OPT PAG
*
MARKUS EQU $146
USRENT EQU $144
CMDUTL EQU $A5E1
EXITE EQU $152
*
* THIS USER FUNCTION EXPECTS TO FIND ON TOP OF THE STACK
*
* AN INTEGER B	(TWO BYTES)
* AN OP CODE X	(ONE BYTE )
* AN INTEGER C	(TWO BYTES)
*
* IT WILL PERFORM BIT LOGICAL OPERATIONS AS FOLLOWS
*
* A := B OR	C IF X=1
* A := B AND C IF X=2
* A := B XOR C IF X=3 AND CALL THE ERROR MESSAGE 19
*	ON DISK FOR ANY OTHER VALUE OF X
*
* A WILL BE RETURNED AS THE RESULT
*
* IT IS LOCATED IN THE FEW BYTES IN THE CMD SPACE
*
 ORG CMDUTL
START EQU *
 LDX MARKUS GET OUR BIT OF STACK
 LDA A 10,X GET OPCODE
 CMP A #1 IS IT OR
 BEQ BOR YES
 CMP A #2 IS IT AND
 BEQ BAND YES
 CMP A #3 IS IT XOR
 BEQ BXOR YES
 LDA B #19 IS AN UNDEFINED ERROR CODE NOT USED BY RUN
 JMP EXITE
*
BOR EQU *
 LDA A 8,X MSB B
 LDA B 9,X LSB B
 ORA A 11,X
 ORA B 12,X
 BRA RETURN
*
BAND EQU *
 LDA A 8,X
 LDA B 9,X
 AND A 11,X
 AND B 12,X
 BRA RETURN
*
BXOR EQU *
 LDA A 8,X
 LDA B 9,X
 EOR A 11,X
 EOR B 12,X
RETURN EQU *
 STA A 0,X STORE RESULT
 STA B 1,X
 RTS
*
* NOW MAKE LINK
*
 ORG USRENT
 FDB START
*
 END
