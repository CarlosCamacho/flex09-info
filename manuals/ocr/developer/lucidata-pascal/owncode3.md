NAM OWNCODE
 TTL OWNCODE.TXT	V 3.X:1
*
* EXAMPLE OF INTERFACING AN EXTERNAL
* FUNCTION TO THE P-6800 RUN TIME SYSTEM
* COPYRIGHT C 1980 LUCIDATA
* NIGEL W.BENNEE JAN 1980
* UPDATED FOR 3.X:1 MAR 81
*
 OPT PAG
*
 LIB RUNEQU3.TXT P-6800 SYMBOL DEFINITIONS
*
* THIS FUNCTION EXPECTS TO FIND ON TOP OF THE STACK
*
* AN INTEGER B	(TWO BYTES)
* AN OP CODE X	(ONE BYTE )
* AN INTEGER C	(TWO BYTES)
*
* IT WILL PERFORM BIT LOGICAL OPERATIONS AS FOLLOWS
*
* A := B OR	C IF X=1
* A := B AND C IF X=2
* A := B XOR C IF X=3 AND CALL THE ERROR MESSAGE 19
*	ON DISK FOR ANY OTHER VALUE OF X
*
* A WILL BE RETURNED AS THE RESULT
*
 ORG CMDEND
START EQU *
 LDX MARKUS GET OUR BIT OF STACK
 LDA A 8,X GET OPCODE (IT HAS ACTUALLY BEEN PASSED IN B ALSO)
 CMP A #1 IS IT OR
 BEQ BOR YES
 CMP A #2 IS IT AND
 BEQ BAND YES
 CMP A #3 IS IT XOR
 BEQ BXOR YES
 LDA B #19 IS AN UNDEFINED ERROR CODE NOT USED BY RUN
 JMP EXITE
*
BOR EQU *
 LDA A 6,X MSB B
 LDA B 7,X LSB B
 ORA A 9,X
 ORA B 10,X
 BRA RETURN
*
BAND EQU *
 LDA A 6,X
 LDA B 7,X
 AND A 9,X
 AND B 10,X
 BRA RETURN
*
BXOR EQU *
 LDA A 6,X
 LDA B 7,X
 EOR A 9,X
 EOR B 10,X
RETURN EQU *
 DEX
 DEX RESULT BELOW MARKUS
 STA A 0,X STORE RESULT
 STA B 1,X
 RTS
*
 END
