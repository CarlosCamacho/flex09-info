# UPDATE

_OCR transcription from: `Screenshot_20260912-071603.png`_

UPDATE

The UPDATE utility enables the user to change the date in a file"
directory entry to the "current date".
## Description
The general syntax of the UPDATE command is:

UPDATE,<filespec>
Where <filespec> is the name of the file for which the date is to b
changed. If the file extension is not specified, UPDATE defaults to a
extension of .TXT . The file's directory entry is changed to reflec
the current date. UPDATE does not alter the contents of the fil
itself.
