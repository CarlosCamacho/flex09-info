 At this point, you have learned just about everything that we can teach you in a
 reasonable  space  about  SCREDITOR  III  other  than  the  COMMANDS  which  are
 associated with printing and final page formatting. Another review  here  should
 be  of  help.  If  you don't remember any of the following material, go back and
 re-read the chapters of the manual associated with the point about which you are
 hazy.


 1) You have learned about the visual display of  SCREDITOR  III  and  what  each
    section tells you and its use.


 2) You have learned how to create and edit a document,  and  how  to  abort  and
    close (log) an edit session.


 3) Those of you who are OS-9 users have learned how  to  make  system  calls  to
    allow  you to do, for instance, a directory listing, as well as how to modify
    SCREDITOR III's memory allocation.


 4) You have learned how to make basic changes to your document.


 5) You have learned almost all of the MODES of SCREDITOR III, as follows:

    COMMAND MODE                 MULTI-COLUMN MODE
    LINE EDIT MODE               JUSTIFICATION MODES
    TEXT EDIT MODE               ACTIVE SYMBOL MODE


 6) You have learned all of SCREDITOR III's OPERATORS:

    ^AS - ACTIVATE SYMBOL        ^MP - MELD PARAGRAPH
    ^BS - DESTRUCTIVE BACKSPACE  ^NL - NEW LINE
    ^CD - CURSOR DOWN            ^PD - PAGE DOWN
    ^CL - CURSOR LEFT            ^PU - PAGE UP
    ^CR - CURSOR RIGHT           ^SD - SCROLL DOWN
    ^CU - CURSOR UP              ^SP - SPLIT PARAGRAPH
    ^DC - DELETE CHARACTER       ^SU - SCROLL UP
    ^DL - DELETE LINE            ^TE - TAB TO END OF LINE
    ^DM - DELETE TO MARGIN       ^TL - TAB LEFT
    ^DW - DELETE WORD            ^TM - TAB TO MARGIN
    ^ES - ESCAPE                 ^TN - TAB TO NEXT WORD
    ^GM - GOTO MARK              ^TP - TAB TO PREVIOUS WORD
    ^IC - INSERT CHARACTER MODE  ^TR - TAB RIGHT
    ^IL - INSERT LINE MODE       ^TS - TAB SET/CLEAR
    ^IS - INSERT SPACE           ^UC - CONVERT TO UPPER CASE
    ^LC - CONVERT TO LOWER CASE


 7) You have learned about the following COMMANDS:

    AB - ABORT EDIT SESSION      NS - NEW SCREEN
    BO - BOTTOM OF BUFFER        NU - NUMBERS ON/OFF
    CH - CHANGE STRINGS          OD - DELETE FILE
    CM - CLEAR MARKS             OL - LIST DISK DIRECTORY
    CO - COPY LINES              OO - OPEN OUTPUT FILE
    CT - CLEAR TABS              OR - OPEN READ-IN FILE
    DS - DEFINE SYMBOL           OS - OS-9 SHELL CALL
    EX - EXIT TO SYSTEM MONITOR  OV - VIEW A FILE
    FI - FIND STRINGS            OW - OPEN A WRITE-OUT FILE
    GO - GOTO LINE               PA - PAGE FLAGS ON/OFF
    GP - GOTO PAGE               PI - PARAGRAPH INDENT
    HR - HELP REQUEST            PL - PACK LINE
    ID - INSERT NUMBER DISPLAY   PP - PACK PARAGRAPH
    JL - JUSTIFY LINE            RI - READ-IN
    JM - JUSTIFY MODE            RM - RIGHT MARGIN
    JP - JUSTIFY PARAGRAPH       RS - READ-IN SKIP LINES
    KL - KILL LINES              SA - SAVE LINES
    LE - LINE EDIT MODE          SM - SET MARK
    LI - LINE INDENT             SS - SAVE SYMBOLS
    LM - LEFT MARGIN             ST - SET TABS
    LO - LOG EDIT SESSION        TA - TALLY
    LS - LOAD SYMBOLS            TE - TEXT EDIT MODE
    MC - MULTI-COLUMN MODE       TO - MOVE TO TOP OF BUFFER
    MO - MOVE LINES              WC - WRITE-OUT COPY
    NE - NEW BLOCK               WE - WRITE-OUT EXTRACT


 The next chapters in this manual will teach you  about  final  page  formatting,
 printing, and the print-merge capabilities of SCREDITOR III.
