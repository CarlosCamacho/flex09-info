LOAD AND SAVE

LOAD AND SAVE IS A WORKING FUNCTION OF THE COMPUTER PROGRAM.	THIS
FUNCTIONN IS USED IN CONNECTION WITH THE OTHER FUNCTIONS OF THIS
PROGRAM.	THE PRIMARY FUNCTION OF THE LOAD AND SAVE FUNCTION IS TO
SAVE THE DATA ON YOUR DATA DISKS AND TO CALL FORTH DATA STORED ON
THE DISKS.
	1.	LOAD RECORD FROM LAST MONTH - THIS COMMAND CODE IS USED
IN CONJUNCTION WITH THE SAVE DATA THIS MONTH COMMAND IN ORDER TO
CALL FORTH THE DATA (RECORD) FROM THE PRIOR MONTH FOR THE MAKING
OF A NEW RECORD FOR THE CURRENT MONTH FOR THE PURPOSE OF MAKING
STATEMENTS AND TRIAL BALANCE.
	2.	LOAD DATA THIS MONTH - THIS COMMAND IS USED TO CALL FORTH
DATA FOR A GIVEN MONTH.	IT IS MOST COMMONLY USED IN THE CASE WHERE
YOU ARE LOOKING FOR SPECIFIC INFORMATION CONTAINED IN A GIVEN MONTH.
	3.	SAVE RECORD THIS MONTH - THIS COMMAND IS USED AFTER RUN-
NING YOUR TRIAL BALANCE FOR A GIVEN MONTH TO STORE THE DATA CON-
TAINED IN THE JOURNALS.	THIS COMMAND IS USED ONLY AFTER YOU HAVE
STORED YOUR DATA FOR THE GIVEN MONTH AND LOADED THE RECORD FROM
THE PRIOR MONTH.
	4.	SAVE DATA THIS MONTH - TTHIS COMMAND IS USED IMMEDIATELY
AFTER YOU HAVE FINISHED INPUTTING YOUR DATA FOR A GIVEN MONTH.
THIS COMMAND STORES YOUR DATA ON THE DISK AND ALLOWS YOU TO COR-
RECT OR USE THE DATA WITHOUT HAVING TO RE-INPUT.
	5.	DELETE RECORD THIS MONTH - THIS COMMAND IS USED IN CON-
NECTION WITH THE EDIT FUNCTION.	THIS COMMAND ALLOWS YOU TO RE-
MOVE A GIVEN RECORD FROM THE DATA DISK.	YOU CAN NOT RECALL THE
RECORD ONCE IT HAS BEEN REMOVED FROM THE DISK.
	6.	DELETE DATA THIS MONTH - THIS IS THE COMMAND MOST FRE-
QUENTLY USED IN CONNECTION WITH YOUR EDIT FUNCTION.	THIS COMMAND
ALLOWS YOU TO DELETE THE DAA CONTAINED ON THE DISK AND TO RESAVE
THE DATA (USING COMMAND 4) WHICH YOU HAVE CORRECTED FOR THE GIVEN
MONTH USINNG THE EDIT FUNCTION.
	7.	COPYNEW TO BACKUP DISC - THIS COMMAND ALLOWS YOU TO COPY
ADDED DATA FROM THE DATA DISK TO A BACKUP DISK.
	8.	LIST CATALOGUE OF FILES - THIS COMMAND SIMPLY LISTS THE
FILES STORED ON THE DATA DISK.
	9.	RETURN TO COMMAND - THIS COMMAND EXITS THE LOAD AND SAVE
FUNCTION AND RETURNS YOU TO THE MENU OF FUNCTION COMMANDS.
	10.	MAKE DATA DISK - THIS IS THE COMMAND WHICH YOU USE WHEN
YOU ARE SETTING UP DATA DISKS FOR A GIVEN CLIENT.	THIS COMMAND
TELLS THE COMPUTER TO FORMAT A BLANK DISK AND SET IT UP FOR RE-
CEIVING DATA.
	11.	LOAD RECORD 00 - THIS COMMAND TELLS THE COMPUTER TO LOAD
THE RECORD CONTAINNG THE BEGINNING BALANCES FOR A GIVEN CLIENT FOR
A GIVEN YEAR.	THIS COMMAND IS USED INSTEAD OF THE "1" COMMAND WHEN
YOU ARE AT THE BEGINNING OF A CLIENT'S FISCAL YEAR.
