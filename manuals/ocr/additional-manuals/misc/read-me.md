June 4, 1982

This disk contains the 6809 FLEX User's Manual and 6809 FLEX
Advanced Programmer's Guide.  The files associated with the
User's Manual begin with the letters "UM", while those of the
Advanced Programmer's Guide begin with "APG".

The User's Manual is contained in the six files UM1 thru UM6
and should be processed with the macro file named "UM-MAC".
The command line would be:
    +++PR UM-MAC UM1 UM2 UM3 UM4 UM5 UM6
There is a separate preface ("UM-PREF") which contains its own
macros and should be processed separately.

The Advanced Programmer's Guide is contained in the four files
APG1 thru APG4 and should be processed with the macro file
named "APG-MAC".  The command line would be:
    +++PR APG-MAC APG1 APG2 APG3 APG4
Again, there is a separate preface ("APG-PREF") which contains
its own macros and should be processed separately.
