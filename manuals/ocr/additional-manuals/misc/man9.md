PRINT CHART OF ACCOUNTS

THIS FUNCTION COMMAND SIMPLY ALLOWS YOU TO PRINT OUT A	
CHART OF ACCOUNTS FOR A GIVEN CLIENT AT ANY TIME.


SPECIAL

THIS FUNCTION COMMAND MAY BE USED TO CALL FORTH A SPECIAL
FUNCTION WHICH HAS BEEN SET UP IN THIS AREA OF THE COMPUTERS
MEMORY.	(OPTIONAL).	THIS FUNCTION MAY CHANGE FROM PROGRAM TO
PROGRAM.


EXIT TO MONITOR

THIS COMMAND FUNCTION RETURNS YOU TO THE BEGINNING POINT OR THE
"BOOT UP" POINT.	YOU MAY USE THIS FUNCTION TO CHANGE FROM ONE
PROGRAM DISK TO ANOTHER OR TO CHANGE FROM CLIENT TO CLIENT.	TO
BOOT UP THE MACHINE SIMPLY TYPE "Z".	THIS COMMAND MAY ALSO BE
USED WHEN ENTERING DATA FOR MORE THAN ONE MONTH AT A TIME.	AFTER
YOU HAVE FINISHED WITH AN ENTIRE MONTH OF DATA, EXIT TO MONITOR
AND REBOOT THE COMPUTER AND ENTER THE DATA FOR THE NEXT MONTH.


EXIT TO FLEX

THIS FUNCTION COMMAND RETURNS YOU FROM OUR ACCOUNTING PROGRAM
TO THE MACHINE LANGUAGE OR PROGRAM OF FLEX.	+++ WILL APPEAR ON
THE SCREEN.	YOU MUST THEN USE THE UTILITY COMMANDS PROVIDED IN
THE FLEX SYSTEM SECTION OF THE MANUAL.
