TRIAL BALANCE

THIS FUNCTION CODE SIMPLY TELLS THE COMPUTER TO PRINT THE TRIAL
BALANCE FOR A GIVEN CLIENT FOR A GIVEN PERIOD OF TIME.	THIS
COMMAND IS USED IN CONJUNCTION WITH THE "LOAD RECORD AND SAVE
DATA" FUNCTIONS OF LOAD AND SAVE.


PRINT JOURNALS

THIS FUNCTION TELLS THE COMPUTER TO PRINT THE JOURNALS FOR A
GIVEN CLIENT.	BY CALLING FORTH THIS FUNCTION, YOU ARE GIVEN A
MENU OF JOURNALS.	YOU MAY PRINT ANY COMBINATION OF THE JOURNALS.
THE COMPUTER WILL RETURN TO THIS MENU AFTER PRINTING EACH
JOURNAL.

	1.	DISBURSEMENT JOURNAL-PRINTS CASH DISBURSEMENTS
	2.	CASH RECEIPTS - PRINTS CASH RECEIPTS
	3.	SALES JOURNAL - PRINTS SALES JOURNAL
	4.	PURCHASE JOURNAL - PRINTS PURCHASE JOURNAL
	5.	PAYROLL JOURNAL - PRINTS PAYROLL JOURNAL
	6.	GENERAL JOURNAL - PRINTS GENERAL JOURNAL
	7.	GENERAL LEDGER - PRINTS GENERAL LEDGER FOR THE MONTH
	8.	BALANCE SHEET & OPERATING STATEMENT - PRINTS THE BALANCE
	SHEET AND PROFIT AND LOSS STATEMENT FOR A GIVEN
	MONTH. (P/L ALSO YEAR TO DATE)
	9.	RETURN - RETURNS YOU TO THE FUNCTION COMMAND CODE MENU.
	10.	PRINT ALL JOURNALS - THIS IS THE COMMAND WHICH YOU
	SET UP FOR EACH CLIENT AT THE TIME OF SETTING UP
	THE CHART OF ACCOUNTS.	THIS COMMAND WILL PRINT ALL
	OF THE JOURNALS WHICH YOU LISTED AT THE TIME OF
	SET UP (IN THE ORDER IN WHICH YOU ENTERED THEM AT
	THAT TIME).
