 Up to this point, you have learned quite a bit about  SCREDITOR  III.  A  little
 review  at  this  point  might  help. If you don't remember any of the following
 material, go back and re-read the chapters of the  manual  associated  with  the
 point about which you are hazy.

 1) You  have  learned  about  the  visual display of SCREDITOR III and what each
    section tells you and its use.

 2) You have learned how to create and edit a document, and how to abort and edit
    session.

 3) Those  of  you  who  are  OS-9 users have learned how to make system calls to
    allow you to do, for instance, a directory listing, as well as how to  modify
    SCREDITOR III's memory allocation.

 4) You have learned how to make basic changes to your document.

 5) You have learned the following OPERATORS:


    ^BS - DESTRUCTIVE BACKSPACE  ^IC - INSERT CHARACTER MODE
    ^CD - CURSOR DOWN            ^IS - INSERT SPACE
    ^CL - CURSOR LEFT            ^IL - INSERT LINE MODE
    ^CR - CURSOR RIGHT           ^NL - NEW LINE
    ^CU - CURSOR UP              ^TE - TAB TO END OF LINE
    ^DC - DELETE CHARACTER       ^TL - TAB LEFT
    ^DL - DELETE LINE            ^TM - TAB TO MARGIN
    ^DM - DELETE TO MARGIN       ^TN - TAB TO NEXT WORD
    ^DW - DELETE WORD            ^TP - TAB TO PREVIOUS WORD
    ^ES - ESCAPE                 ^TR - TAB RIGHT


 6) You have learned something about the following COMMANDS (you'll  be  learning
    more later):


    AB - ABORT EDIT SESSION      OS - OS-9 SHELL CALL
    LE - LINE EDIT MODE          TE - TEXT EDIT MODE
    LO - LOG EDIT SESSION


 The  next  chapters in this manual will teach you even more about the wide range
 of capabilities of SCREDITOR III Word Processing.
