		THE "B MACHINE" COMPUTER CONSISTS OF THE FOLLOWING PARTS;

		1. MAINFRAME	(HOUSING, POWER SUPPLY, CPU, MEMORY & I/O)
		2. FLOPPY DISK DRIVES (MAY BE IN MAINFRAME)
		3. TERMINAL W/ KEYBOARD
		4. PRINTER

		THE GENERAL BUSINESS SYSTEM (GBS) PROGRAM PACKAGE IS A LARGE
	ASSORTMENT OF PROGRAMS WHICH HAVE BE SELECTED TO WORK TOGETHER
	TO PRODUCE THE DESIRED RESULTS.	THE COMMON ELEMENT TO ALL OF
	THESE ROUTINES IS THE "BBUG" ROM WHICH CONTAINES THE SUBROUTINES
	NECESSARY TO DO THE MATH, CONTROL THE TERMINAL, OPERATE THE
	PRINTER AND MANIPULATE DATA IN MEMORY AND TO THE DISKS. THERE
	ARE SEVERAL MAJOR CATAGORIES WHICH ARE LISTED AS FOLLOWS;

		1. INVOICING
		2. ACCOUNTS RECEIVABLE
		3. ACCOUNTS PAYABLE
		4. PAYROLL
		5. GENERAL LEDGER
		6. INVENTORY

		THE (GBS) CAN BE CONSIDERED AS A FUNNEL WHICH COLLECTS ALL
	TYPES OF INFORMATION, PROCESSES AND CONCENTRATES IT AND THEN
	PASSES IT TO OTHER PROGRAMS WHICH COMBINE AND FURTHER CONCEN-
	TRATE IT AND PRODUCE REPORTS WHICH REFLECT THE STATUS OF THE
	PHYSICAL AND ECCONOMIC HEALTH OF THE BUSINESS.

		IN ADDITION THERE IS A DISK OPERATING SYSTEM (D0S) WHICH DOES
	ALL THE FUNCTIONS NECESSARY TO KEEP TRACK OF THE DATA ON THE DISKS,
	LOAD AND STORE THE DATA FILES AND FORMATT NEW DISKS.

		A MONITOR IS ALSO AVAILABLE TO START THE COMPUTER FROM AN OFF
	CONDITION, TO LOAD THE D0S AND HANDLE SOME ERROR CONDITIONS.

		ALL OF THESE PROGRAMS HAVE BEEN WRITTEN IN THE MACHINE LANGUAGE
	OF THE 6809 MICROPROCESSOR, THIS HAS BEEN DONE TO INSURE FAST
	OPERATION, EFFICIENT MEMORY MANAGEMENT AND THE IMPLEMENTATION OF
	FUNCTIONS NOT OTHERWISE AVAILABLE.	THERE ARE SOME DISADVANTAGES
	TO THIS APPROACH, (GBS) CAN ONLY WORK ON THE EXACT MACHINE FOR WHICH
	IT WAS WRITTEN, AND IT IS VERY DIFICULT TO CHANGE OR ADD NEW FEATURES
	AFTER FINALIZATION.	WE HOPE THAT THE (GBS) IS FLEXIBLE ENOUGH
	TO ADAPT TO YOUR OFFICE PROCEDURES; HOWEVER IT IS ONLY REASONABLE
	TO EXPECT TO MAKE SOME CHANGES TO YOUR WAY OF DOING THINGS.
