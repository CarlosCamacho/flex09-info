MASTER SYSTEM DISK

WHEN SETTING UP A COMPUTER SYSTEM, YOU WILL HAVE AT YOUR DISPOSAL
ONE (1) MASTER SYSTEM DISK.	THIS IS THE DISK PROVIDED BY US WITH
YOUR COMPUTER SYSTEM. (NOT A PROGRAM DISK)

THIS MASTER SYSTEM DISK SHOULD BE USED TO FORMAT YOUR SYSTEM DISKS
AND IN MAKING PROGRAM DISKS FOR EACH CLIENT OR APPLICATION

THE MASTER DISK SHOULD BE RETAINED IN A SEPARATE PLACE FROM YOUR
OTHER SYSTEM, PROGRAM AND DATA DISKS.

DISKS MAY BE USED TIME AND AGAIN.	TO REUSE A DISK, YOU SHOULD
REFORMAT THE DISK USING YOUR MASTER SYSTEM DISK.	THIS WILL BE
DISCUSSED IN THE SECTION ON FORMATTING.

WRITE PROTECT

IT IS POSSIBLE TO WRITE PROTECT A DISK (MAKE IT IMPOSSIBLE FOR
TTHE SYSTEM TO WRITE ON THE DISK) BY PLACING A PIECE OF TAPE OVER
THE SMALL RECTANGULAR CUTOUT ON THE EDGE OF THE DISK.	ANY ATTEMPTS
TTO WRITE FILES OR DELETE FILES ON A PROTECTED DISK WILL CAUSE AN	
ERROR MESSAGE TO BE ISSUED.	IT IS GOOD PRACTICE TO WRITE PROTECT
DISKS WITH IMPORTANT FILES ON THEM.


RESET

THE RESET BUTTON ON THE FRONT PANEL OF YOUR COMPUTER SHOULD NEVER
BE PRESSED DURING A DISK OPERATION.	THERE SHOULD NEVER BE A REASON
TTO "RESET" THE MACHINE WHILE IN FLEX.	IF THE MACHINE IS "RESET"
AND THE SYSTEM IS WRITING DATA ON A DISK, IT IS POSSIBLE THAT THE
ENTIRE DISK WILL BECOME DAMAGED.	NEVER PRESS THE RESET WHILE THE
DISK IS IN OPERATION.


FORMATTING A DISK
	1.	POWER UP THE MACHINE
	2.	INSERT YOUR MASTER SYSTEM DISK INTO DRIVE 0
	3.	INSERT A NEW, BLANK DISK INTO DRIVE 1
	4.	CLOSE DRIVE DOORS
	5.	BOOT UP THE COMPUTER: TYPE "Z"	
	FLEX 1.0 WILL APPEAR ON SCREEN
	NOTE THERE WILL APPEAR ON SCREEN
	+++ WILL APPEAR ON SCREEN
	6.	TYPE "NEW DISK" - CARRIAGE RETURN
	SCRATCH DISK IN DRIVE 0? WILL APPEAR ON SCREEN
	7.	REMOVE MASTER DISK FROM DRIVE 0 AND REPLACE WITH THE
		BLANK DISK FROM DRIVE 1.	TYPE "Y".
		THE COMPUTER WILL NOW FORMAT THE BLANK DISK INTO A DISK
		WHICH MAY BE USED TO PERFORM COMPUTER OPERATIONS.
	FORMATTING COMPLETE WILL APPEAR ON SCREEN
	+++ WILL APPEAR ON SCREEN
	8.	YOU SHOULD PERFORM THIS OPERATION FROM STEP 7 FOR ALL
		OF THE BLANK DISKS YOU PURCHASE.	THIS SETS THEM UP SO
		THAT THEY MAY BE USED WITHIN OUR COMPUTER SYSTEM.
	9.	WHEN ALL OF YOUR BLANK DISKS HAVE BEEN FORMATTED, PLACE
		THE MASTER DISK INTO DRIVE 0 AND A BLANK FORMATTED DISK
		INTO DRIVE 1.
	10.	TYPE "BACKUP 0,1" - CARRIAGE RETURN
		DOING BACKUP SHOULD APPEAR ON SCREEN
		THIS TELLS US THAT THE COMPUTER IS TAKING THE DATA FROM
		YOUR MASTER SYSTEM DISK AND PRINTING IT ONTO THE BLANK
		DISK.
	BACKUP COMPLETE SHOULD APPEAR ON SCREEN
		THIS TELLS YOU THAT ALL OF THE INFORMATION FROM THE MASTER
		SYSTEM DISK HAS BEEN COPIED ONTO THE BLANK.
	+++ WILL APPEAR ON SCREEN.
	11.	YOU NOW HAVE A SYSTEM DISK IN DRIVE 1.
		REMOVE DISK FROM DRIVE 1.
	12.	REPEAT FROM STEP 10 FOR THE NUMBER OF SYSTEM DISKS WHICH
		YOU REQUIRE AT ANY GIVEN TIME.
	13.	WHEN YOU HAVE SET UP THE REQUIRED NUMBER OF SYSTEM DISKS,
		REMOVE THE MASTER SYSTEM DISK FROM DRIVE 0.
	14.	STORE YOUR SYSTEM DISKS TOGETHER.	YOU NOW HAVE FORMATTED
		SYSTEM DISKS READY FOR SETTING UP PROGRAM DISKS FOR IN-
		DIVIDUAL CLIENTS.


SET UP OF NEW CLIENT

EACH CLIENT SHOULD HAVE TWO "PROGRAM DISKS", A PRIMARY AND A
BACKUP, AND THE DATA DISKS CONTAINING THEIR INPUT INFORMATION.

PROGRAM AND DATA DISKS SHOULD BE KEPT TOGETHER BY CLIENT.

A STANDARD CHART OF ACCOUNTS HAS BEEN SET UP CONTAINING THOSE
ACCOUNTS MOST COMMONLY USED FROM CLIENT TO CLIENT.	THIS IS ONLY
A GUIDE AND MAY BE MODIFIED TO FIT INDIVIDUAL NEEDS AND REQUIRE-
MENTS OR DISCARDED ALTOGETHER.
	1.	DETERMINE THE CHART OF ACCOUNTS FOR YOUR PARTICULAR
		CLIENT.
	2.	FORMAT YOUR DISKS AND DETERMINE YOUR OPENING FIGURES
		FOR THE APPROPRIATE TIME PERIOD.
	3.	YOU MAY USE THE PAYROLL RECORD AND THE CLIENT SET-UP
		FORMS (GUIDE) IN HELPING YOU TO SET UP THE CLIENT.
	4.	MAKE CHART OF ACCOUNTS. (SEE SECTION OF THIS MANUAL
		UNDER THIS HEADING).
	5.	MAKE DATA DISK - LABEL	(SEE APPROPRIATE SECTION)
	6.	INPUT DATA - BEGINNING BALANCES OR IF IN THE MIDDLE
		OF THE YEAR, PREVIOUS MONTHS' YEAR-TO-DATA TOTALS.
		(RECORD 00 OR RECORD XX WHERE X= MONTH OF DATA.)
