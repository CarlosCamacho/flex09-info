EDIT DATA

WHEN YOU HAVE FINISHED INPUTTING YOUR DATA FOR A GIVEN MONTH,
YOU SHOULD SAVE THE DATA WHETHER IT IS CORRECT OR NOT.	THE EDIT
DATA FUNCTION GIVES YOU THE OPPORTUNITY TO CORRECT DATA OR TO CHECK
YOUR DATA TO BE SURE THAT THE DATA ENTERED IS THE CORRECT DATA.

	1.	PRESS COMMAND CODE "5"	EDIT DATA
	2.	THE MACHINE WILL ASK YOU FOR A REFERENCE NUMBER.
		A.	IF YOU HAVE A SPECIFIC REFERENCE NUMBER WHICH YOU

WISH TO CHECK, YOU SHOULD SIMPLY ENTER THE REFERENCE

NUMBER IN QUESTION.
		B.	IF YOU WISH TO REVIEW ALL OF THE INPUT, ENTER YOUR

FIRST REFERENCE NUMBER.
	3.	TO REVIEW DATA SIMPLY PRESS THE SPACE BAR.	THE MACHINE	
		WILL AUTOMATICALLY SWITCH FROM ONE REFERENCE NUMBER TO
		ANOTHER.	PRESS THE SPACE BAR BETWEEN REFERENCE NUMBERS
		TO CONTINUE REVIEW.
	4.	IF YOU COME TO A REFERENCE NUMBER WHICH YOU WISH TO CHANGE
		OR CORRECT:
		A.	ENTER REFERENCE NUMBER
		B.	ENTER CORRECT JOURNAL NUMBER
		C.	ENTER CORRECT ACCOUNT NUMBER
		D.	ENTER CORRECT PAYEE
		E.	ENTER CORRECT AMOUNT
		DO THE ABOVE PROCEDURE FOR ANY REFERENCE NUMBERS WHICH YOU
		ARE CORRECTING. AFTER YU HAVE CORRECTED ANY REFERENCE
		NUMBER, THE COMPUTER WILL AUTOMATTICALLY RETURN YOU TO THE
		FUNCTION CODE MENU.	IF YOU HAVE MORE THAN ONE REFERENCE
		NUMBER TO CORRECT, YOU SHOULD RETURN TO THE EDIT FUNCTION
		BY PRESSING "5" AND REPEATING THE ABOVE PROCESS (SEE INS.
		2)

WHEN ALL OF THE DATA HAS BEEN CORRECTED TO THE BEST OF YOUR KNOW-
LEDGE:
	A.	RETURN TO THE LOAD AND SAVE FUNCTION
	B.	IF YOU HAVE SAVED THE DAA PRIOR TO THE EDITING, YOU SHOULD
		NOW DELETE THE DATA FOR THIS MONTH (6).	THE COMPUTER WILL
		RESPOND "DELETE 1.DATA(XX).BIN?"	YOU SHOULD TYPE "Y" SPACE
		BAR.	THE COMPUTER WILL RETURN "ARE YOU SURE?"	TYPE "Y" IF
		YOU ARE SURE THE DATA IS WHAT YOU WISH TO DELETE.	THE COM-
		PUTER WILL PERFORM THIS FUNCTION AND RETURN YOU TO THE LOAD
		AND SAVE FUNCTION MENU.
	C.	YOU SHOULD NOW PRESS THE LOAD AND SAVE FUNCTION "4"	SAVE
		THE DATA THIS MONTH.	THIS WILL SAVE THE CORRECTED DATA.
		WHEN THIS FUNCTION IS COMPLETED THE COMPUTER WILL RETURN YOU
		TO THE MENU.
	D.	YOU SHOULD NOW PRESS "9"	RETURN TO COMMAND AND WHEN THE
		FUNCTION MENU APPEARS, YOU SHOULD PRESS "3".	THE MACHINE
		WILL THEN GIVE YOU A PRINT OUT OF THE CORRECT TRIAL BALANCE
		FOR ONLY THE DATA ENTERED FOR THE MONTH.
	E.	IF THE TRIAL BALANCE GIVEN ABOVE IS IN BALANCE AND CORRECT
		TO YOUR KNOWLEDGE, RETURN TO THE LOAD AND SAVE FUNCTION AND
		PRESS "1"	LOAD RECORD LAST MONTH.	THE MACHINE WILL PER-
		FORM THIS FUNCTION AND RETURN TO THE LOAD AND SAVE MENU.
		PRESS "9" TO RETURN TO THE CONTROL CODES AND AGAIN PRESS
		"3" FOR A TRIAL BALANCE.	THIS SHOULD GIVE YOU A PRINT
		OUT OF THE CORRECT YEAR TO DATE TRIAL BALANCE.
	F.	IF THE TRIAL BALANCE (YEAR TO DATE) IS CORRECT, YOU SHOULD
		NOW SAVE THE RECORD FOR THIS MONTH. (LOAD AND SAVE FUNCTION
		#3) AND PRINT YOUR JOURNALS.
	G.	IF THE DATA IS STILL INCORRECT, SIMPLY REPEAT THE EDIT	
		FUNCTION UNTIL THE DATA IS CORRECT.

NOTE:
	IF YOU WISH TO ADD DATA TO A DATA FILE, USE YOUR EDIT FUN-
	CTION TO PERFORM THIS FUNCTION.

1.	PRESS COMMAND CODE "5"	EDIT DATA

2.	ENTER A REFERENCE NUMBER NOT PREVIOUSLY USED.

3.	COMPUTER WILL RESPOND:	NOT FOUND - ADD DATA Y/N

4.	ENTER Y, REFERENCE NUMBER, JOURNAL NUMBER, ACCOUNT
	NUMBER, PAYEE, AND AMOUNT.

5.	THE COMPUTER WILL RETURN TO THE ORIGINAL COMMAND
	CODES.	PRESS EDIT DATA AND ENTER THE REFERENCE
	NUMBER OF THE ENTRY YOU JUST MADE.	THE MACHINE SHOULD
	SHOW YOU THE ENTTRY.

6.	YOU SHOULD NOW SAVE THE CORRECTED DATA AS EXPLAINED IN
	THE ABOVE SECTION.
