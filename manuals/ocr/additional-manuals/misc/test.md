	A. WHAT TO DO BEFORE THE COMPUTER ARRIVES.

		THERE ARE A NUMBER OF THINGS THAT CAN BE DONE BEFORE THE
	COMPUTER IS INSTALLED.	YOU SHOULD REVIEW YOUR CUSTOMER AND
	VENDOR LISTS, ELIMINATING INACTIVE ENTRIES, CHECKING THAT
	ADDRESS, ZIP CODES ETC ARE UP TO DATE.	EMPLOYEE RECORDS
	SHOULD BE CHECKED FOR SOCIAL SECURITY #, PROPER DEDUCTIONS,
	ADDRESS, ETC.	ALL EMPLOYESS WHO HAVE RECEIVED PAY DURING
	THIS YEAR SHOULD HAVE THEIR RECORDS IN THE COMPUTER.

		ALL ITEMS THAT YOU STOCK FOR SALE SHOULD BE LISTED, OFFICE
	SUPPLIES, CLEANING MATERIALS, AND OTHER CONSUMABLES USUALLY
	SHOULD NOT BE ON THE COMPUTER.	YOU SHOULD TRY TO DETERMINE
	WHAT STOCK # YOUR ARE GOING TO USE FOR EACH ITEM. THEN THE
	SELLING PRICE, YOUR COST, UNIT NAME, RE-ORDER POINT, AND
	THE MFG PART # OR ORDER # SHOULD ALL BE ASSEMBLED, READY FOR
	INPUT TO THE COMPUTER.

		YOU SHOULD WAIT UNTIL AFTER INVOICING HAS STARTED BEFORE
	MAKING AN ACTUAL COUNT OF THE INVENTORY.	THE MOST USED ITEMS
	SHOULD BE COUNTED FIRST, AND WHEN ENTERED IN THE COMPUTER, A BIN
	TAG SHOULD BE PREPARED AND ATTACHED TO THE STOCK # CONTAINER.
	THIS WILL INDICATE WHICH ITEMS HAVE ALREADY BEEN COUNTED.
	WHEN THE INVOICING IS STARTING TO GO SMOOTHLY, THEN IS THE
	TIME TO START COUNTING.	YOU SHOULD COUNT SEVERAL HUNDRED
	ITEMS AND THEN PROCESS ALL INVOICES UP TO THE TIME OF THE
	COUNT.	NEXT ENTER INVENTORY FILE MAINTENANCE AND CHANGE
	THE ON HAND QUANTITY TO THE CORRECT VALUE.	IT WILL GO FASTER
	IF YOU GROUP ALL ITEMS WITH THE SAME FIRST CHAR TOGETHER.

		STUDY THE FLOW CHARTS, THEN FLOW CHART YOUR OWN OPERATION.
	TRY TO FIND A WAY TO INSERT THE COMPUTER INTO THE PAPERWORK
	FLOW WITHOUT DISRUPTING REGULAR PROCEDURES FOR THE TRIAL
	INVOICING PERIOD.	AS THE COMPUTER OUTPUT BECOMES MORE
	AND MORE RELIABLE YOU CAN START ELIMINATING THE MANUAL
	OPERATIONS ONE AT A TIME UNTIL THE COMPUTER HAS ASSUMED
	THE FULL LOAD.

		TAKE A COPY OF THE STANDARD CHART OF ACCOUNTS TO YOUR
	ACCOUNTANT AND HAVE HIM CHOOSE THE APPROPRIATE ACCOUNT #'S
	AND TITLES FOR YOU.	HE SHOULD ALSO BE ALERTED TO PREPARE
	THE BEGINNING TRIAL BALANCE FOR THE MONTH IN WHICH YOU PLAN
	TO START FULL COMPUTER OPERATIONS.	DETERMINE IF YOU ARE ON
	A CASH OR ACCURAL BASIS.

	B. AFTER INSTALLATION

		THERE ARE A NUMBER OF THINGS THAT WILL HAVE TO BE DONE BEFORE
	'GBS' WILL DO YOUR BIDDING.	THE NEXT SEVERAL PROCEDURES REQUIRE
	THE DETAILED KNOWLEDGE OF THE DOS AND SHOULD BE DONE BY THE
	DEALER.

		FIRST THE MASTER DISK SHOULD BE COPIED TO ANOTHER DISK AND
	LINKED, AND THE MASTER DISK STORED AWAY.	BOOT UP THIS NEW
	MASTER DISK AND CALL CREATE NEW DISKS.	MAKE A NEW PROGRAM
	DISK AND THEN RETURN TO MENU.

		TO CREATE A HEADING FOR YOUR COMPANY A PROGRAM (MAKHEADR) IS
	CALLED AND WHEN ALL THE INSTRUCTIONS AND PROMPTS HAVE BEEN
	SATISIFIED A	HEADING SHOULD BE PRINTED, IF NOT ABSOLUTELY
	CORRECT THEN DO AGAIN.	YOU WILL NEED THE FEDERAL ID # FOR
	YOUR COMPANY AND THE STATE ID #, ALSO IF YOU HAVE PAYROLL
	DEDUCTIONS OTHER THAN FIT AND FICA THESE SHOULD BE ENTERED
	AS ITEM 4,5 OR 6.	IF YOUR EMPLOYEES ARE REQUIRED TO REPORT
	TIPS OR GRATUITIES THEN ITEM 6 MUST BE USED FOR THIS ITEM.
	ANY REQUESTS THAT DO NOT APPLY MAY BE IGNORED BY USING THE
	C/R TO TERMINATE WITHOUT INPUTING ANY DATA.

		YOUR ACCOUNTANT SHOULD BE CONSULTED TO HELP SET UP THE CHART
	OF ACCOUNTS.	WE PROVIDE A STANDARD CHART WHICH SHOULD HAVE
	MORE THAN ENOUGH ENTRIES JUST DONT USE THE ONES THAT DON'T
	APPLY.	CALL (MAKCHART) AND FOLLOW INSTRUCTIONS, WHEN FINISHED
	PRINT CHART OF ACCOUNTS AND IF NOT CORRECT, JUST EDIT UNTIL
	CORRECT.	WHEN SATISFIED THEN SAVE CHART ON THE NEW PROGRAM
	DISK.

		IF THE STANDARD DISCOUNT TABLE WHICH FOLLOWS IS NOT AATIS-
	FAXTORY THEN A FILE (TE.TXT) WILL HAVE TO EDITED AND REASSEMBLED WITH
	THE NEW DISCOUNTS. ( THIS SHOULD ONLY BE ATTEMPTED BY AN
	EXPERIENCED PROGRAMER).

		0 - NO DISCOUNT
		1 -	5%
		2 - 10%
		3 - 15%
		4 - 20%
		5 - 25%
		6 - 30%
		7 - 35%
		8 - 40%
		9 - 50%

		THE SALES TAX CALCULATOR SHOULD COME CUSTOMIZED FOR YOUR
	STATE, IF FOR SOME REASON THIS IS NOT SO THEN THE FILE (STAX1.TXT)
	MUST BE EDITED, CHANGED, REASSEMBLED AND INSTALLED ON YOUR
	PROGRAM DISK.	IN THE RARE EVENT YOU ARE REQUIRED TO CALCULATE
	SALES TAX FOR 2 OR MORE STATES THEN (STAX1.TXT) MUST BE CHANGED
	TO CALCULATE THE STATES REQUIRED AND SAVED AS (STAX2.CMD) OR
	(STAX3.CMD) ETC.	THESE ROUTINES WILL OVERLAY THE SALES TAX
	CALCULATOR WHEN CALLED BY CUSTOMER TAX CODES IN THE 20'S,30'S
	ETC. AGAIN, A SKILLED PROGRAMER IS REQUIRED TO MAKE THESE CHANGES.

		IF YOU WANT TO USE THE LOOK-UP TABLE OPTION FOR PRICING AND
	COSTING CERTAIN GROUPS OF STOCK ITEMS, THEN A ROUTINE (LUTFM.CMD)
	MUST BE CALLED AND SET TO YOUR PRICES.	THE LOOK-UP TABLE
	IS ACCESSED BY SETING THE PRICE OR COST TO (990,XXX.00) WHERE
	(XXX) IS ANY NUMBER FROM 1 TO 255.	A DISCOUNT RATE IS SET
	IN THE TABLE SO THAT THE COST OF AN ITEM CAN BE A PERCENTAGE
	OF RETAIL PRICE.

		THE REST OF THE STARTING DATA SHOULD BE ENTERED BY YOUR OPERATOR
	IF FOR NO OTHER REASON THAN TO GAIN EXPERIENCE AND CONFIDENCE
	IN THE COMPUTER.

WHEN POWER IS APPLIED THE MONITOR PROMPT (>) WILL APPEAR ON
	THE SCREEN.	INSERT A PROGRAM DISK IN DRIVE #0 AND DEPRESS THE
	"D" KEY THIS WILL LOAD THE DOS AND DISPLAY THE MENU.	AT THIS
	POINT YOU HAVE A NUMBER OF CHOICES AND QUITE A FEW OF THEM
	HAVE SUB-MENUS WHICH GIVE YOU EVEN MORE PROGRAMS TO SELECT.

	WHEN THE (*) PROMPT IS DISPLAYED, SPECIAL KEYS ARE ACTIVATED
	WHICH ALLOW YOU TO MANIPULATE THE DATA AND CONTROL THE PROGRAM.
	THESE KEYS GENERALLY HAVE THE FOLLOWING FUNCTIONS; HOWEVER,
	THERE ARE SOME EXCEPTIONS WHICH WILL BE EXPLAINED WHEN NECESSARY.

	D.	INVENTORY DISK


CALL 'CREATE DISKS' AND SELECT 'INVENTORY DISK' WHEN
	FINISHED RETURN TO MENU AND SELECT `FILE MAINTENANCE' THEN
	SELECT `INVENTORY & STOCK LEVEL'.	NOW COMMENCE INPUTING
	THE INVENTORY.

		STOCK #'S ARE OF EXTREME IMPORTANCE, THEY MUST BE EASY TO REMEMBER
	THEY MUST DESCRIBE THE PRODUCT SO THAT IT MAY BE READILY IDENTIFIED,
	THEY SHOULD BE EVENLY DISTRIBUTED AMONG THE 35 FILES (1-9,A-Z),
	THEY CAN ONLY HAVE 10 CHARS, AND EACH STOCK # MUST BE DIFFERENT.
	FOR EXAMPLE: IN A PLUMBING SUPPLY AN ELBOW COMES IN SEVERAL DIFFERENT
	MATERIALS (PVC,COPPER,GALVANIZED,CAST IRON), ALSO IT HAS DIFFERENT
	ANGLES (90,45), AND THERE ARE DIFFERENT SIZES (3/4",1",1.25",ETC)
	YOU COULD USE 90ELG3/4, BUT THIS WOULD HAVE SOME ELBOWS IN THE 9
	FILE AND SOME IN THE 4 FILE. HOW ABOUT ELBOWG903/4 THAT HAS 11
	CHARS AND THE 903/4 IS NOT CLEAR. AGAIN EL90G3/4 THIS LOOKS OK, BUT
	DO YOU WANT TO USE FRACTIONS? CONSIDER EL45G11/4 IS THIS 11/4 OR
	1 1/4 MABE EL45G1.25 WOULD BE BETTER.	IN SOME CASES THE SAME ITEM
	WILL BE SOLD IN DIFFERENT QUANTITIES AT DIFFERENT PRICES. TAKE
	THUMB TACKS, WE COULD HAVE (TTACK) FOR A BOX OF 50, (TTACK-12)
	FOR A CARTON OF 12 BOXES, AND (TTACK-144) FOR A CASE OF 12 CARTONS.
	ONE OF YOUR MINOR PROBLEMS WILL BE WHEN A CARTON OF TTACK-12
	IS SOLD 1 OR 2 AT A TIME AS TTACK, THE COMPUTER WILL REPORT THAT
	TTACK IS OUT OF STOCK DO YOU WISH TO BACK-ORDER? YOUR OPERATOR
	WILL REALIZE THAT THE TTACK HAS ALREADY BEEN SOLD AND PAID FOR
	AND CAN'T BE OUT OF STOCK, SO IGNORE THE BACK-ORDER AND COMPLETE
	THE INVIOCE, BUT MAKE A NOTE; AT THE NEXT OPPORTUNITY TO CONVERT
	1 TTACK-12 TO 12 TTACK.

		THE SPACE IS A POOR CHAR TO PUT IN A STOCK #, IT IS HARD TO
	REMEMBER, CHARS SUCH AS (-,/,*,.,#) ARE MUCH BETTER TO INDICATE
	A SEPARATION.	IF YOU HAVE 3 WAREHOUSES #1,2,3 YOU MIGHT USE
	THE (@) TO SHOW WHICH LOCATION. EXAMPLE IF YOU SHIPPED A 1/2
	HP WATER PUMP FROM WAREHOUSE #2 THE STK# MIGHT BE (WPUMP.5@2).
	THIS CERTAINLY WOULD GIVE YOU THE ABILITY TO CHECK ON WAREHOUSE
	#2 BUT WOULD REQUIRE THAT ANY TRANSFER'S BETWEEN WAREHOUSES
	WOULD HAVE TO BE ENTERED INTO THE COMPUTER.

		EVERY ITEM YOU SELL IS IDENTIFIED IN SOME MANNER AND IT WOULD
	BE NICE IF YOU COULD USE THE SAME ID YOU ARE USING NOW. ONE OF
	THE WORST THINGS YOU COULD DO IS TO START ASSIGNING SEQUENCIAL
	NUMBERS AND REQUIRING EVERYONE TO LOOK UP ON THE LIST WHAT
	THEY ARE SELLING, BUYING, STOCKING ETC. IT IS MUCH EASIER IF YOU
	SELL A CALCULATOR TO WRITE SHARP150 THAN A1834 AND ALL PEOPLE
	WHO PROCESS THE PAPERWORK WILL KNOW WHAT WAS SOLD.	THE COMPUTER
	COULD CARE LESS.	IF YOU SELL ITEMS FROM DIFFERENT MFG. WITH
	THE SAME DESCRIPTION YOU CAN PREFIX THE STK# WITH THE MFG.
	INITIAL OR CODE.	EXAMPLE IF YOU SELL A 1/2 HORSEPOWER ELECTRIC
	MOTOR MADE BY WESTINGHOUSE AND A SIMILAR MOTOR MADE BY BALDOR
	YOU MIGHT USE (WEMOTOR.5) AND (BEMOTOR.5)

		TRY TO DISTRIBUTE STOCK #'S EVENLY BETWEEN THE 35 FILES.
	2000 ITEMS IN 10 FILES OF 200 ITEMS EACH WOULD ACCESS HALF
	AS FAST AS 2000 ITEMS IN 30 FILES OF 67 ITEMS.	IF YOU HAVE
	A LARGE NUMBER OF PARTS FOR 1 MANUFACTURER YOU SHOULD SPLIT THEM
	UP INTO SEVERAL FILES. FOR EXAMPLE IF YOU WERE TO SELL WESTINGHOUSE
	APPLIANCES, THE APPLIANCES AND THEIR ACCESSORIES COULD ALL START
	WITH 'W' SUCH AS (WFREEZ135) FOR A 13.5 CU FOOT FREEZER, AND THE
	PARTS FOR THESE ITEMS COULD START WITH 'F' FOR FREEZER, 'R' FOR
	REFRIGERATOR, 'D' FOR DISHWASHER, ETC. A DOOR GASKET FOR THE
	WESTINGHOUSE FREEZER COULD BE (FWDGAS135) AND THE SAME ITEM FOR
	A G E FREEZER COULD BE (FGDGAS135).	THE MAXIMUN NUMBER OF ENTRIES
	TO ANY INVENTORY FILE IS 720 AND THE ONLY PENALTY FOR USING ALL
	OF THEM IS SLOWER ACCESS TIME, WHICH MIGHT BE JUST FINE FOR
	ITEMS WHICH ARE SLOW MOVERS.

		STOCK #'S STARTING WITH "Z" ARE SPECIAL IN THAT THEY WILL
	NOT BE DISCOUNTED BY THE DISCOUNT CODE; HOWEVER THEY CAN BE
	PRICED TO ANY VALUE BY EDITING.


	E. CUSTOMER AND ACCOUNTS RECEIVABLE DISK

		THE CREATE DISKS ROUTINE SHOULD BE CALLED AND A 'NEW CUSTOMER
	LIST AND A-R DISK' SELECTED. WHEN FINISHED, RETURN TO MENU AND
	CALL FILE MAINTENANCE.	NOW SELECT 'CUSTOMER FILE MAINT', AFTER
	A QUESTION OR TWO A MASK WILL BE DISPLAYED AND THE (*) PROMPT
	ON THE COMMAND LINE.	THE SPECIAL KEYS ARE NOW ACTIVE AND TO
	ENTER A CUSTOMER YOU USE THE 'ADD' KEY,	CUSTOMER # IS REQUESTED
	AND THE NUMBER YOU HAVE CHOSEN TO REPRESENT THE CUSTOMER SHOULD
	NOW BE ENTERED, TERMINATE ENTRY WITH THE C/R.

		THE FIRST CHAR OF A CUSTOMER # SHOULD BE THE SAME AS THE FIRST
	CHAR OF THE SIGNIFICANT WORD IN THE CUSTOMER'S NAME OR TITLE.
	E.G. E. F. HUTTON & CO. SHOULD USE AN 'H' FOR THE FIRST CHAR, AND
	THE ACME HARDWARE CO. WOULD USE 'A'.	THE NEXT 2 DIGITS CAN BE
	ANY NUMBER FROM 0 TO 99.	IT IS PROBABLY BEST TO USE SEQUENCIAL
	NUMBERS AS YOU CAN ALWAYS FIND THE LAST NUMBER USED BY THE 'LAST'
	KEY WHICH DISPLAYS THE LAST RECORD IN THE FILE.	(C0) AND (C1)
	SHOULD BE SET UP AS 'CASH'.

		THE NEXT REQUEST FROM THE COMPUTER WILL BE THE 'TAX CODE'.
	THIS IS A TWO DIGIT NUMBER, THE FIRST DIGIT INDICATES IF THE
	CUSTOMER PAYS SALES TAX, AND IN WHAT STATE. (0 = NO TAX, 1 =
	PAYS SALES TAX IN YOUR STATE, 2 = PAYS SALES TAX IN ANOTHER
	STATE, 3 = ETC).	THE SECOND DIGIT IS THE DISCOUNT CODE
	AND IF NOT ZERO WILL CAUSE THE EXTENSION CALCULATION TO BE
	DISCOUNTED ACCORDING TO THE TABLE, EXCEPT FOR THOSE STOCK #'S
	BEGINNING WITH "Z".


THE CUSTOMER NAME AND 3 ADDRESS LINES ARE REQUESTED NEXT.
	IF YOU DON'T NEED ALL THESE LINES JUST ENTER C/R WITHOUT ANY
	INPUT TO SKIP IT.	YOU ARE ALLOWED 30 CHARACTERS INPUT FOR
	EACH LINE, BACKSPACE WILL WORK AND WHEN YOU ARE FINISHED AND
	THE (*) PROMPT IS DISPLAYED YOU CAN CORRECT ANY ERRORS AND
	THEN USE THE REPL KEY TO SEND THE CORRECTED RECORD TO MEMORY
	IT IS FASTER TO GROUP SEVERAL ENTRIES WITH THE SAME FIRST
	CHAR TOGETHER, HOWEVER WHEN YOU REQUEST TO ENTER ANOTHER
	FIRST CHAR, THE OLD FILE IS WRITTEN TO THE DISK WHERE IT IS
	SAFE FROM MOST DISASTERS.

	F.	VENDOR AND ACCOUNTS PAYABLE DISK

		PROCEED AS IN CUSTOMER DISKS EXCEPT CALL "VENDER LIST AND
	A/P DISK".	THERE IS NO TAX CODE IN A VENDOR RECORD.
