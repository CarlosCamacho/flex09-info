         IL IC LE AS PR MC WR JL PC C:001 R:001 L:00001 T:00001 D:001-072
         L.........T.........T.........T.........T.........T.........R.....


 THE (IL) FLAG SAYS THAT INSERT LINE MODE IS ACTIVE.


 THE (IC) FLAG SAYS THAT INSERT CHARACTER MODE IS ACTIVE.


 THE (AS) FLAG SAYS THAT A SYMBOL IS ACTIVE.


 THE (PR) FLAG SAYS THAT ADDITIONAL LINES EXIST TO BE READ IN THE INPUT FILE.


 THE (MC) FLAG SAYS THAT THE MULTI-COLUMN MODE IS ACTIVE.


 THE (WR) FLAG SAYS THAT A READ-IN IS ACTIVE. THIS FLAG MAY ALSO DISPLAY (WW) FOR
 A  WRITE-OUT, (WP) FOR A PRINT-OUT OR (WE) IF AN ERROR OCCURRED IN SOME PREVIOUS
 USE OF AN EXTENDED DOS COMMAND.


 THE (JL) FLAG SAYS THAT LEFT-JUSTIFY MODE IS ACTIVE. THIS FLAG MAY ALSO  DISPLAY
 (JA) FOR ALL-JUSTIFY, (JC) FOR CENTER-JUSTIFY OR (JR) FOR RIGHT-JUSTIFY.


 THE (PC) FLAG SAYS THAT PRINTING WILL NOT STOP AT PAGE BOUNDARIES.


 C:001 INDICATES THAT THE CURSOR IS IN COLUMN ONE.


 R:001 INDICATES THAT THE CURSOR IS ON ROW ONE.


 L:00001 INDICATES THAT THE CURSOR IS ON THE FIRST LINE OF THE FILE.


 T:00001 INDICATES THAT THERE IS ONLY ONE LINE IN THE FILE AT THIS TIME.


 D:001-072 INDICATES THE EDIT WINDOW HORIZONTAL COLUMN DISPLAY.
