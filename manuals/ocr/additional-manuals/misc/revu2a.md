 At this point, you have learned quite a bit about SCREDITOR III. Another  review
 here  should be of help. If you don't remember any of the following material, go
 back and re-read the chapters of the manual  associated  with  the  point  about
 which you are hazy.

 1) You  have  learned  about  the  visual display of SCREDITOR III and what each
    section tells you and its use.

 2) You have learned how to create and edit a document,  and  how  to  abort  and
    close (log) an edit session.

 3) Those  of  you  who  are  OS-9 users have learned how to make system calls to
    allow you to do, for instance, a directory listing, as well as how to  modify
    SCREDITOR III's memory allocation.

 4) You have learned how to make basic changes to your document.

 5) You have learned most of the MODES of SCREDITOR III, as follows:

    COMMAND MODE                 MULTI-COLUMN MODE
    LINE EDIT MODE               JUSTIFICATION MODES
    TEXT EDIT MODE

 6) You have learned the following OPERATORS:

    ^BS - DESTRUCTIVE BACKSPACE  ^MP - MELD PARAGRAPH
    ^CD - CURSOR DOWN            ^NL - NEW LINE
    ^CL - CURSOR LEFT            ^PD - PAGE DOWN
    ^CR - CURSOR RIGHT           ^PU - PAGE UP
    ^CU - CURSOR UP              ^SD - SCROLL DOWN
    ^DC - DELETE CHARACTER       ^SP - SPLIT PARAGRAPH
    ^DL - DELETE LINE            ^SU - SCROLL UP
    ^DM - DELETE TO MARGIN       ^TE - TAB TO END OF LINE
    ^DW - DELETE WORD            ^TL - TAB LEFT
    ^ES - ESCAPE                 ^TM - TAB TO MARGIN
    ^GM - GOTO MARK              ^TN - TAB TO NEXT WORD
    ^IC - INSERT CHARACTER MODE  ^TP - TAB TO PREVIOUS WORD
    ^IL - INSERT LINE MODE       ^TR - TAB RIGHT
    ^IS - INSERT SPACE           ^TS - TAB SET/CLEAR


 7) You  have  learned something about the following COMMANDS (you'll be learning
    more later):

    AB - ABORT EDIT SESSION      MC - MULTI-COLUMN MODE
    BO - BOTTOM OF BUFFER        NU - NUMBERS ON/OFF
    CM - CLEAR MARKS             OS - OS-9 SHELL CALL
    CO - COPY LINES              PA - PAGE FLAGS ON/OFF
    CT - CLEAR TABS              RM - RIGHT MARGIN
    GO - GOTO LINE               SM - SET MARK
    GP - GOTO PAGE               ST - SET TABS
    JM - JUSTIFY MODE            TA - TALLY
    LE - LINE EDIT MODE          TE - TEXT EDIT MODE
    LM - LEFT MARGIN             TO - MOVE TO TOP OF BUFFER
    LO - LOG EDIT SESSION


 The  next  chapters in this manual will teach you even more about the wide range
 of capabilities of SCREDITOR III Word Processing.
