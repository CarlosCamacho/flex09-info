MAKE DATA DISK

YOUR DATA DISKS ARE USED TO INPUT ALL DATA FOR A SPECIFIC CLIENT.

	1.	LABEL A BLANK DISK AS DATA DISK FOR THE INDIVIDUAL CLIENT
		AND PLACE IN DISK DRIVE SLOT 1.
	2.	INSERT A PROGRAM DISK FOR THE INDIVIDUAL CLIENT IN DRIVE
		O.	BOOT UP THE MACHINE.
