C DOCUMENTATION - REV. 2
                ------------------------

The files on this disk represent replacement or additional text
for the C Manual REV. 1.1.

The hard-copy manual should be consulted for other detailed
changes which have been made in red ink. There is also an
indication of where the new text should be slotted in.

There is a TSC PR version of most files (.PR) and a formatted
version (.TXT) which have been generated by:

        +++ O 1.FOO.TXT PR MACROS FOO.PR

I have removed all headers and footers from the .PR files
but the relevant macros still exist.

REV2 is a general introduction to the new library which points
out the changes between the old and the new. I suggest that
this be placed just before the language feature section.

ARERRS is text for page 6.

DRIVES is also for page 6. I am not sure whether this is
strictly necessary as it is a repeat of stuff found later.
However, it appears that people are often too impatient to read
the whole manual before using and complaining about the
compiler!

HEADERS is for page 42. This is also a reinforcing repeat.

The documentation for the Standard Library should be split into
two parts. I think it was too confusing having the high-level and
low-level stuff mixed up. These two sections should replace
pages 43-78.

LIBHIGH has all the printf(), getc() and putc() type functions.

LIBLOW has the low-level functions such as open(), read() and
write().

ROM is a revamped description and listing of the new C start module
which was originally included to help stand-aloners. This should
replace pages 82-85.

CBUG is the introduction and listing of the example monitor
rom. I suggest this goes after page 90. PLEASE NOTE that there
is a correction in 'term.c' since I sent the listing on paper.
