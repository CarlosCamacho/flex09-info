INPUT DATA

EACH CLIENT, YOU ARE NOW READY TO INPUT DATA.

		INTO DRIVE 0 AND A FORMATTED DATA DISK INTO DRIVE 1.
	2.	BOOT UP THE MACHINE

	6.	WHEN YOU ARE USING THE INPUT DATA FUNCTION, THERE ARE
		SEVERAL CONTTROL CODES AT YOUR DISPOSAL TO MAKE THE INPUT
		OF DATA EASIER.	THESE CODES CAN BE USED TO CORRECT DATA,
		TO INPUT DATA WHERE YOU HAVE MORE THAN ONE ENTRY TO A
		GIVEN REFERENCE NUMBER (SPLIT ENTRY), TO VOID AN ENTRY
		(USED IN THE AUTO REFERENCE FUNCTION), AND SEVERAL OTHERS.
		THESE WILL EACH BE EXPLAINED IN THIS SECTION.
	7.	WHEN YOUR INPUT IS COMPLETED AND THE COMPUTER AGAIN ASKS
		FOR AN ACCOUNT NUMBER, SIMPLY PRESS "9".	THIS WILL RE-
		TURN YOU TO THE FUNCTION COMMAND MENU.
	8.	IF YOU ARE FAIRLY CERTAIN THAT YOUR DATA IS CORRECT,
		YOU SHOULD PRESS "2" - LOAD AND SAVE.	THIS WILL GIVE YOU
		A MENU OF THE LOAD AND SAVE FUNCTION CODES.	YOU SHOULD
		"SAVE DATA THIS MONTH" (4).	THE COMPUTER WILL THEN PERFORM
		THIS FUNCTION.	THE MENU OF LOAD AND SAVE FUNCTIONS WILL
		REAPPEAR.	IF YOUR DATA IS CORRECT, YOU SHOULD NOW EITHER

A.	LOAD RECORD FROM LAST MONTH (1) IF DATA IS IN THE
	MIDDLE OF THE YEAR OR

B.	LOAD RECORD 00 (10) IF THE DATA IS FOR THE FIRST
	MONTH IN A NEW YEAR.
		THE COMPUTER WILL PERFORM THIS FUNCTION AND THE WORDS
		"NO LINK" WILL APPEAR ON THE SCREEN ALONG WITH THE MENU
		FOR LOAD AND SAVE.	RETURN TO THE FUNCTION COMMANDS BY
		TYPING "9" (RETURN TO COMMAND).	THIS WILL RETURN YOU TO
		THE ORIGINAL MENU OF FUNCTIONS.
	9.	TYPE "3" - TRIAL BALANCE.	THE COMPUTER WILL PRINT OUT
		THE COMPANY'S CURRENT TRIAL BALANCE.	THIS SHOULD END IN
		ZERO.	IF NOW YOU DO NOT HAVE THE CORRECT FIGURES IN THE
		COMPUTER, YOU SHOULD USE THE EDIT FUNCTION (5) TO CORRECT
		YOUR DATA.	SEE SECTION ON EDIT DATA FOR EXPLAINATION OF
		THIS IMPORTANT FUNCTION.
	10.	IF YOUR TRIAL BALANCE ENDS IN ZERO AND ALL DATA IS CORRECT,
		YOU SHOULD NOW RETURN TO THE LOAD AND SAVE FUNCTIONS (2)
		AND SAVE THE RECORD FOR THIS MONTH "3".	THE COMPUTER WILL
		PERFORM THIS FUNCTION AND RETURN YOU TO THE MENU FOR LOAD
		AND SAVE.	RETURN TO COMMAND (9) AND YOU ARE NOW READY TO
		PRINT YOUR JOURNALS.
	11.	TO PRINT THE JOURNALS SIMPLY TYPE "4" - PRINT JOURNALS.
		THIS WILL GIVE YOU THE MENU FOR YOUR JOURNALS.	IF YOU
		WISH TO PRINT ALL JOURNALS FOR A GIVEN MONTH, PRESS "10".
		IF YOU WISH TO ONLY PRINT A SELECT FEW OF THE JOURNALS,
		PRESS THE REQUIRED COMMAND NUMBER.	WHEN THE COMPUTER HAS
		PRINTED THE REQUIRED NUMBER OF JOURNALS THE MENU WILL AGAIN
		APPEAR.	YOU SHOULD NOW RETURN TO COMMAND "9" AND EXIT TO
		FLEX "9".	THE COMPUTER WILL RESPOND WITH +++.	IF YOU ARE
		FINISHED USING THE COMPUTER YOU SHOULD REMOVE YOUR DISKS
		FROM THE DRIVE DOORS AND WITH DRIVE DOORS OPEN, POWER DOWN
		THE MACHINE.
	12.	IF YOU ARE ENTERING MORE THAN ONE MONTH OF DATA AT A TIME
		YOU SHOULD INSTEAD OF TYPING A "9" AND EXITING TO FLEX,
		(SEE STEP 11), WHEN YOU HAVE COMPLETED THE MONTH, TYPE
		"8" - EXIT TO MONITOR.	THE MACHINE WILL RESPOND WITH THE
		PROMPT ($).	BOOT UP THE MACHINE (TYPE "Z").	THE MACHINE
		WITH RESPOND WITH "MONTH #" (ENTER MONTH), "YEAR #"
		(ENTER YEAR).	YOU ARE NOW READY TO BEGIN INPUTTING THE
		DATA FOR THE NEXT MONTH.


INPUT CONTROL CODES

THERE ARE SEVERAL CONTROL CODES WHICH APPLY TO THE FUNCTION NAMED
INPUT DATA.	THESE ARE AS FOLLOWS:

	1.	PRINNT BALANCE
	2.	CLEAR BALANCE
	3.	SPLIT ENTRY
	4.	END SPLIT
	5.	BACKUP ONE ENTRY
	6.	VOID
	7.	STOP AUTO
	9.	EXIT

THESE WILL BE GONE INTO IN DEPTH IN THIS SECTION.

	1.	PRINT BALANCE - THIS CONTROL CODE ENABLES YOU TO PRINT
		THE BALANCE SHOWN AT THE END OF THE LAST DATA INPUT.
		THIS IS VALUABLE IN THE CASE WHERE YOUR INPUT SHOULD
		ENTER INCORRECTLY AND YOU SHOW A BALANCE WHICH IS IN-
		CORRECT.	TTHIS CONTROL CODE ENABLES YOU TO "FLAG" THE
		DATA AT THIS POINT AND COME BACK LATER AND CORRECT THE
		DATA USING THE EDIT FUNCTION.

	2.	CLEAR BALANCE - THIS CONTROL CODE ENABLES YOU TO CLEAR
		THE BALANCE SHOULD THE BALANCE SHOWN REFLECT AN IN-
		CORRECT ENTRY.	EXAMPLE:	SOME DATA IS ENTERED IN-
		CORRECTLY.	THEREFORE THE BALANCE WHICH SHOULD BE ZERO
		SHOWS A NUMBER.	THIS CONTROL CODE ENABLES YOU TO "FLAG"
		THE ERROR AND CLEAR THE BALANCE TO ZERO SO THAT THE
		DATA ENTERED SUBSEQUENTIALLY COMES OUT TO THE CORRECT
		BALANCE.	YOU SHOULD THEN CORRECT THE INCORRECT DATA USING
		THE EDIT FUNCTION.

NOTE:	THE TWO PRECEEDING CONTROL CODES ARE OPTIONAL.	THEIR USE IS
	NOT REQUIRED AS THE COMPUTER AUTOMATICALLY SHOWS YOU YOUR
	BALANCE AFTER EACH DATA INPUT.

	3.	4.	TO MAKE A SPLIT ENTRY - A SPLIT IS WHEN YOU HAVE ONE
		REFERENCE NUMBER WITH MORE THAN ONE ACCOUNT NUMBER IN-
		VOLVED IN THE SAME REFERENCE NUMBER.	EXAMPLE:	A CHECK
		TO PETTY CASH WHICH HAS SOME MONEY GOING TO THE SUPPLY
		ACCOUNT AND SOME TO AUTO AND SOME TO OFFICE.


		A.	ENTER REFERENCE NUMBER
		B.	ENTER JOURNAL NUMBER
		C.	ENTER INPUT CONTROL CODE "3" AS YOUR ACCOUNT NUMBER

THIS WILL ENABLE YOU TO ENTER MORE THAN ONE ACCOUNT

NUMBER, PAYEE AND AMOUNT PER REFERENCE NUMBER.
		D.	WHEN YOU HAVE ENTERED ALL OF THE DATA IN YOUR SPLIT

ENTRY, THE SAME REFERENCE NUMBER WILL APPEAR AGAIN.

ENTER ANY JOURNAL NUMBER (VALID), AND INPUT CONTROL

CODE "4" AS YOUR ACCOUNT NUMBER.	THIS WILL END THE

SPLIT ENTRY AND YOU SHOULD RETURN TO NORMAL SEQUENCE.

(IF ON AUTO REFERENCE, THE NEXT REFERENCE NUMBER SHOULD

APPEAR ON THE SCREEN.)

YOU MAY SPLIT AND END SPLIT ANY AMOUNT OF TIMES WHEN INPUTTING DATA.

NOTE:	IF YOU MAKE AN ERROR WHEN INPUTTING DATA IN A SPLIT ENTRY,
	YOU SHOULD MAKE A NOTE OF THE REFERENCE NUMER, END THE SPLIT,
	CONTINUE INPUTTING ALL OF YOUR OTHER DATA AND CORRECT THE
	ERROR BY EDITING THE DATA.	(SEE EDIT DATA)

	YOU CAN NOT BACK INTO OR OUT OF A SPLIT ENTRY USING CONTROL
	CODE "5".

	5.	BACKUP ONE ENTRY - THIS COMMAND ENABLES YOU TO WIPE OUT
AND CORRECT ANY ERROR WHEN INPUTTING DATA AT THE TIME OF INPUT.

NOTE:	YOU CAN NOT USE THIS COMMAND IN A SPLIT ENTRY.	DO NOT BACK
	INTO OR OUT OF A SPLIT ENTRY.	THIS COMMAND SHOULD ONLY BE
	USED WHEN YOU HAVE ONE JOURNAL, ACCOUNT NUMBER, PAYEE AND
	AMOUNT PER REFERENCE NUMBER.

		A.	IF YOU WISH TO CORRECT A SINGLE REFERENCE NUMBER AT THE
	TIME OF INPUT, WHEN ENTRING THE ACCOUNT NUMBER OF THE FOLLOWING
	ENTRY, PRESS INPUT CONTROL CODE "5".	THIS WILL BACK YOUR RE-
	FERENCE NUMBER ONE ENTRY.
		B.	AT THIS TIME, ENTER THE CORRECT DATA AND GO ON.	YOU MAY
	WANT TO MAKE A NOTE OF THE REFERENCE NUMBER AND CHECK YOUR
	CORRECTION AT THE END OF INPUTTING DAA BY USING THE EDIT
	FUNCTION.

NOTE:	IF YOU MUST CORRECT A SPLIT ENTRY, THEN NOTE THE REFERENCE
	NUMBER AND CORRECT IT USING THE EDIT FUNCTION.


	6.	VOID - WHEN ENTERING DATA USING THE AUTOMATIC REFERENCE
NUMBER, YOU MAY RUN INTO THE SITUATION WHERE A PARTICULAR NUMBER
NEEDS TO BE SKIPPED OR VOIDED.	EXAMPLE:	IN THE SITUATION WHERE
YOU ARE ENTERING FROM CHECK STUBS AND COME ACROSS A VOIDED CHECK.
		A.	ENTER REFERENCE NUMBER
		B.	ENTER ANY VALID JOURNAL NUMBER
		C.	ENTER ACCOUNT NUMBER "6".

THIS FUNCTION MAY BE REPEATED AS MANY TIMES AS IS NECESSARY.


	7.	STOP AUTO - YOU MAY WISH TO SET UP AUTOMATIC REFERENCE
AND JOURNAL NUMBERS WHEN ENTRING DATA IN NUMERICAL SEQUENCE WITH
THE SAME JOURNAL NUMBERS.	THIS IS THE FUNCTION OF INPUT CONTROL
CODE "7".
		A.	WHEN BEGINNING INPUT, YOU WERE ASKED IF YOU DID OR
DID NOT WAHT AUTOMATIC REFERENCE NUMBERS.	IF YOU DID START WITH
AN AUTOMATIC NUMBER SYSTEM AND IT CHANGES, (EXAMPLE:	FROM GENERAL
JOURNAL ENTRIES 1,2,3 TO CHECK NUMBERS FOR CASH DISBURSEMENTS)
YOU MAY CHANGE TO YOUR NEW REFERENCE NUMBERS BY PRESSING ACCOUNT
NUMBER "7".
		B.	ENTER REFERENCE NUMBER IN SEQUENCE
		C.	ENTER VALID JOURNAL NUMBER
		D.	ENTER ACCOUNT NUMBER "7".
		E.	THE QUESTIONS:	AUTO REFERENCE NUMBER Y/N

AUTO JOURNAL NUMBER Y/N

WILL APPEAR
		F.	SIMPLY ENTER Y OR N DEPENDING ON WHETHER YOU WANT

AUTOMATIC NUMBERS OR NOT AND CONTINUE ENTERING DATA.
THIS COMMAND MAY BE USED AS OFTEN AS YOU DEEM NECESSARY.


	9.	EXIT - IF AT ANYTIME WHEN ENTERING DATA, YOU SHOULD WISH
TO RETURN TO YOUR BASIC COMMAND LISTING FROM YOUR INPUT COMMANDS,
YOU ENTER ACCOUNT NUMBER "9".	THIS COMMAND IS GENERALLY USED ONLY
AFTTER ALL INPUT DATA HAS BEEN ENTERED.	THE BASIC COMMANDS SHOULD
APPEAR ON THE SCREEN UPON EXECUTION OF INPUT CONTROL CODE "9".	YOU
ARE NOW READY TO GO ON TO ANOTHER FUNCTION COMMAND.
EXAMPLE:	LOAD AND SAVE, TRIAL BALANCE, PRINT JOURNALS, EDIT DATA.
