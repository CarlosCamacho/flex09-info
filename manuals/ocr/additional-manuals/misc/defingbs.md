D E F I N I T I O N S


	ABORT A SPECIAL KEY THAT WILL INTERRUPT AN INPUT OR OUTPUT OPERATION
		THE REGISTERS WILL BE DISPLAYED AND A "G" WILL RESUME THE PROGRAM.

	ADD A SPECIAL KEY THAT WILL ONLY FUNCTION AFTER THE '*' PROMPT, THIS
		WILL EITHER ADD A NEW RECORD TO AN EXISTING FILE OR ADD A NEW ITEM
		TO AN EXISTING RECORD.

	BACK-ORDER	IF AN ITEM IS OUT OF STOCK YOU WILL HAVE THE OPTION OF
		SAVING A SHORT MESSAGE TO BE CHECKED LATER FOR AVAILABILITY AND
		THE CREATION OF A NEW INVOICE TO DELIVER THE ITEMS.


	BACKSPACE	A SPECIAL KEY THAT WILL ERASE THE LAST CHARACTER ENTERED
		AND ALLOW A CORRECTION, DOES NOT WORK ON NUMERIC ENTRIES

	BIN TAG	A SMALL ADHESIVE LABEL LISTING STOCK #, RE-ORDER POINT, AND

DISCRIPTION (MFG PART #) TO BE ATTACHED TO THE STOCK LOCATION.

	CAT	A DISK UTILITY THAT WILL LIST THE CATALOGUE OF FILES(DIRECTORY)

	COPY	A DISK UTILITY THAT WILL COPY FROM ONE DISK TO ANOTHER

	COPYNEW	A DISK UTILITY THAT WILL COPY FILES FROM ONE DISK TO ANOTHER

THAT DO NOT ALREADY EXIST.

	COST	THE WHOLESALE COST OF AN INVENTORY ITEM.

	CUSTOMER # - A 1 CHAR 2 DIGIT NUMBER ASSIGNED TO EACH CUSTOMER WITH

CHARGE PRIVILEGES.	THE FIRST CHAR SHOULD BE THE SAME AS THE FIRST

CHAR OF THE MOST SIGNIFICANT WORD IN CUSTOMERS NAME.	THE OTHER 2

DIGITS CAN BE ANY NUMBER FROM 0 TO 99.

	DELET A SPECIAL KEY TO DELETE A RECORD

	DELIVERY #	A SEQUENCIAL NUMBER ASSIGNED BY THE COMPUTER TO DELIVERY

ORDERS	THE STARTING NUMBER IS REQUESTED DURING DJ DISK CREATION.

	DELIVERY ORDER	A DUMMY TRANSACTION THAT IS SAVED FOR LATER RECALL

TO BE CONVERTED INTO AN INVOICE, THEY MAY ALSO INDICATE A LOANER

OR DEMONSTRATION UNIT THAT HAS NOT BEEN RETURNED.

	DESCRIPTION	A 14 CHARACTER FIELD IN AN INVENTORY RECORD TO CONTAIN

THE MANUFACTURER'S PART # OR IDENTIFICATION FOR ORDERING NEW STOCK.

	DISCOUNT CODE	THE 2ND DIGIT IN TRANSACTION CODE,	THE DISCOUNT TABLE

IS PART OF THE TRANSACTION ENTRY MENU AND CAN BE CHANGED FOR CUSTOM

REQUIREMENT. (SOURCE CODE IS FURNISHED TO DEALER)

	DRIVE #	THE ADDRESS OF THE DISK DRIVE GENERALLY THE PROGRAM DISK

IS IN DRIVE #0 AND THE DATA DISK IN DRIVE #1.

	ERASE FIELD	A SPECIAL KEY THAT WILL ERASE THE SCREEN FROM THE CUSOR

TO THE END OF THE FIELD.

	FILE - A BLOCK OF DATA IT MAY CONTAIN SUB UNITS CALLED RECORDS

	FIRST - A SPECIAL KEY ACTIVE ONLY AFTER THE '*' PROMPT THAT WILL

DISPLAY THE FIRST RECORD IN A FILE.

	LINK - A DISK UTILITY COMMAND THAT INSTALLS THE ADDRESS OF

DOS IN THE LOADER

	LOC - A SPECIAL KEY ACTIVATED AFTER A '*' PROMPT THAT WILL DISPLAY

A REQUESTED RECORD.

	MASK - A FIXED DISPLAY ON THE SCREEN IN HALF INTENSITY.	THERE

ARE FIELDS IN THE MASK WHERE VARIABLE DATA CAN BE

DISPLAYED AT FULL INTENSITY

	NEXT - A SPECIAL KEY ACTIVATED AFTER A '*' PROMPT THAT WILL DISPLAY

THE NEXT PHYSICAL RECORD IN MEMORY

	ON HAND - A STOCK LEVEL FIELD INDICATION THE NUMBER OF ITEMS IN

INVENTORY (MAX LEVEL = 7999 - NEGATIVE # ARE PERMITTED)

	ON ORDER - A INVENTORY RECORD FIELD INDICATING THE # OF AN ITEM

THAT HAS BEEN ORDERED.

	ORDER # - THE SEQUENCIAL NUMBER ON PREPRINTED SALES ORDER FORMS,

WORK ORDER FORMS, OR SERVICE ORDER FORMS.	THIS IS A LINK IN THE

AUDIT TRAIL BACK TO THE ORIGINAL DOCUMENT THAT RESULTED IN A

TRANSACTION (CAN BE IGNORED IF DESIRED)

	OUT OF MEMORY - A WARNING THAT THERE IS NOT ENOUGH MEMORY TO

COMPLETE ANOTHER ENTRY.

	PREV - A SPECIAL KEY ACTIVE ONLY AFTER '*' PROMPT THAT WILL DISPLAY

THE PREVIOUS PHYSICAL RECORD IN MEMORY

	PRICE - A FIELD IN THE STOCK LEVEL RECORD CONTAINING THE RETAIL PRICE

OF THE ITEM,	THIS MAY ALSO REFERENCE A LOOK-UP TABLE FOR THE PRICE.

	PRINT - A SPECIAL KEY ACTIVATED AFTER '*' PROMPT THAT WILL CAUSE

A PRINTING FUNCTION TO START.

	PROGRAM DISK - A DISK CONTAINING THE DOS, UTILITIES, PROGRAMS,

STOCK LEVEL FILES, AND DAILY JOURNAL FILES

	QUANTITY - A REQUEST FOR THE NUMBER OF ITEMS

	READY DISK - A DISK THAT HAS BEEN FORMATTED AND CONTAINES THE UTILITIES

CAT AND COPY.

	REMARK - A 20 CHAR FIELD ON A INVOICE FOR RECORDING ANY INFORMATION

ABOUT THE TRANSACTION.	A SPECIAL INVENTORY ITEM REM SHOULD BE

PROVIDED TO ALLOW FOR LONGER MESSAGES.

	RECORD - A UNIT OF DATA, A PART OF A FILE, MAY CONTAIN SEVERAL FIELDS

	REOP - RE-ORDER POINT A FIELD IN AN INVENTORY RECORD INDICATING

THE STOCK LEVEL AT WHICH A REPLACEMENT ORDER SHOULD BE PLACED.

	REPLACE - A SPECIAL KEY ACTIVE AFTER '*' PROMPT THIS WILL CAUSE THE

BRIGHT CHARACTERS ON THE SCREEN TO BE READ BACK INTO THE RECORD

THEY CAME FROM. SOME CRITICAL FIELDS SUCH AS STOCK # CAN NOT BE

CHANGED IN THIS MANNER.

	SALES ACCOUNT - THIS IS A METHOD TO SEPARATE THE VARIOUS DEPARTMENTS

INTO SEPARATE SALES ACCOUNTS,	EACH ACCOUNT IS TOTALED

DAILY AND MONTHY. THIS FUNCTION MAY BE IGNORED, TYPE C/R.

	SKIP - A SPECIAL KEY THAT WILL MOVE THE CURSOR TO THE NEXT UNPROTECTED

AREA ON THE SCREEN.

	STOCK # - A 10 CHARACTER FIELD IN BOTH STOCK LEVEL AND INVENTORY

RECORDS, THE FIRST CHAR MUST BE FROM 1 TO 9 OR FROM A TO Z, ZERO

IS NOT PERMITTED, THE OTHER 9 CHARS CAN BE ANY ASCII CHAR.

	TAX CODE - A TWO DIGIT ENTRY THE FIRST DIGIT INDICATES THE SALES

TAX (0=NO 1=YES) AND THE SECOND INDICATES THE DISCOUNT RATE IF

ANY.	THIS INFO IS REQUESTED DURING CUSTOMER FILE MAINT AND CAN

NOT BE ALTERED.	CUSTOMER #'S OF C0 AND C1 SHOULD BE SET UP AS

CASH TO HANDLE CASH SALES WITH AND WITHOUT SALES TAX.

	TEST - A SPECIAL KEY ACTIVE AFTER '*' PROMPT THIS WILL TEST A STOCK

LEVEL FOR QUAN AND PRICE AND IN SOME CASES TEST A FILE FOR BALANCE

	TRANSACTION CODE - THIS FIELD IN THE INVOICE RECORD HOLDS THE

TAX CODE UNTIL THE INVOICE IS SENT TO THE DAILY JOURNAL WHEN

IT THEN HOLDS THE SALES ACCOUNT #.

	TRANSACTION ENTRY - A MAIN MENU SELECTION WHICH ALLOW FOR THE

SELECTION OF THE VARIOUS TYPES OF TRANSACTIONS AS REQUIRED.

	TRANSACTION # - A SEQUENCIAL NUMBER ASSIGNED BY THE COMPUTER TO

IDENTIFY EACH SEPARATE ENTRY.	THE STARTING # IS REQUESTED

DURING THE DJ FILE CREATION. RECEIPT # OR TRADE-IN # MAY

APPEAR ON VARIOUS INVOICES THESE ONLY INDICATE THE TYPE OF

TRANSACTION INVOLVED. A TRANSACTION FILE SHOULD BE MAINTAINED

WITH A TRANSACTION FILE COPY OF THE INVOICE IN NUMERICAL

SEQUENCE FOR PERMANENT RECORDS.

	UNITS - A 2 CHAR FIELD IN THE INVENTORY RECORD INDICATION THE

PACKAGING METHOD FOR EACH ITEM (DZ - GR - EA - HW )

	VENDOR # - A 1 CHAR + 2 DIGIT NUMBER ASSIGNED TO EACH VENDOR

THE FIRST CHARACTER SHOULD = THE FIRST CHAR IN THE MOST

SIGNIFICANT WORD IN THE COMPANY NAME, THE 2 DIGITS CAN BE

ANY NUMBER FROM 0 TO 99.

	'*'	- A PROMPT WHICH WILL ALLOW THE SPECIAL KEYS TO FUNCTION

ALSO THE CURSOR MOVEMENT KEYS WORK, ANY CHAR TYPED WILL BE

ECHOED TO THE SCREEN.

	'#'	- A PROMPT ASKING THAT A NUMBER BE INPUT.	BACK SPACE WILL

NOT WORK IN THIS MODE HOWEVER TYPING ANY NON NUMERIC CHAR

WILL CAUSE THE 'RE-ENTER' TO APPEAR AND THEN JUST TYPE CORRECT

NUMBER.

	'?'	- A PROMPT ASKING THAT TEXT BE INPUT. BACKSPACE WILL WORK.

	'$'	- A PROMPT ASKING THAT MONEY BE INPUT. SAME RULES AS '#'
