A PROGRAM DISK IS ANY SYSTEM DISK WHICH HAS A CHART OF ACCOUNTS
FOR A GIVEN CLIENT ON THE DISK.

MAKE CHART OF ACCOUNTS
	1.	DETERMINE CHART OF ACCOUNTS FOR INDIVIDUAL CLIENT
	2.	POWER UP MACHINE
	3.	TAKE TWO (2) BLANK FORMATTED DISKS FROM YOUR BOX OF
		DISKS AND LABEL THEM PRIMARY AND BACKUP FOR THE IN-
		DIVIDUAL CLIENT.
	4.	TAKE YOUR MASTER SYSTEM DISK TO DRIVE 0 AND ONE (1)
		OF THE LABELED BLANK DISKS TO DRIVE 1
	5.	BOOT UP THE MACHINE (TYPE Z)

FLEX 1.0 SHOULD APPEAR ON SCREEN

NOT THERE SHOULD APPEAR ON SCREEN

+++ SHOULD APPEAR ON SCREEN
		TYPE "BACKUP 0,1" - CARRIAGE RETURN

DOING BACKUP SHOULD APPEAR ON SCREEN

BACKUP COMPLETE SHOULD APPEAR ON SCREEN
	6.	TYPE "CAT,1" - CARRIAGE RETURN

THIS WILL LIST THE CATALOGUE OF FILES NOW TO BE FOUND

ON THE SYSTEM DISK IN DRIVE 1.
	7.	TYPE "MAKCHART" - CARRIAGE RETURN

	10.	IF THE CHART OF ACCOUNTS IS NOT CORRECT, YOU SHOULD EDIT
		THE CHART USING CONTROL CODE "3".	TO DO THIS SIMPLY
		TYPE "3" AND THE SPACE BAR.	THE COMPUTER WILL RESPOND
		"ACCOUNT NUMBER"	ENTER THE ACCOUNT NUMBER OF THE ACCOUNT
		YOU WISH TO CHANGE.	THE COMPUTER WILL SHOW ON THE SCREEN
		WHAT IS ENTERED FOR THAT ACCOUNT NUMBER.	THEN "ACCOUNT
		NUMBER" WILL AGAIN APPEAR.	AT THIS POINT, ENTER THE
		CORRECT ACCOUNT NUMBER AND ACCOUNT NAME.	THE COMPUTER WILL
		AUTOMATICALLY RETURN TO THE MENU OF CONTROL CODES.	IF ALL
		DATA IS NOW CORRECT, SAVE THE CHART. (SEE STEP 9)
	11.	ONCE YOU HAVE SAVED THE CHART OF ACCOUNTS, YOU MAY WISH
		TO HAVE A PRINT-OUT OF THE CHART TO KEEP WITH THE DATA FOR
		THE INDIVIDUAL CLIENT.	YOU CAN PRINT THE CHART OF ACCOUNTS
		BY TYPING "4" SPACE BAR.	THE COMPUTER WILL NOW PRINT OUT
		THE CHART OF ACCOUNTS.
	12.	ONCE YOU HAVE COMPLETED THE CHART OF ACCOUNTS FOR THE IN-
		DIVIDUAL CLIENT YOU SHOULD RETURN TO FLEX BY TYPING "6".
		REMOVE THE DISK FROM DRIVE 1 AND WRITE PROTECT IT. (SEE
		SECTION ON WRITE PROTECT FOR EXPLANATION)
	13.	REMOVE THE MASTER SYSTEM DISK AND INSERT THE PROTECTED
		PROGRAM DISK FROM DRIVE 1 INTO DRIVE 0
	14.	INSERT YOUR SECOND BLANK DISK INTO DRIVE 1.
	15.	TYPE "BACKUP 0,1" - CARRIAGE RETURN.	THIS WILL COPY THE
		DATA ON THE PROGRAM DISK IN DRIVE 0 ONTO THE SYSTEM DISK
		IN DRIVE 1.
		WHEN BACKUP IS COMPLETE, REMOVE THE DISK FROM DRIVE 1 AND
		WRITE PROTECT THIS DISK ALSO.	YOU NOW HAVE A PRIMARY AND
		A BACKUP PROGRAM DISK FOR THIS CLIENT.
	16.	YOU ARE NOW READY TO BEGIN TO INPUT YOUR DATA FOR THE IN-
		DIVIDUAL CLIENT.
	17.	SEE MAKE DATA DISK.

"ADD TO CHART" COMMAND.

		APPEAR.
