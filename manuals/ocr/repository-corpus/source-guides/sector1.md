.CE
SECTOR1
.SP 1
THE SECTOR1 COMMAND ALLOWS ANY SECTOR ON A DISK TO BE EXAMINED AMENDED AND WRITTEN BACK.
THE INFORMATION IS OUTPUT IN BOTH HEX AND ASCII CHARACTERS.
THE UTILITY CAN BE USED TO LOOK AT AND MODIFY THE CONTENTS OF THE LOADER AND DIRETORY SECTORS OF TRACK 00 AS WELL AS THE NORMAL DATA SECTORS.
.SP 2
DESCRIPTION
.SP 1
THE GENERAL SYNTAX OF THE SECTOR1 UTILITY IS:
.SP 2
.LM 10
SECTOR1,(DRIVE),(TRACK),(SECTOR)
.SP 2
.LM 0
WHERE (DRIVE) IS THE DRIVE NUMBER (0-3), (TRACK) IS THE TRACK NUMBER
IN	HEX (00-4C), AND (SECTOR) IS THE SECTOR NUMBER IN HEX (NB. IN FLEX SECTORS START AT 1).
.SP 2
THE FIRST ACTION OF THE SECTOR1 UTILITY IS TO DISPLAY THE SPECIFIED SECTOR.
HOWEVER, BEFORE THIS IS DONE, TWO, 2 DIGIT NUMBERS ARE OUTPUT. THE FIRST
IS THE HEX VALUE OF THE TRACK NUMBER AND THE SECOND IS THE SECTOR NUMBER (ALSO IN HEX).
EACH OF THE LINES OF DATA WILL CONTAIN 16 HEX DIGITS REPRESENTING THE DATA
FOLLOWED BY THE ASCII REPRESENTATIONS OF THE DATA.
ALL NON-PRINTABLE CHARACTERS ARE DISPLAYED AS UNDERSCORES.
.SP 2
WHEN THE COMPLETE SECTOR HAS BEEN PRINTED, THE UTILITY WILL ENTER SWTBUG.
IT IS THEN POSSIBLE TO ALTER THE CONTENTS OF THE SECTOR. THIS IS STORED IN THE FILE CONTROL
BLOCK $A840.
.SP 2
SOME USEFUL ADDRESSES ARE:
.SP 1
.NF
.LM 10
$A840	FUNCTION CODE
$A841	ERROR STATUS BYTE
$A85E	CURRENT TRACK
$A85F	CURRENT SECTOR
$A880-$A97F SECTOR BUFFER
$A880-$A881	LINK TO NEXT SECTOR (TRACK SECTOR)
$A882-$A883	FILE LOGICAL RECORD NUMBER
$A884-A97F	DATA
.SP 2
.FI
.LM 0
TO WRITE BACK THE SECTOR,	THE SWTBUG G COMMAND SHOULD BE INPUT.
.SP 2
.NF
