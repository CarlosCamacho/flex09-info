# EDREAD

> Source: `sourcecode/library-disks/LIB14 - FLEX Source Library - Source Code and Build Files - Includes ALIGN, ANADEX, COPYNEW.zip!LIB14.DSK!EDREAD.DOC`  
> Method: FLEX disk extraction

OCR and media-decoding errors may remain.

EDREAD.CMD
This program is used to read text files from
FLEX2 disk to the TSC Cassette Editor.
It is most conveniently used in conjunction
with the DC command program written by
Art Weller in `68' Micro Journal, but can also
be called as a FLEX2 command provided one
remembers to return to the warm start of the
Editor.
As this program has been accepted for publication
by `68' Micro Journal, permission should be
sought from that journal before publishing it.
