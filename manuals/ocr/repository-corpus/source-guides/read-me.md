This disk contains several additional text files of programs which
may be useful to you, either for direct use or as guides to writing
your own versions for your equipment:

 CACHE	implements a 64K disk cache on an extended memory board
 RAMDISK	implements a RAM disk (virtual disk) in extended memory
 TIMEADD	adds the time-of-day to directory entries. There are two

versions, one for the Gimix CPU board, the other for

the PT-69 computer
 DATEADD	patches STAR-DOS so it gets the date from the clock when

booted, so you do not have to enter the date manually.

Only works if you have a backup battery installed so

the clock works even when system power is off.
