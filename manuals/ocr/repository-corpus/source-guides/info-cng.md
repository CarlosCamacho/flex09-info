THE TERMINAL.	YOU MAY INPUT A NAME +

THE ADDRESS YOU WANT.	CHANGE ALSO HAS
A TRACE ROUTINE THAT YOU CAN USE IF YOU
WISH. TRACE IS HELPFUL WHEN YOU ARE
UNCERTAIN OF THE EXACT ADDRESS YOU WANT
BUT SLOWS DOWN THE PROGRAM QUITE A BIT.
SELECTING TRACE CAUSES EACH DATA BYTE
IN THE FILE TO BE DISPLAYED ALONG WITH
ITS LOGICAL RUNTIME ADDRESS.

ADDRESS AND WRITE THE NEW DATA TO THE
