This disk contains the source code for a FLEX based
EPROM programmer which should have been described in
a 1988 issue of Microcosm.
The article covers hardware design,software design and
any modifications that may be required to adapt the system
for other user's systems.

Please refer to the article first if you intend to build
this design. At some point I intend designing a printed circuit
board which will be approximately Eurocard card and double sided
with plated through holes. If and when I find the time to do it I
could arrange to have a batch manufactured and sold at cost to
any interested 68 Micro Group members.

If any technical difficulties are encountered in converting
this program or the programmer circuit then I will try my best to
answer any queries but I do tend to get rather busy at times so
I'd prefer contact by letter.

I hope this disk and design is of use. Have fun !
