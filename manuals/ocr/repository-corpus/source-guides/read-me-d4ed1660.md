On this disk you find a few programs which you might like to include in your
library. These were written by me, friends or appeared in 68 Micro Journal
and are therefore public domain.

COPY	.CMD	the new COPY from 68 Micro Journal Nov. 83
CSSTABS .TXT	selfwritten for formatting source files
TABSTEST.TXT	test text for CSSTABS
SYSEQU	.TXT	FLEX equates (needed in all 3 TXT-files)
CSSTABS .CMD	
DOWNLOAD.TXT	loading of binary files with offset (68 MJ)
UPSAVE	.TXT	saving	of binary files with offset (68 MJ)
SCAT	.CMD	sorting CATalog (options +U or +S)
MEMEX	.CMD	screen-oriented memory examine (68 MJ)

If you are interested you may list CSSTABS on your FLEX-page. But I am not
aggrieved if you think other programs are more worth it. I wrote CSSTABS because
I can't stand source files with the labels hidden amoung the opcodes and the
comments hidden amoung the operands. The program works in most cases, but
I could make it work all the time. This could only be accomplished by making
it understand the text it is formatting (like the assembler does). This seemed
like too much trouble to me.
