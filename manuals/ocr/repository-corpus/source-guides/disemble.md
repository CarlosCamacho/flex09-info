# DISEMBLE

> Source: `sourcecode/library-disks/LIB14 - FLEX Source Library - Source Code and Build Files - Includes ALIGN, ANADEX, COPYNEW.zip!LIB14.DSK!DISEMBLE.DOC`  
> Method: FLEX disk extraction

OCR and media-decoding errors may remain.

DISEMBLE.CMD is a disk disassembler which was described in 68 Micro Journal
in December 1981, to which reference should be made for details of this utility.
The program is based on a previously published program which produces a listing,
written by R L Pigford, and was modified by W A Hughes, to produce assembler
mnemonics in assembly format.
