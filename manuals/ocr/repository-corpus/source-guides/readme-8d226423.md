MODS TO CHANGE MICROBOX ][ TO USE DOUBLE SIDED DISK DRIVES.
 -----------------------------------------------------------
**** This modification is only for early versions pre ver.4.5 ****

 Software mods.

MON09B is .bin file assembled @ E000-FFFF moved to 0000-1FFF
ready for programing.

 Hardware mods.

 Cut the track from pin 14 on IC 19 to switch 1,
fit a 74LS04 under the board by the socket to the disk drives
run a lead from pin 14 of IC 19 to an input on the 74LS04 &
a lead from the output to pin 32 of the disk drive socket.

NEWDISK1 is modified NEWDISK to format double sided disks on MICROBOX ][

PGRAPH is a program to print graphics screen on EPSOM MX80 mkIII

DISSEM published in '68' MICRO JOURNAL July-Aug./Sept 1984.

R.CMD published in '68' MICRO JOURNAL February 1984.
