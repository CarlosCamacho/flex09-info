SUPPLEMENTARY INSTRUCTIONS:

This program is menu-driven,and so should present
no problems in use.....
Points to note-LASTCBFL.DAT contains name of last
file used
Filing is standard sequential,by name of month--
Remember that no spaces are permitted within filenames,and that you cannot use punctuation likewise!
To set up own files,break out of initial sequence,which will take you into the blank statement.
The first entry carries a request for a balance,which must be correct balance carried forward as at	that date...
However you can always Change the entry afterwardsif needs be.
Standing orders can be set up equally easily,and when you select a transfer of that particular STO to the main statement,the program
will select the most recent date that matches,and ask you for confirmation that this is correct position.
You can specify a position as an alternative,when asked.

<BREAK> will always return you to main menu,I think!

Being in basic,the program is easy to reconfigure to any printer you have-there is a Centronics 739	driver(80col)
and an Amber 2400	driver here,please feel free to alter routines as necessary,you'll find it's dead easy!
However,a point to note is that the program is compressed,and editing may be peculiar!...
By all means enter complete new lines and delete old lines,but edit existing lines at your peril !!!

You will find that monthly accounts are easy to manage,and the program runs reasonably fast as well.
Don't overload it,as deletes and Inserts become laboured.You can delete all entries up to a certain entry
by entering "-20" in response to question,i.e.delete all entries "to twenty".Only logical!
Also do this just before going to get a cup of coffee,and by the time you get back it will have finished-it's rather longwinded!
Probably could be speeded up/rewritten,but I haven't the time to do everything!And it's fast enough for me,anyway.
More important,it's staraightforward!

I use this program on a regular basis,with my own business account,and it certainly tells me 3days early if i'm about to go O/D
and I hope that it's of some use to you....

Please let me know if you find any bugs,or have any comments,there's always an ansafone on the above No.if I'm not there!
