68 MICRO GROUP LIBRARY


Vol 12	-	FLEX-9 UTILITY PROGRAMS


BACKUP	-	Sansaska Systems


Compares all text files on drive 1 with those on drive 0.

Where the date on drive 1 is later than that on drive 0,

the version on drive 0 is replaced.	Published in '68'

Micro Journal, May 1981.


INIT	-	Leo Taylor


A really fast disk initialisation program.	Published in

'68' Micro Journal, April 1982.	NOTE: The only boot

included is for 6809 with MF68 type controller.


MEMDUMP	-	Richard Gaskell


Prints dump of specified area of memory, in hex and ASCII.


TRAP	-	Richard Gaskell


Loads specified file into memory and then enters S-BUG.

Breakpoints may then be set, etc. before executing the

program with 'G' command.	Allows program load to have

parameters unlike FLEX's GET command.	Based on program

in '68' Micro Journal, March 1980.


TRKDUMP	-	Richard Gaskell


Produces a memory image of specified track on diskette.

The memory image is then printed.


USE	-	Richard Gaskell


Counts the number of times each word is used in a text

file.	Lines starting with '.' or ':' are ignored as it

is assumed that these are commands for TSC's text pro-

cessor.


VOLSET	-	Richard Gaskell


Allows user to change volume name/number of a FLEX diskette.

Based on program in '68' Micro Journal, November 1980.


WORDS	-	Richard Gaskell


Counts the number of words in a text file but ignoring

lines starting with '.' or ':' as it is assumed that

these are commands for TSC's text processor.
