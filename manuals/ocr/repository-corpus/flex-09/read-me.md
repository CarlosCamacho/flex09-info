UPDATING VERSIONS
=================

1/   Modify all occurrences of 8x for 8y in the file MAKE-SYS.TXT, where x is
     the old variant and y the new of WMFLEX8,

2/   Modify the version number patch in DRIVFLOP.ASM from 8x to 8y.
