# T-READ

> Source: `flex-09/distributions/255X32 - Unix Kermit C Source and Terminal Library - 4 MiB Disk Image.zip!255X32.DSK!T-READ.ME`  
> Method: FLEX disk extraction

OCR and media-decoding errors may remain.

This is the termlib system by Mike Mattone and added to c.dragon with the
authors permission.	I have played with this version for FLEX but it should
be little trouble to get it up on any system.	This is a replacement fot the
UNIX termlib stuff and I have written a test program called ttest.c to try
the code out.	The origional code is on the Andover, MA c.node (see "topic
numbers" for phone number").

This version looks for a file called TERM.TXT on drive 0 as the terminal
profile.	I will be using this code on future projects and help converting
UNIX code down to FLEX.	The next step would be to write "curses" package.
If you want to contact Mike, try the "ubbs" Stony Point system.

As I work with the code, I will add further test programs.	I have
tried the system on TVI950 only!
