EUROCARD HARDWARE DRIVERS
                          =========================


This file details the hardware specific drivers used by FLEX.  These  drivers
fall into three categories:

1. PARALLEL PRINTER DRIVERS
2. SERIAL PRINTER DRIVERS
3. PRINT SPOOLER INTERRUPT TIMER DRIVERS


This disk contains several files that fall into  the  above  categories.  The
assembly  language  source  files for these drivers are on the 'UNCONFIGURED'
FLEX disk.


PRINT   .SYS    This file is identical in all  respects  to  the  file  named
                'PPRINT-C.SYS',  i.e. it is a parallel printer driver for use
                with the Rockwell R6522 on the CPU1 board. The reason  it  is
                present  is  that 'BASIC' and many BASIC programs will search
                the system disk for a printer driver of  this  name.  If  the
                driver  is not found the program will abort. If you intend to
                use another printer driver we suggest that  you  delete  this
                file  and  take  a 'COPY' of the driver you intend to use and
                give it this name, e.g. 'COPY 0.SPRINT-T.SYS,0.PRINT.SYS'.


PPRINT-C.SYS    This  is  a  general  purpose parallel printer driver for use
                with the Rockwell R6522 on the CPU1 board. It will  generally
                be  used  in  conjunction  with the 'CEN1' centronics printer
                driver.


PPRINT-T.SYS    This  is  a  general  purpose parallel printer driver for use
                with the Rockwell R6522 on the TIM1 board. It will  generally
                be  used  in  conjunction  with the 'CEN1' centronics printer
                driver.


SPRINT-C.SYS    This  is a general purpose serial printer driver for use with
                the Rockwell R6551 on the CPU1 board. This driver  cannot  be
                used  in  a serial terminal based system as the R6551 will be
                used for communication with the serial terminal.  It  can  be
                used  in  'VIDEO CONSOLE' systems however as the R6551 is not
                used in this configuration except when the  system  is  being
                used  to emulate a serial terminal.


SPRINT-T.SYS    This  is a general purpose serial printer driver for use with
                the  Rockwell R6551 on the TIM1 board.


SPOOL-RC.CMD    This  is  a printer spooler interrupt driver for use with the
                Rockwell R6522 on the CPU1 board. If you decide to  use  this
                driver  you must install link 'M' on the CPU1 board to enable
                interrupts from the R6522.
