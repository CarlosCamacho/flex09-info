WHIMLIST UTILITY
                        -------- -------

This utility is designed purely for printing out the Whimsical
manual when Screditor 3 is not available. e.g.

       P WHIMLIST WHIMD00 +M8

The M option creates a margin of the given width. The EXEC file
LISTALL.TXT may be used to print out the entire manual. If just
certain pages are required of a given file use the P option
followed by the first and last page required. e.g.

       P WHIMLIST WHIMD44 +M8P2,4

The Whimsical manual consists of all the files whose names
begin with WHIMD.
