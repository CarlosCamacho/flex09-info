	LOAD is a program that will load but not execute a binary file from disk to memory at the absolute address specified by the user.
The syntax is:

LOAD <DRV #>.<FILENAME>[.<EXT>] <ADDRESS>

EX: LOAD TTYSET.CMD 1000

	The file TTYSET would be loaded into location 1000 and control returned to Flex.
