****************	HELP11	***********************************

	CREATION OF CUSTOM REPORTS

*************************************************************

 PURPOSE:	TO TELL THE COMPUTER VARIOUS PARAMETERS TO DEFINE

THE FORMAT FOR A CUSTOM REPORT, TO PRINT-OUT ANY

AND ALL GROUPS BY.

 FUNCTIONS: CREATE A NEW CUSTOM REPORT


DELETE AN OLD CUSTOM REPORT


	DISCUSSION:
	A REPORT IS SPECIFIED BY ENTERING 3 CATAGORIES OF INFORMATION

	1) TYPE OF TITLE BLOCK TO BE PRINTED AT TOP OF EACH REPORT PAGE.
	2) DATA FIELDS TO BE USED FOR EACH COLUMN
	3) COLUMN LABELS


	1) THERE ARE TWO POSSIBLE TITLE BLOCKS AVAILABLE:
	STANDARD	AND	CUSTOM


	STANDARD TITLE BLOCK: ONCE SELECTED, NO OTHER USER INPUT REQUIRED.

	CUSTOM TITLE BLOCK: THE USER IS ALLOWED TO ENTER 4 (FOUR) CUSTOM
	LINES, WITH SPECIAL CHARACTERS AVAILABLE AS
	DEFINED AT THE END OF THIS "HELP" FILE.


	2) DATA FIELDS FOR EACH COLUMN:

	ALL OF THE POSSIBLE DATA FIELDS FOR AN ITEM ARE DISPLAYED
THEN YOU MUST ENTER THE DATA FIELD NUMBERS YOU WOULD LIKE TO INCLUDE
IN THE REPORT, IN THE ORDER YOU WANT THEM TO APPEAR ON THE REPORT.
YOU MAY ENTER ONLY ONE FIELD OR ALL OF THEM!


	3) COLUMN LABELS:

	AS YOU ENTER EACH DATA FIELD NUMBER, THE COMPUTER WILL DISPLAY
THE NUMBER OF CHARACTERS AVAILABLE FOR A LABEL AND ASK YOU FOR THE
LABEL YOU WANT AT THE TOP OF THAT COLUMN ON THE REPORT.


	AFTER EACH FIELD AND IT'S LABEL IS ENTERED, THE FIELDS USED SO FAR
AND THE NUMBER OF CHARACTERS CONSUMED ARE DISPLAYED.	DON'T WORRY
ABOUT THE NUMBER OF CHARACTERS USED-UP, BECAUSE THE OUTPUT REPORT
PROGRAM AUTOMATICALLY COMPENSATES FOR THIS.


****************************************************************


CUSTOM TITLE SPECIAL CHARACTERS

****************************************************************

	"\"	- (BACKSLASH) IF THIS IS THE FIRST CHARACTER ON THE LINE

A DOUBLE-WIDE CONTROL CHARACTER WILL BE SENT TO THE PRINTER

( PRINTER MUST HAVE DOUBLE-WIDE OR ENHANCED OPTION INSTALLED)

	"RETURN" - (CARRIAGE RETURN) THIS WILL CAUSE A BLANK LINE FOR OUTPUT.

	"%"	- (PERCENT)	THIS CHARACTER WILL BE REPLACED WITH THE CURRENT

PAGE NUMBER BEING OUTPUT, ANYTIME IT APPEARS IN THE 4 LINES.

	"^"	- (UPARROW)	THIS IS THE TAB CHARACTER FOR THE REPORT PROGRAM.

THE NEXT THREE (3) CHARACTERS FOLLOWING "^" MUST BE THE PRINT

COLUMN TO TAB TO OR A " " (SPACE).	YOU CAN HAVE AS MANY "^"

ON A LINE AS NEEDED.

	"##/##/##" - THESE CHARACTERS WILL BE REPLACED WITH TODAY'S DATE
	ANYTIME THEY ARE ENCOUNTERED ON ONE OF THE FOUR LINES.

	"GT$"	-	THESE CHARACTERS WILL BE REPLACED WITH THE GROUP TITLE
	STRING OF CHARACTERS, DEFINED WHEN THE GROUP WAS CREATED.

	"GF$"	-	THESE CHARACTERS WILL BE REPLACED WITH THE GROUP'S DISK
	FILENAME.

	"GD$"	-	THESE CHARACTERS WILL BE REPLACED WITH THE GROUP'S
	CREATION DATE.

	"GN$"	-	THESE CHARACTERS WILL BE REPLACED WITH THE GROUP'S
	NUMBER OF ITEMS IN GROUP.


	ANY OTHER CHARACTERS IN THE FOUR LINES WILL BE PRINTED EXACTLY AS
YOU ENTER THEM.

*********************************************************************
	SPECIAL CHARACTERS SUMMARY
	"\"		-	DOUBLE-WIDE OR ENHANCED CONTROL CODE
	"^"		-	TAB CHARACTER FOLLOWED BY 3 CHARACTERS FOR TAB COLUMN
	"%"		-	CURRENT PAGE NUMBER
	"GT$"	-	GROUP TITLE
	"GF$"	-	GROUP FILENAME
	"GD$"	-	GROUP CREATION DATE
	"GN$"	-	GROUP NUMBER OF ITEMS
	"##/##/##"	-	TODAY'S DATE
	"RETURN"	-	BLANK LINE
