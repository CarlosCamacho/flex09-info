INVENTORY FILE MAINTENANCE PROGRAM

*********************************************************************

	FUNCTIONS:	INQUIRE - ALLOWS DISPLAY OF ANY STOCK ITEM.

ALLOWS SCROLLING UP OR DOWN IN THE FILE.

ALLOWS GOING DIRECTLY TO MODIFY MODE.

	MODIFY	- ALLOWS MODIFYING ANY PIECE OF DATA ON AN

ITEM EXCEPT THE "STOCKNO"

	DELETE	- ALLOWS YOU TO DELETE ALL DATA FOR AN ITEM.

ONCE DELETED - GONE FOREVER!
	LIST	- ALLOWS LISTING ALL OR ANY PART OF THE MASTER

FILE TO THE TERMINAL OR PRINTER.

	INDEX LIST - ALLOWS LISTING THE MASTER FILE INDEX TO
	THE TERMINAL OR PRINTER.
	( USEFUL FOR ADDING NEW ITEMS )


	NOTE:	THE "DELETE FUNCTION" STORES THE MASTER RECORD NUMBER OF THE
	DELETED ITEM IN A FILE CALLED "DELETED.DAT".	THE NEXT NEW ITEM
	"ADDED" WILL TAKE A RECORD NUMBER FROM THIS "DELETED" FILE AND
	USE IT FOR THE NEW ENTRY.	THIS FEATURE ALLOWS MAXIMUM USAGE
	OF THE DISK SPACE, HOWEVER, YOU SHOULD BE AWARE OF A PROBLEM
	RELATED TO GROUPS.

WHEN A GROUP IS CREATED, THE ONLY INFO STORED IN THE GROUP
	FILE IS THE MASTER RECORD NUMBERS OF THE ITEMS FOR THE GROUP.


SO, IF A GROUP IS CREATED AND THEN DAYS LATER YOU DELETE
	AN ITEM WHICH HAPPENS TO HAVE BEEN INCLUDED IN THE GROUP, AND
	THEN YOU "ADD" A NEW STOCK ITEM WHICH GOES INTO THE MASTER
	RECORD NUMBER OF THE DELETED ITEM - WHEN A GROUP REPORT IS
	PRINTED IT WILL LIST THE NEWLY ADDED POINT - WHICH MAY NOT
	HAVE ANYTHING IN COMMON WITH THE REST OF THE GROUP MEMBERS.

SIMPLY DELETE THAT GROUP ENTRY OR RE-CREATE THE GROUP.
	( SEE GROUP PROGRAM DISCUSSIONS FOR MORE DETAILS )
