STYLOGRAPH CHANGES

The following applies to copies of "STYLO" with serial number greater
than 306180000.

It is no longer necessary to have a printer driver named "STYPRINT.CMD"
on your system disk. STYLO.CMD has been modified so that it now looks
for a printer driver named "PRINT.SYS" by default.

When printing from STYLO and it asks you 'Different Printer	(Y/N*)'
respond by typing "<RETURN>", which is "NO" by default.

If your system uses a driver with a name other than "PRINT.SYS", you
must respond to the 'Different Printer (Y/N*)' prompt by typing "Y"
for YES and then give the appropriate name. For convenience, you can
include a copy of your printer driver renamed to "PRINT.SYS" on your
system disk. You can then respond, to the prompt, by typing "<RETURN>".

See the file "HISTORY.TXT" for further details.
