As delivered, the DATAMAN system assumes a certain environment of both system hardware and software.
Because DATAMAN is written in Basic, it is possible to load and run it on computer systems not meeting the environment criteria
if modification is done to the program code.
It should be noted that the word 'possible' is used here in the sense that anything is possible given enough time, money, and
knowledge!
DATAMAN is supported, at the present time, only on computer systems meeting the hardware and software specs given below.
Other environments may be supported for DATAMAN if enough interest is shown.
For further information contact the distributor, FRANK HOGG LABORATORY, INC.

As delivered DATAMAN requires a 6800 or 6809 based microcomputer with 32K of program core memory and at least 8K of memory
for the disk operating system.
The computer must have at least two disk drives for storage.
If the computer uses a CRT for the system terminal it should be an 80 X 24 format.
A 16 X 64 CRT will work with DATAMAN but problems like line wraparound , unexpected scrolling, and other screen size
related problems should be expected.
If the system terminal is a 'printer terminal' like a thermal printer it should be at least 80 columns wide.
An online time/date generator (like the MICROTIME board) is suggested for a heavy user of DATAMAN for convenience.

The above hardware must be running a version of TSC FLEX (not MINIFLEX) for disk.
A number of standard FLEX utilities are also required.
They are 'PRINT.SYS', COPY.CMD', 'CAT', 'EXEC', 'TTYSET', and 'DELETE'.
Also required is the TSC Extended Basic and the TSC Sort/Merge package.
DATAMAN also supports the TSC Text Processor, but it is not required for the operation of DATAMAN.
6800 computers will have to have the 6800 versions of the above programs and 6809 users must have 6809 versions.
All TSC products are available from your computer manufacturer, computer store or direct from TECHNICAL SYSTEMS CONSULTANTS,
