********************	HELP10	*********************************

	SORT GROUP PROGRAM

***************************************************************

	PURPOSE:	TO SORT AN EXISTING GROUP INTO A NEW ORDER FOR

REPORTS, ETC.

	FUNCTIONS:	GROUP DIRECTORY - LIST THE GROUP FILENAMES ON DISK

	ERASE GROUP	- DELETE ENTIRE GROUP FROM DISK

	LIST GROUP	- TERMINAL LIST OF A GROUP

	FILE RENAME	- RENAME THE DISK FILENAME

	SORT GROUP	- SORT GROUP INTO NEW ASCENDING ORDER


	THE SORT FUNCTION WILL REARRANGE ANY EXISTING GROUP ITEMS BY
SORTING THEM IN ASCENDING ORDER USING UP TO 10 OF THE 24 POSSIBLE
RECORD FIELDS FOR ITEMS.

	IT IS A FULL DISK SORT-MERGE OPERATION, WHICH MEANS ANY SIZE
GROUP CAN BE SORTED PROVIDED THERE IS ENOUGH ROOM ON THE DISKETTE
IN DRIVE 0 TO STORE THE TEMPORARY WORKING FILES.

OPERATION:
	AFTER SPECIFYING WHICH GROUP YOU WISH TO SORT AND HOW MANY SORT
FIELDS YOU REQUIRE ( 1 TO 10 ), THE PROGRAM WILL ASK YOU FOR EACH
SORT FIELD - YOU ENTER THE FIELD NUMBERS IN THE ORDER YOU DESIRE THE
SORT TO BE ACCOMPLISHED.
	WHEN THE SORT IS COMPLETED YOU HAVE THE OPTION OF STORING THE
NEW SORTED GROUP UNDER THE OLD "FILENAME" (ERASING THE ORIGINAL GROUP)
OR UNDER A NEW "FILENAME" (LEAVING THE ORIGINAL GROUP INTACT).
YOU ALSO HAVE THE OPTION OF ENTERING A NEW DESCRIPTIVE "TITLE" OR
RETAINING THE OLD "TITLE".
	THE PROGRAMS AUTOMATICALLY ERASE ANY TEMPORARY FILES THAT MIGHT
HAVE BEEN CREATED IN THE PROCESS.
	THE SPEED OF THE SORT OPERATION IS DIRECTLY RELATED TO THE NUMBER
OF ITEMS IN THE GROUP, THE NUMBER OF FIELDS SPECIFIED, AND THE LENGTH
OF THOSE FIELDS.
	A SORT OF 325 ITEMS ON FOUR FIELDS AVERAGING 50 CHARACTERS/ITEM
TOOK 5.5 MINUTES TO COMPLETE.
	WHEN THE PROGRAM IS COMPLETED, IT RETURNS CONTROL TO THE
MASTER MENU PROGRAM.
