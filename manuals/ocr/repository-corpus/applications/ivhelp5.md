*************************	HELP5	***********************************

	GROUP CREATE PROGRAM

*********************************************************************

	PURPOSE:	TO CREATE A NEW GROUP OF ITEMS

	FUNCTIONS:	GROUP DIRECTORY	-	LISTS THE NAMES OF THE EXISTING
	"GROUP DATA FILES.

	ERASE GROUP	-	DELETES AN ENTIRE GROUP FILE!

	LIST GROUP	-	TERMINAL LISTING OF ITEMS IN THE GROUP

	MANUAL CREATE	-	CREATION OF A GROUP BY ENTERING THE
	"STOCK NUMBER I.D.'S DESIRED.

	AUTOMATIC CREATE -	COMPUTER CREATES A GROUP BASED ON THE
	"ITEM PARAMETERS YOU SPECIFY.


NOTE:	GROUP FILE NAMES
	EACH GROUP MUST HAVE A FILE NAME FOR THE COMPUTER TO USE TO KEEP
	TRACK OF THE GROUP.	THE RULES FOR NAMES FOLLOWS THE "FLEX" DOS
	FILE NAME CONVENTIONS.	THE NAME CAN HAVE NO MORE THAN 8 CHARACTERS
	AND THE FIRST CHARACTER MUST BE ALPHABETIC, THE REST MAY BE ALPHA
	OR NUMBERS.	THE 3 CHARACTER EXTENSION TO THE NAME IS AUTOMATICALLY
	SET TO ".GRP" BY THE INVENTORY PROGRAMS.	YOU DO NOT ENTER THIS
	EXTENSION (".GRP") AT ANY TIME!!!


	THE GROUP CREATE PROGRAM IS A COMPLEX, BUT INVALUABLE PROGRAM, WHICH
YOU SHOULD BECOME VERY FAMILIAR WITH TO MAXIMIZE MANAGEMENT OF YOUR
INVENTORY SYSTEM.

	BY SPECIFYING 1 TO 3 PARAMETERS, THE COMPUTER DOES THE WORK BY
COMPARING EACH MASTER FILE RECORD AGAINST YOUR SPECIFIED PARAMETERS
AND EITHER INCLUDES OR SKIPS THE MASTER RECORD INTO THE GROUP.

PROCEEDURE: A) YOU SPECIFY WHICH PARAMETER YOU WANT THE COMPUTER TO
	EXAMINE OF THE 23 STORED ON EACH ITEM IN THE MASTER RECORD.

B) YOU ENTER A STRING OF CHARACTERS TO COMPARE AGAINST

C) YOU ENTER A COMPARE CODE FOR THE COMPUTER TO USE IN
	COMPARING THE "STRING" AGAINST THE "PARAMETER" AS FOLLOWS:
	EQUAL TO
	NOT EQUAL TO
	GREATER THAN
	GREATER THAN OR EQUAL TO
	LESS THAN
	LESS THAN OR EQUAL TO


D) IF YOU SELECT 2 OR 3 PARAMETER CHECKS,
	YOU MUST ENTER A DIRECTIVE OR CONNECTOR BETWEEN THE
	2 OR 3 PARAMETERS, NAMELY: "AND" OR "OR"


********************	SOME EXAMPLES	****************************

EXAMPLE 1: SUPPOSE MANAGEMENT NEEDED TO KNOW HOW MUCH MONEY WAS

INVESTED IN INVENTORY STOCK FROM A PARTICULAR SUPPLIER

VENDOR.

	SOLUTION:	SELECT THE GROUP CREATE PROGRAM
	SELECT AUTO CREATE FUNCTION
	ENTER GROUP FILE NAME: "STKVEN23"
	( STOCK FOR VENDOR #23 )
	ENTER A GROUP TITLE: "STOCK ON HAND FOR VENDOR 23 = XYZ CO"
	(TITLES APPEAR ON REPORT HEADINGS, MAX OF 40 CHARACTERS)


NOW YOU ARE READY TO SPECIFY THE PARAMETERS:

	SPECIFY "1" PARAMETER FOR THIS CREATE
	SPECIFY PARAMETER: "2"	(PARAMETER 2 = VENDOR NAME FIELD)
	SPECIFY COMPARE CODE:	"EQUAL TO"
	SPECIFY COMPARE STRING: "XYZ CO."

********	COMPUTER STARTS SEARCH	********

	COMPUTER SEARCHES AT APPROXIMATELY 100 RECORDS PER MINUTE, PRINTING
THE RECORD NUMBERS OF THE ITEMS WHERE A MATCH WAS FOUND.

	WHEN THE COMPUTER IS ALL DONE, YOU RETURN TO THE MENU.

	SELECT GROUP REPORTS PROGRAM
	SELECT DIRECTORY - MINI REPORT
	TAKE REPORT TO BOSS.
	TASK IS DONE!!!

	TIME REQUIRED:	1 MINUTE	(SELECTING PROGRAMS & PARAMETERS)
	10 MINUTE	(SEARCHING 1000 ITEMS IN MASTER FILE)
	3 MINUTE	(PRINTING REPORT FOR 200 ITEMS)
	============

TOTAL: 14 MINUTES

EXAMPLE 2: BOSS WANTS TO REORDER ITEMS SUPPLIED BY THE "XYZ CO."

SOLUTION:	FOLLOW THE STEPS OUTLINED ABOVE EXCEPT THIS TIME,


SPECIFY 2 PARAMETER CREATE

SPECIFY PARAMETER 1: "2"	(VENDOR NAME FIELD)

SPECIFY COMPARE CODE: "EQUAL TO"

SPECIFY STRING:	"XYZ CO."

SPECIFY PARAMETER 2: "26" (REORDER TEST, NO FIELD)

( NO COMPARE STRING REQUIRED ON THIS ONE )

SPECIFY CONNECTOR BETWEEN PARAMETER 1 & 2: "AND"

YOU HAVE NOW TOLD THE COMPUTER THE FOLLOWING:


PARAMETER	#1
CONNECTOR	PARAMETER #2
	IF (ITEM IS SUPPLIED BY "XYZ CO.") - AND - (THE ITEM NEEDS REORDERING)
	THEN	PUT THE ITEM IN THIS NEW GROUP.


	WHEN THE COMPUTER IS DONE,
	SELECT GROUP REPORT PROGRAM
	SELECT "MASTER REPORT"	-	MIGHT HAVE SPECIAL ORDERING INSTRUCTIONS

FOR SOME ITEMS IN THE "NOTE" FIELDS.

 ADDITIONAL INFORMATION

 ENTERING COMPARE "STRING"

	CAREFUL ATTENTION SHOULD BE PLACED ON THE STRING ENTERED FOR THE
COMPUTER TO USE TO COMPARE AGAINST.

	THE COMPUTER COMPARES THE "STRING" YOU ENTER AGAINST THE MAXIMUM
NUMBER OF CHARACTERS ALLOWED FOR THE PARTICULAR DATA FIELD INVOLVED,
APPENDING SPACES TO YOUR "STRING" IF YOUR STRING IS SHORTER THAN THE
MAXIMUM ALLOWED FOR THE PARTICULAR FIELD IT IS CHECKING.

	EXAMPLE:	ALL THE "AUX" FIELDS MAY HAVE A MAXIMUM OF "8" CHARACTERS.

SUPPOSE YOU SET-UP "AUX1" TO CONTAIN A MINIMUM ORDER

QUANTITY FROM YOUR SUPPLIER, SOME ITEMS MIGHT BE:

	ITEM 1:	AUX1: 6_______	( ENTERED BY TWO
	ITEM 2:	AUX1: 06______
DIFFERENT PEOPLE )

	NOW, IF YOU TRIED TO CREATE A GROUP BY SPECIFYING ONE OF THE
PARAMETERS TO BE "AUX1" FIELD - EQUAL TO -	"6",
THE FIRST ITEM WOULD BE INCLUDED IN THE GROUP, THE SECOND WOULDN'T,
BECAUSE "06" IS NOT THE SAME AS "6" TO THE COMPUTER!!!!!

	THE POINT HERE IS THAT THE PERSON/PERSONS DOING THE DATA ENTRY
WHEN ITEMS ARE ADDED OR MODIFIED """MUST""" BE CONSISTENT IN ORDER
TO TAKE ADVANTAGE OF THE GROUP CREATE PROGRAM'S USEFULNESS AND TO
GET THE RESULTS DESIRED IN MANAGING YOUR INVENTORY.


	DON'T CARE CHARACTERS

	ANOTHER FEATURE IS PROVISION FOR "LEADING" & "TRAILING" DON'T
CARE CHARACTERS.

	EXAMPLE: LET'S SAY YOU HAVE SET-UP THE "CLASS" FIELD

(MAX. OF 4 CHARACTERS) FOR A RUDIMENTARY CATALOG SCHEME.

SET-UP AS FOLLOWS:

	CHARACTER 1 = MAJOR DIVISION; RANGE "0" TO "9"
	CHARACTER 2 = SUBDIVISION	; RANGE "A" TO "Z"
	CHARACTER 3 = MINOR DIVISION; RANGE "0" TO "9"
	CHARACTER 4 = SUBDIVISION	; RANGE "A" TO "Z"

	NOW, LET'S SUPPOSE YOU WANTED A LIST OF ALL ITEMS WHICH HAD A
MAJOR SUBDIVISION (CHARACTER 2), WHICH EQUALLED "M" REGARDLESS OF WHAT
ANY OF THE OTHER CHARACTERS WERE (1, 3, & 4).


SOLUTION: SELECT AUTO GROUP CREATE PROGRAM

SPECIFY 1 PARAMETER: "CLASS" FIELD

SPECIFY COMPARE CODE: "EQUAL TO"

SPECIFY STRING	: " M	"	(NOTICE LEAD & TRAIL SPACES)

	THE LEADING SPACE FOR CHARACTER 1 MEANS YOU DON'T CARE ABOUT IT,
AND THE TRAILING SPACES FOR CHARACTERS 3 & 4 MEANS YOU DON'T CARE ABOUT
THEM EITHER.

	THE COMPUTER WILL THEN AUTOMATICALLY IGNORE THE 1ST, 3RD, & 4TH
CHARACTERS IN THE "CLASS" FIELDS AND WILL ONLY CHECK THE 2ND CHARACTER
TO SEE IF IT IS AN "M", TO DETERMINE WHETHER THE ITEM SHOULD BE IN THE
GROUP OR NOT!

	IN ESSENCE, THIS FEATURE ALLOWS YOU TO CREATE A GROUP OF ITEMS
BASED ON AS FEW AS 1 CHARACTER OUT OF THE POSSIBLE 252 CHARACTERS
BEING STORED ON EVERY ITEM IN THE FILE.

	THIS FEATURE ONLY APPLIES TO LEADING & TRAILING SPACES!!
	EMBEDDED SPACES ARE CONSIDERED AS DATA CHARACTERS!!!!!!!!!!!

	SO, IF YOU WANTED A GROUP OF ALL THE ITEMS CONTAINING "M" IN
POSITION 2, AND "R" IN POSITION 4:

	" M R" - WOULD NOT YIELD THE DESIRED RESULTS AS A SEARCH STRING!
	
	BUT, BY SPECIFYING 2 PARAMETERS AS FOLLOWS IT WILL WORK:

	PARAMETER 1 STRING: " M	"
	PARAMETER 2 STRING: "	R"
	CONNECTOR		: "AND"


	AS YOU CAN SEE THE "GROUP CREATE PROGRAM" IS A POWERFUL TOOL!
THROUGH WHICH YOU CAN CREATE VIRTUALLY ANY KIND OF "REPORT" YOU NEED
TO MANAGE YOUR COMPANY'S INVENTORY!!
