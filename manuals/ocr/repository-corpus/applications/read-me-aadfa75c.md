# READ-ME

> Source: `apps/screditor/Screditor_III.zip!READ-ME.TXT`  
> Method: archive text extraction

OCR and media-decoding errors may remain.

This project was undertaken to fix the annoying behaviour of the backspace
key in the SCREDITOR III editor for the 6800. I still find the way that ED
treats the cursor control keys in regards to the Insert Character mode.

Description of the files on this disk:

    1. SCRED_09_0.IMA           The real 6809 sources (not a disassembly)
    2. SCRED_DOC_0.IMA          A very nice PDF of the user manual
    3. SCRED_DOC_1.IMA          A very nice PDF of the training manual
    4. SCREDITOR_1.2.IMA        Screditor III as disassembled using DA68Sharp
    5. SCREDITOR_1.4.IMA        the above disassemb;y modified for backspace fix

They are all complete with project files for the 680xAssembler and for the
disassemblies, the DA68Sharp project files are also included. I did this in
case anyone wanted to pick up where I left off.

The assembler used to assemble the any source file was the 680xAssembler by
Evenson Consulting Services (Michael Evenson). I used this so I could
assemble the monolithic files in their entirety. Any new development
should probably be done on a host that can handle large files. The symbol
table generated by assembling some files are too large for the 6800 ASMB
assembler program to handle.
