SPECIAL NOTE TO GIMIX-BUG III USERS -

Although the code generated by SYSGEN produces a working set	of
handlers for the SCREDITOR II when used	with	the	GIMIX	80x24
board, a problem may exist when the SCREDITOR II	is	used	with
this hardware in conjunction with GIMIX-bug III.

The problem is that the SCREDITOR II does not use	the	on-board
scrolling capability of the video board;	rather,	scrolling	is
accomplished by physically moving every location on	the	screen
by one line. This is necessary due to the	number	of	different
boards we support, as well	as	the	difficulty	of	maintaining
screen pointers when a particular line of text may be	addressed
to any line on the screen depending on	the	number	of	scrolls
done since initialization.

For	this	reason,	GIMIX-bug	III	users	should	append	the
following code to the end of the	INPRES	routine	which	SYSGEN
generates. This routine is called whenever	an	exit	to	system
monitor, a fatal DOS error, a normal edit	closing,	etc...,	is
done.

	APPEND TO THE END OF INPRES BY REPLACING RTS WITH
	THE FOLLOWING THREE LINES:

	SWI	DO SWI COMMAND TO GIMIX-BUG
	FCB	23	FORM FEED CODE
	RTS	THEN RETURN FOR FINAL EXIT TO DOS

This code will cause GIMIX-BUG to re-initialize the	screen	for
further use with DOS.
