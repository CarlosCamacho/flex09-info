	====== REPAIR =====

REPAIR IS A PROGRAM DESIGNED TO FACILITATE DISC PATCHING FOR THE RECOVERY OF FILES ACCIDENTALLY DELETED OR FILES WHICH HAVE A SECTOR THAT CANNOT BE READ.

THIS DOCUMENTATION IS RESTRICTED TO EXPLAINING WHAT REPAIR WILL DO FOR YOU AND MAKES NO ATTEMPT TO EXPLAIN THE MAGICAL THINGS WHICH CAN BE DONE BY USING REPAIR. THIS PROGRAM CAN BE A REAL ADVENTURE!

REPAIR COMMAND FORMAT:

	+++REPAIR,<DISC UNIT NUMBER>

THIS LOADS THE REPAIR PROGRAM AND PREPARES IT TO WORK ON THE DISC IN DRIVE <DISC UNIT NUMBER>. REPAIR WILL PROMPT WITH:

ENTER NUMBER OF TRACKS & SECTORS-

AFTER ENTERING THE NUMBER OF TRACKS AND SECTORS (NO SPACES), THE SCREEN WILL CLEAR AND REPAIR WILL PROMPT WITH:

		CMD:

WHEN IT IS READY TO ACCEPT A COMMAND.


REPAIR EXECUTES THE FOLLOWING COMMANDS:

	A	RESTART FROM BEGINNING
	R	READ A SPECIFIED TRACK & SECTOR
	D	DISPLAY CURRENT SECTOR IN BUFFER
	C	CHANGE SECTOR BUFFER
	E	EMPTY CURRENT SECTOR; FILL WITH ZEROES
	F	FIND ONE OR TWO BYTES IN BUFFER
	N	READ NEXT SECTOR IN PROGRAM CHAIN
	S	STEP TO NEXT SEQUENTIAL SECTOR ON DISK
	W	WRITE SCREEN TO DISK
	U	CHANGE DRIVE UNIT NUMBER
	X	EXIT TO FLEX 9.0

ALL INPUT TO REPAIR IS DONE THROUGH THE USE OF THE MONITOR LINE INPUT ROUTINE WHICH MAKES THE USUAL COMMAND EDITING FEATURES AVAILABLE.	NOTE THAT THE COMMAS IN THE FOLLOWING COMMAND DESCRIPTIONS MAY BE REPLACED BY A SPACE.

,PG
COMMAND DESCRIPTIONS:
---------------------

A	RESTART
------------

SYNTAX:	A

THE ENTRY LINE TO ENTER THE NUMBER OF TRACKS AND SECTORS WILL BE DISPLAYED AND THE PROGRAM RESTARTED.

R	READ
----------

SYNTAX:	REP: R,<TRACK NUMBER>,<SECTOR NUMBER>

THE SPECIFIED SECTOR IS READ INTO THE SECTOR BUFFER.

D	DISPLAY
-------------

FORMAT:	REP: D

REPAIR PRINTS THE CURRENT SECTOR ADDRESS FOLLOWED BY THE CONTENTS OF THE SECTOR BUFFER DISPLAYED BOTH IN HEX AND IN ASCII ON THE TERMINAL. ASCII CHARACTERS LESS THAN $20 ARE DISPLAYED AS A PERIOD.

THE DISPLAY IS FORMATTED WITH 16 BYTES PER LINE BY 16 LINES. EACH BYTE IS IDENTIFIED BY ITS OFFSET INTO THE BUFFER WHICH IS SHOWN AS ROW AND COLUMN HEADINGS. THUS THE 16TH BYTE OF THE BUFFER (OFFSET OF $10) IS IN ROW 1 COLUMN 0.


C	CHANGE
-----------

SYNTAX:	REP: C,<STARTING BYTE OFFSET>,<NEW CONTENTS LIST>

CHANGE ALLOWS FOR MODIFICATIONS OF THE SECTOR BUFFER FOR UPDATING THE DISC. FOR EXAMPLE: TO CHANGE BYTE $31 (SEE D DESCRIPTION FOR LOCATION OF THIS BYTE) TO A VALUE OF $53, THE FOLLOWING COMMAND IS USED:

		REP: C 31 53

TO CONVINCE YOURSELF THAT THE CHANGE HAS BEEN MADE, USE THE 'D' COMMAND NOTE: THIS ONLY CHANGES MEMORY,THE DISC HAS NOT YET BEEN UPDATED.	THIS IS DONE WITH THE WRITE (W) COMMAND.

SEVERAL CONSECUTIVE BYTES MAY BE CHANGED AS SHOWN IN THE FOLLOWING EXAMPLE:

		REP: C 31 54 55 56

THIS EXAMPLE CHANGES 3 BYTES STARTING AT BYTE 31
,PG
E	EMPTY SECTOR
------------------

SYNTAX:	REP: E

THIS COMMAND WILL FILL THE CURRENT SCREEN WITH ZEROES.

F	FIND
----------

SYNTAX:	REP: F XX XX

THIS COMMAND WILL FIND A BYTE OR GROUP OF BYTES CONTAINED ON THE DISPLAYED SCREEN.	THE LOCATIONS WILL BE DISPLAYED AT THE BOTTOM OF THE SCREEN. IF THERE ARE TOO MANY LOCATIONS TO BE DISPLAYED, MORE LOCATIONS CAN BE BE DISPLAYED BY TYPING A SPACE. IF NO MORE ARE TO BE DISPLAYED, TYPE 'RETURN'.

N	READ NEXT
---------------

SYNTAX:	REP: N

THE SECTOR SPECIFIED BY THE FORWARD LINKAGES (IN THE SECTOR BUFFER) IS READ INTO THE SECTOR BUFFER AND THE CURRENT & NEXT SECTOR ADDRESSES ARE LISTED.

P	PREVIOUS
-------------

SYNTAX:	REP: P

THE LAST SECTOR WILL BE READ AND DISPLAYED. THE 'P' COMMAND WILL ONLY BACK UP ONE SECTOR AND ONLY IF A READ, PLUS A (NEXT OR STEP) COMMAND HAS BEEN PREVIOUSLY ISSUED.

S	STEP
----------

SYNTAX:	REP: S

THE NEXT SEQUENTIAL SECTOR ON THE DISK WILL BE DISPLAYED.

W	WRITE
-----------

SYNTAX:	REP: W

THE CONTENTS OF THE SECTOR BUFFER ARE WRITTEN TO THE CURRENT SECTOR ON THE DISC (THE CURRENT SECTOR ADDRESS IS SHOWN WITH EACH DISC READ AND WHEN THE D COMMAND IS USED).

,PG
U	CHANGE UNIT
-----------------

SYNTAX:	REP: U <UNIT NUMBER>

THE CURRENT DISC UNIT NUMBER IS CHANGED TO <UNIT NUMBER> WHERE <UNIT NUMBER> MAY BE 0,1,OR 2. THE CONTENTS OF THE SECTOR BUFFER ARE UNAFFECTED.


X	EXIT
----------

SYNTAX:	REP: X

REPAIR EXITS TO FLEX 9.0
