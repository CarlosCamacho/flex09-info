DYNAMITE IS FULLY
POSITION-INDEPENDENT, AND SO
CAN BE RUN FROM ANYPLACE IN
RAM.	DYNAMITE COMES TO YOU
WITH A DEFAULT LOAD ADDRESS OF
$0000, SO AS TO LEAVE THE
MAXIMUM RAM ABOVE ITSELF FOR
SYMBOL TABLE SPACE.

	HOWEVER, IF YOUR SYSTEM
DOES NOT ALLOW PROGRAMS TO USE
LOW MEMORY, USE THE SUPPLIED
UTILITY PROGRAM "RELOCATE" TO
MOVE DYNAMITE (AND OTHER
POSITION-INDEPENDENT PROGRAMS)
TO HIGHER LOCATIONS IN RAM.

	FOR EXAMPLE, TO MOVE
DYNAMITE TO LOCATION $0600 AS
REQUIRED FOR OPERATION IN SOME
IMPLEMENTATIONS OF FLEX ON THE
RADIO SHACK COLOR COMPUTER, USE
THE FOLLOWING FLEX COMMAND:

RELOCATE DYNAMITE C-DYNAM 600

	WHEN RELOCATION IS
COMPLETED, YOU CAN CALL
DYNAMITE BY ITS NEW NAME,
"C-DYNAM", OR RENAME BOTH FILES
SO THAT THE WORKING COPY IS
CALLED "DYNAMITE", FOR
AGREEMENT WITH THE EXAMPLES
GIVEN IN THE DYNAMITE USER'S
MANUAL.
