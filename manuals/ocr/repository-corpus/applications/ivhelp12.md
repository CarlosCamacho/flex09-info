****************	HELP12	*******************************

	CUSTOM REPORT OUTPUT PROGRAM

*********************************************************

 PURPOSE: TO OUTPUT A CUSTOM REPORT FOR A GROUP OF ITEMS

 FUNCTIONS: GROUP DIRECTORY - LISTS GROUP FILENAMES


REPORT DIRECTORY - LISTS CUSTOM REPORT FILENAMES


CUSTOM REPORT	-	OUTPUTS REPORT


	DISCUSSION:

	THE OUTPUT FUNCTION ASKS A SERIES OF QUESTIONS, AFTER WHICH IT
OUTPUTS THE REPORT DESIRED TO THE PRINTER.

 QUESTIONS ASKED & POSSIBLE ANSWERS:

 CUSTOM REPORT TO USE?	ENTER FILENAME OF REPORT TO USE, PREVIOUSLY
	CREATED WITH THE CREATE PROGRAM.

 PRINTING WIDTH?		ENTER THE NUMBER OF COLUMNS FOR THE PAPER IN THE
	PRINTER.	MUST BE GREATER THAN 25 AND LESS THAN
	132.	(8.5" PAPER = 80)
	DEFAULT ENTRY IS 132

 LEFT MARGIN?
ENTER THE NUMBER OF SPACES FOR THE LEFT MARGIN.
	DEFAULT = 0

 RIGHT MARGIN?
ENTER A RIGHT MARGIN IF DESIRED.	THIS SUBTRACTS
	FROM THE PRINTING WIDTH PREVIOUSLY SPECIFIED.
	DEFAULT = 0

 LINE SPACING?
ENTER THE NUMBER OF BLANK LINES NEEDED BETWEEN
	ITEMS PRINTED.
	DEFAULT = 1	( SINGLE SPACE )

 NUMBER OF COPIES?	ENTER THE NUMBER OF COPIES YOU NEED.
	DEFAULT = 1

 PRINTER LINES/INCH?	ENTER "6" OR "8" (SKIP IF PRINTER DOESN'T HAVE
	THIS OPTION)
	DEFAULT = 6

 ENDING TOTALS?
ENTER YES OR NO IF TOTALS OF ALL THE NUMBER
	FIELDS IS DESIRED AT THE END OF THE REPORT.
	DEFAULT = YES

**********************************************************************

	THIS SEEMS LIKE A LOT OF INFORMATION TO ENTER, BUT UTILIZING THE
DEFAULT (NULL ENTRY OR CARRIAGE RETURN) ANSWERS, YOU CAN GET YOUR
REPORT BY ENTERING THE REPORT FILENAME & THE GROUP FILENAME ONLY.

	THE PROGRAM WILL AUTOMATICALLY "WRAPAROUND" ANY DATA THAT WILL
NOT FIT ON THE PRINTING WIDTH YOU SPECIFIED.	THIS MEANS THAT BY
CHANGING ONLY THE "PRINTING WIDTH" SPEC, YOU CAN PRINT-OUT A REPORT
ON 25 COLUMN PAPER OR 80 COLUMN OR 100 COLUMN OR 132 COLUMN OR ANY
COLUMN PAPER!!	YOU CAN SPECIFY A LEFT MARGIN TO ALLOW EASY NOTEBOOK
HOLE PUNCHING.	YOU CAN SPECIFY 8 LPI TO SAVE PAPER.	AND YOU CAN GET
TEN COPIES IF YOU LIKE WITHOUT ASKING FOR THEM INDIVIDUALLY!!

	THIS CUSTOM REPORT PACKAGE GIVES YOU THE FLEXIBILITY OF
GETTING THE INFORMATION NEEDED IN THE FORM YOU DESIRE IT.

	THIS PROGRAM COUPLED WITH THE GROUP CREATE AND GROUP SORT
PROGRAMS WILL ALLOW YOU UNMATCHED VERSATILITY IN MANAGEMENT OF
YOUR INVENTORY!
