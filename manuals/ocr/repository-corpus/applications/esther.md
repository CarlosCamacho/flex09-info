Welcome to the world of artificial intelligence.

ESTHER.CMD is a standard FLEXtm command file and can be executed
by simply typing ESTHER.

ESTHER loads into memory from $0020 to $3210.	The program also uses
antoher 800 bytes above $3211.

When talking (typing) to ESTHER place your keyboard in the lowercase
mode so that she may identify any names you happen to mention.

All of ESTHER's input and output is made through calls to FLEX's
GETCHR and PUTCHR so if you are running FLEX you should have it made.

ESTHER's clear screen string at $08B3 contains nulls on the disk
you received.	If you have a CT-1024 with the standard SWTPC convention
you should place $10 and $16 in this string to automatically
erase your screen at the programs beginning and before each
of ESTHER's replys.

If you own another terminal please look up the clear screen
string information in your user's manual.

Also, it's a good idea to use simple sentences (subject, verb, object)
when conversing with ESTHER.	It just makes life easier.

Now, type ESTHER and have fun ! ! !
