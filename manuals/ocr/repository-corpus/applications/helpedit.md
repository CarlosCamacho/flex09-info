	'EDITRAN' IS A POWERFUL RANDOM TYPE FILE EDITOR WRITTEN IN
TSC XBASIC.	FUNCTIONALLY, IT IS SIMILAR TO TSC'S EDITOR FOR
SEQUENTIAL TYPE FILES.

	*****	EDITRAN USES	*******

	THIS PROGRAM WAS DESIGNED TO GIVE THE USER A TOOL TO EDIT
RANDOM FILES.	IT WILL BE ESPECIALLY HELPFUL TO THE BUSINESS
SOFTWARE PROGRAMMER & USER, SINCE MOST BUSINESS PROGRAMS UTILIZE
RANDOM TYPE DATA FILES FOR SPEED AND VERSATILITY.
	
	1. IT CAN BE USED TO EDIT VIRTUAL STRING FILES AND RECORD I/O
	FILES.	VIRTUAL FILES ARE SINGLY DIMENSIONED.	HOWEVER, DOUBLY
	DIMENSIONED FILES CAN BE EDITED IF THE USER KEEPS TRACK OF WHERE
	HE/SHE IS IN THE FILE.	TO EDIT RECORD I/O FILES, SET THE STRING
	LENGTH = 252.	IF RECORD I/O FILES CONTAIN NUMBERS ENTERED BY
	ONE OF THE "CVT$X" STATEMENTS, UNPREDICTABLE RESULTS MAY OCCUR.
	THESE NUMBERS ARE IN BINARY FORM, NOT ASCII.	YOUR TERMINAL MAY
	DO SOME WEIRD THINGS WHEN THAT RECORD IS DISPLAYED.
	2. IT CAN BE USED TO RECONSTRUCT RANDOM FILES - DAMAGED IN
	EQUIPMENT OR PROGRAM FAILURES.
	3. IT CAN BE USED TO "BUILD" INITIAL DATA IN A RANDOM FILE
	4. IT CAN ALSO BE USED AS A "HOW TO" GUIDE FOR PROGRAMMERS
	NOT EXPERIENCED WITH RANDOM FILES BY STUDYING THE SOURCE
	CODING.
	5. I HAVE ALSO INCLUDED SEVERAL	"TRICKS-OF-THE-TRADE"
	WHICH SHOULD BE USEFUL TO ANY "BASIC" PROGRAMMER
	SUCH AS:	ERROR HANDLING,	USING "INCH$( )",
	DATE ROUTINE, DAY OF WEEK ROUTINE,
	ON-LINE INSTRUCTIONS, SELECTION MENU,
	'PEEK'ing AT FLEX LOCATIONS, AND OTHERS.

	*****	EDITRAN COMPARISON WITH TSC'S EDIT	*****


****	DIFFERENCES	****

	1. A BACK-UP FILE IS "NOT" AUTOMATICALLY CREATED!!
	2. ONLY "SINGLE" COMMANDS RECOGNIZED ( NO : SEPARATOR )
	3. NO "TABS" SUPPORTED
	4. NO "RENUMBER" COMMAND	-	NUMBERING IS AUTOMATIC
	5. NO "APPEND" COMMAND	- (RANDOM STRINGS ARE FIXED LENGTH)
	6. NO "SET" COMMAND FOR TABS
	7. NO "VERIFY" COMMAND	-	ALWAYS ON
	8. NO "X" COMMAND - USER CAN PUT IN PROGRAM IF DESIRED
	9. NO "ZONE" COMMAND
 10. NO "LOG" COMMAND	-	STOP ONLY
 11. NO "BOTTOM" OR "TOP" - USE "!" OR "^"
 12. NO "EXPAND" COMMAND
 13. NO "OVERLAY" COMMAND
 14. NONE OF THE CASSETTE TAPE DIRECTIVES.


****	ENHANCEMENTS	****

	1. "+" COMMAND	- EXECUTES ANY FLEX COMMAND FOLLOWING "+"
	USER SHOULD BE CAREFUL NOT TO USE A COMMAND WHICH USES
	MEMORY OUT OF FLEX AREA or THAT CLOSES ALL OPEN FILES
	DON'T USE: COPY, NEWDISK, BACKUP, ETC
	CAN USE: CAT,RENAME,TTYSET,FILES,LIST,DELETE, ETC.
	2. "O" COMMAND - THIS COMMAND DIRECTS OUTPUT TO PRINTER
	OR BACK TO CRT	VIA THE "PRINT.SYS" FILE
	THIS ALLOWS THE USER TO GET A HARD COPY LISTING OF THE FILE.
	3. "?" COMMAND	-	THIS COMMAND LISTS A "HELP" FILE TO THE
	OUTPUT DEVICE IN SERVICE ( VIA "O" COMMAND )
	4."H" COMMAND	-	TURNS "HEADER" LINE ON or OFF
	(NOT JUST A ONE-TIME HEADER )
	5. "NEW" COMMAND	-	CLOSE CURRENT FILE, OPEN NEW FILE

**************************************************************

	****	INITIAL DATA ENTRY *****

	1. FILENAME = ANY VALID FLEX FILE SPECIFICATION

( DEFAULT = 1000 )	SINGLE
	3. STRING LENGTH = SEE TSC XBASIC MANUAL SECTION 10.2

NOTE: PROVISIONS ARE INCLUDED TO ALLOW EDITING THE FLEX "ERRORS.SYS"

 NOTE: COMMANDS MAY BE ENTERED FOLLOWING "#" SIGN

CONVENTIONS: <ESSENTIAL ELEMENT>	[OPTIONAL ELEMENT]

***	EXTERNAL COMMANDS	***

	"+"	-	EXECUTE ANY FLEX COMMAND.	USE CAREFULLY!
	FORM: +<FLEX COMMAND LINE>

	"O"	-	ROUTE OUTPUT TO ALTERNATE DEVICE, USES "PRINT.SYS" FILE
	FORM: O	( LETTER O, NOT NUMBER 0 )

	"?"	-	LIST HELP FILE
	FORM: ?
	NOTE: PRECEDE WITH O COMMAND TO PRINT HELP FILE

	"H"	-	HEADER LINE ON/OFF	DEFAULT = OFF
	FORM: H

	"NEW" -	NEW FILE COMMAND	CLOSES OLD FILE, OPENS NEW FILE
	FORM: NEW

	"STOP" -	STOP PROGRAM
	FORM: S

	"CTL R" - REPEAT LAST COMMAND	(LIKE TSC'S EDITOR)
	FORM: CTL R	( CONTROL KEY & R KEY - SIMULTANEOUSLY )


***	CURRENT LINE MOVERS	***

	"N"	-	NEXT LINE COMMAND
	FORM: <N>	( LETTER N )

	"12" -	ABSOLUTE LINE ADDRESS, MOVE TO LINE NUMBER ENTERED
	FORM: N	( SOME NUMBER N )

	"-N" -	MOVE BACKWARDS N LINES
	FORM: -[N]	( SOME NUMBER N, OR -1 IF N MISSING )

	"^"	-	MOVE TO TOP OF FILE
	FORM: ^	( GO TO RECORD "0" )

	"!"	-	MOVE TO END OF FILE
	FORM: !	( GO TO LAST ENTRY IN FILE )


***	DATA EDITING COMMANDS	***

	"C"	-	CHANGE COMMAND	( OPERATES ON CURRENT LINE ONLY )
	FORM: C <*OLD STRING> <*NEW STRING> [*]

EXAMPLES:	C/NAME/NAMES/
	C*NAME*NAMES
	C/NAME//	( NEW STRING = NULL )

	"CO" -	COPY COMMAND
	FORM: CO [<*DESTINATION>] [<*RANGE>] [*]
	WHERE: DESTINATION CAN BE "#N" TO COPY AFTER A SPECIFIC LINE

OR DESTINATION CAN BE "N"	TO COPY AFTER CURRENT LINE + N

OR DESTINATION CAN BE "!" TO COPY AFTER END OF FILE
	RANGE CAN BE "#N" TO INCLUDE CURRENT LINE THRU LINE #N

OR RANGE CAN BE "N"	TO INCLUDE CURRENT LINE THRU +N LINES

OR RANGE CAN BE "!"	TO INCLUDE CURRENT LINE THRU END OF FILE
	NOTE: A LINE NUMBER LESS THAN THE CURRENT LINE IS NOT SUPPORTED

EXAMPLES: CO		COPY CURRENT LINE AFTER CURRENT LINE
	CO/#3	COPY CURRENT LINE AFTER LINE #3
	CO/#10/#5/ COPY CURRENT LINE THRU LINE #5 AFTER #10
	CO/10/5/	COPY CURRENT LINE +5 AFTER C.L. + 10
	CO/!/!	COPY CURRENT LINE THRU END AFTER END


	"D"	-	DELETE COMMAND
	FORM: D <N>	WHERE N IS A POSITIVE # OR !

EXAMPLE: D	DELETE CURRENT LINE
	D3	DELETE CURRENT LINE PLUS 2 MORE
	D!	DELETE CURRENT LINE TO END OF FILE

	"F"	-	FIND COMMAND
	FORM: F <*STRING*> [!]

EXAMPLE: F/STRING/	- FINDS FIRST OCCURRENCE OF "STRING"
	$STARTING AT CURRENT LINE AND
	$PRINTS ENTIRE LINE
	F/STRING/!	- FINDS & LISTS ALL OCCURRENCES

	"I"	-	INSERT COMMAND	( UP TO 20 LINES AT A TIME )
	FORM: I
	NOTE: INSERTS NEW LINE OR LINES AFTER CURRENT LINE.

TERMINATE INSERT MODE WITH "#" OR WILL TERMINATE

AUTOMATICALLY AFTER 20 NEW LINES ARE ENTERED.

	"M"	-	MOVE COMMAND
	FORM: M [<*DESTINATION>] [<*RANGE>] [*]

RULES FOR DESTINATION & RANGE SAME AS "COPY" COMMAND
	EXAMPLES: M	- MOVE CURRENT LINE AFTER CURRENT LINE
	M/#3	- MOVE CURRENT LINE AFTER LINE #3
	M/#10/#5 - MOVE C.L. THRU LINE #5 AFTER #10
	M/10/5/	- MOVE C.L. +5 NEXT LINES AFTER

C.L. PLUS 10 MORE LINES

	"P"	-	PRINT COMMAND
	FORM: P [N]	WHERE N IS POSITIVE # OR !

EXAMPLE: P	- PRINT CURRENT LINE
	P5	- PRINT CURRENT LINE + 4 MORE
	P!	- PRINT CURRENT LINE TO END OF FILE

	NOTE: TO LIST FILE TO PRINTER

1).	^	GO TO TOP OF FILE

2).	O	SWITCH OUTPUT TO PRINTER

3).	P!	PRINT TO END OF FILE

4).	O	SWITCH OUTPUT TO TERMINAL


	"R"	-	REPLACE COMMAND
	FORM: R
	ACTION: REPLACES CURRENT LINE WITH NEW LINE,
	THEN GOES TO INSERT ROUTINE
	TERMINATE WITH "#" AS IN INSERT COMMAND
