TO MOST "PROGRAMMED" VDU USERS -

	If you are using a board such	as	the	SSB	VDB-1,	Percom
Electric Window, or F&D Associates, the SYSGEN program	produces
tables which are used to program the	controller	chip	on	your
board. These tables may have to be patched for various	systems,
especially if you are using 50 Hz lines instead	of	60	Hz,	as
are used in this country.

	The values used will also vary from one system	to	another
depending	upon	what	you	are	using	for	a	monitor.	The
documentation which you received	with	your	video	board	will
tell you how to change them for your application.

	Be aware, however, that the	coding	in	the	body	of	the
program you purchased from us will ONLY support 16x64	or	24x80
character formats. If you routinely	program	your	system	for,
for instance, 16x80, you may	not	use	this	format	with	this
software. We suggest that if this	is	the	case,	you	use	the
16x64 version of the program supplied on this disk.
