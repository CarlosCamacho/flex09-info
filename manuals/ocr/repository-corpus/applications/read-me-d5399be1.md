# READ-ME

> Source: `apps/stylograph/STYCOCO - Stylograph Word Processor - Program and Support Utilities.zip!STYCOCO.DSK!READ-ME.TXT`  
> Method: FLEX disk extraction

OCR and media-decoding errors may remain.

Flex must be in the 51 column mode to run Stylo.
The Stylograph program on this disk is configured
for the FHL version of Flex. To run it
immediately, place the disk in drive 1 and type:
	+++1.STYLO,1.INTRO
Stylo will load and bring in the sample file
called "INTRO.TXT".

************************************************
This is a preliminary version that changes some
things in FLEX. To get FLEX back to normal after
running this version of stylo, type RESTORE after
you exit stylo.
************************************************


If you have the Data Comp version of Flex just
type:
	+++1.STYLO,1.INTRO +T3
Stylo will load just as above. Later configure
your own version of Stylo using the "STYFIX.CMD".
