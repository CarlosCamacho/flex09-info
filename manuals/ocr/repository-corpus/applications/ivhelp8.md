**********************	HELP8	***********************************

	GROUP DATA REROUTE PROGRAM

******************************************************************

	PURPOSE:	TO PROVIDE A RAPID MEANS OF CHANGING MASTER RECORDS OF

A GROUP OF ITEMS.

	FUNCTIONS: GROUP DIRECTORY	- LISTS GROUP FILE NAMES


ERASE GROUP	- DELETE OLD GROUPS FROM DISK


LIST GROUP	- TERMINAL LISTING OF ITEMS IN A GROUP


FILE RENAME	- RENAME THE DISK FILE NAME


REROUTE DATA	- CHANGE ANY DATA FIELD FOR A WHOLE GROUP

NOTE: THE REROUTE FUNCTION HAS TWO MODES
	1) AUTOMATIC
	2) MANUAL

1)	THE AUTOMATIC MODE CAN BE USED TO CHANGE ANY ONE DATA FIELD
	(OUT OF THE 23 POSSIBLE FIELDS) TO SET THE FIELD SELECTED TO
	ANY DESIRED "NEW STRING" FOR ALL THE ITEMS IN THE GROUP!

	EXAMPLE: LET'S SAY THAT VENDOR "XYZ CO." CHANGES IT'S NAME TO THE

"ABC CO.".


A) USING THE GROUP CREATE PROGRAM - CREATE A GROUP OF ALL

ITEMS WHOSE VENDOR FIELD WAS EQUAL TO "XYZ CO."

B) USE THE GROUP DATA REROUTE PROGRAM TO CHANGE THE VENDOR

FIELD FOR THE ITEMS IN THE GROUP JUST CREATED TO BE

"ABC CO.".

	THE AUTOMATIC MODE IS VERY FAST AND REQUIRES NO OPERATOR INTERVENTION
	THE MASTER RECORDS ARE NOT DISPLAYED AS THEY ARE BEING CHANGED!!


2)	MANUAL MODE

	IN THE MANUAL MODE OF DATA REROUTE, THE MASTER RECORD IS DISPLAYED
 FOR EACH STOCK ITEM IN THE GROUP, ONE-AT-A-TIME.

	THE COMPUTER WILL THEN ASK YOU:

	"CHANGE	'OLD STRING'	TO	'NEW STRING'	?"

	YOU HAVE THE FOLLOWING RESPONSE OPTIONS:

	"N"	-	FOR NO, NEW DATA STRING REQUIRED FOR THIS ITEM ONLY
	"S"	-	TO SKIP TO NEXT ITEM WITH NO CHANGES BEING MADE
	"Y"	- FOR YES, OR ANY OTHER KEY, WILL PROCEED WITH THE CHANGE


	IF AN "N" ENTRY IS MADE, THE COMPUTER WILL ASK YOU FOR A "NEW STRING"
	( FOR THE ITEM BEING DISPLAYED ONLY! ), THE CHANGE WILL BE MADE,
	COMPUTER WILL PROCEED TO THE NEXT ITEM, REMEMBERING THE ORIGINAL
	"NEW STRING" THAT WAS ENTERED AT THE START OF THE PROGRAM.


	EXAMPLE:	LET'S SAY YOU HAD A GROUP CREATED OF ALL ITEMS BEING

FURNISHED BY VENDOR "ABC CO."	AND	THIS VENDOR SENDS

YOU A NEW PRICE SHEET FOR HIS GOODS - SOME ITEMS HAD NO

PRICE CHANGES, OTHERS HAD PRICE INCREASES

	SOLUTION:	YOU COULD USE THE INVENTORY FILE MAINTENANCE PROGRAM
	TO CALL-UP EACH ITEM ONE AT A TIME AND "MODIFY"
	THE PRICES


- OR -

	YOU COULD USE GROUP DATA REROUTE PROGRAM IN THE MANUAL
	MODE TO REROUTE THE "LIST PRICE" DATA FIELDS
	AS EACH ITEM WAS DISPLAYED, YOU COULD ENTER THE "NEW"
	LIST PRICE IF THE ITEM HAD INCREASED IN PRICE	OR
	SKIP THE ITEM IF NO PRICE CHANGE HAD OCCURRED.
	ACCOMPLISHING THE TASK IN A VERY SHORT TIME PERIOD!
