INVENTORY ADD NEW ITEM PROGRAM

********************************************************************


	FUNCTIONS:	INQUIRY	- WITH SCROLL FEATURE, NO MODIFY
	
	ADD	- ADD A NEW ITEM TO MASTER FILE

	COPY ADD	- ADD A NEW ITEM BY COPYING ALL OF THE DATA
	 FOR AN EXISTING ITEM EXCEPT THE STOCKNO.

	INDEX LIST - TO TERMINAL OR PRINTER

	NOTE:	WHEN A NEW ITEM IS ADDED TO THE MASTER FILE, YOU MUST ENTER

A UNIQUE "STOCKNO".	THEN YOU ARE ALLOWED TO FILL-IN THE

BLANKS FOR ALL THE OTHER (23) PIECES OF DATA FOR THE NEW ITEM.


YOU MAY ENTER 1 TO 20 NEW STOCK ITEMS IN A SESSION.

AFTER 20 ENTRIES OR WHEN YOU ARE DONE, THE SYSTEM WILL SORT

THE NEW ENTRIES INTO THE INDEX FILE - THIS MAY TAKE A COUPLE

OF MINUTES - DEPENDING ON HOW MANY ITEMS ARE ALREADY ON FILE.


COPY ADD	- THIS FUNCTION IS PARTICULARLY USEFUL WHEN YOU

ARE ADDING SEVERAL ITEMS TO THE SYSTEM WHICH HAVE A LOT OF

INFORMATION IN COMMON - SAVING YOUR TYPING FINGERS, BY COPYING

THAT INFORMATION INTO NEW ITEMS FOR YOU.
	ALSO, IT IS USEFUL TO REASSIGN A NEW "STKNO" TO

AN ITEM, THEN DELETING THE OLD ITEM.
