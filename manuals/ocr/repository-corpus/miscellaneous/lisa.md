# LISA

> Source: `misc/uncategorized/tsc - Bootable FLEX System and Utilities.zip!tsc/Tsc_util_2.dsk!LISA.DOC`  
> Method: FLEX disk extraction

OCR and media-decoding errors may remain.

LISA is a utility to LISt in Assembler layout - it gives you
 a line-numbered listing of an assembler source file with
 assembler-type columnar display - a quick way to view a large
 assembler source file if you don't need object code.
Format of the command is
	LISA SOURCFIL
 with TXT being the default extension.
