*
* PUT LINE FROM HELPFILE.TXT IN LINEPT
*
HELP2 JSR FMS GET CHARACTER
 BNE ERROR3 ERRORS?
 LDX LINEPT GET POINTER
 STAA 0,X SAVE CHARACTER
 INX BUMP TO NEXT
 STX LINEPT SAVE POSITION
 LDX #FCB RESTORE TO FCB
 CMPA #$D END OF LINE?
 BNE HELP2

 LDX #LINEBF POINT TO LINE
 STX LINEPT SAVE POINTER
 STX STP
 BRA HELP3

ERROR3 LDAA 1,X GET ERROR NUMBER
 CMPA #8 IS IT EOF?
 BEQ HELP32
 CMPA #4 IS HELPFILE.TXT THERE ?
 BEQ HELP33
ERROR LDAA 1,X GET ERROR TYPE
 JSR RPTERR REPORT ERROR
FLEX JSR FMSCLS CLOSE ALL
 JMP WARMS RETURN TO FLEX

HELP32 JSRPCRLF PRINT CR & LF
 LDAA FOUND SEE IF WE COULD HELP
 CMPA #$0 IF >0 THEN YES
 BNE HELP35
 LDX #SORRY PRINT SORRY MESSAGE
 JSR PDATA
 LDX #INBUF PRINT WHAT WE LOOKED FOR
 JSR PDATA
 JSR PCRLF
 LDX #SORRY1
 JSR PSTRNG
 JSR PCRLF PRINT CR & LF
HELP35 JMP FLEX CLOSE FILE,GOTO FLEX

HELP33 LDX #NOT PRINT CAN'T FIND HELPFILE.TXT
 JSR PSTRNG
 BRA FLEX

 PAG
HELP3 LDX #LINEBF POINT TO LINE FROM HELPFILE
 LDAA 0,X GET FIRST CHARACTER IN LINE FOR TESTING
 CMPA #$20 IS IT A SPACE
 BEQ SPACE
 TST MATCH SEE IF WE WANT TO TEST FOR @
 BEQ TSTL NO IF 0
 CMPA #'@ TEST FOR OTHER YES NO PROMPT
 BEQ YESNO
TSTL TST MATCH1 SEE IF WE WANT TO TEST LINES
 BNE HELP4 IF NO
 CMPA #'% RETURN TO FLEX?
 BEQ FLEX
 CMPA #'$ WANT A Y OR N PROMPT
 BEQ YESNO
 CMPA #'& WANT A NEW MATCHSTRING?
 BEQ NEWMCH
HELP4 CLR MATCH RESET MATCH FLAG
 LDX #INBUF POINT TO SEARCH STRING
 STX POINT
HELP5 CPX ENDPT END OF STRING?
 BEQ HELP77 IF SO, MATCH!
 LDAA 0,X GET CHARACTER
 INX BUMP TO NEXT
 STX POINT SAVE POINTER
 LDX LINEPT

 BNE HELP65 NOT A MATCH SO GET ANOTHER LINE
 INX BUMP TO NEXT
 STX LINEPT SAVE POSITION
 LDX POINT
 BRA HELP5 REPEAT PROCESS

 STX LINEPT

 BNE HELP7 YES PRINT IT
 LDX #FCB POINT TO FCB

YESNO JSR PCRLF
 JSR PCRLF
 JSR TESTLN
 BEQ YESNO1
 LDX #YORN ASK FOR Y OR N CONTINUE
 JSR PDATA
YESNO1 JSR GETCHR
 ANDA #$5F MAKE UPPERCASE
 PSHA
 JSR PCRLF
 PULA
 CMPA #'N
 BNE DONE3 IF N SET FLAG AND TRY FOR MORE
 CLR MATCH SET PRINT FLAG TO NO PRINT
DONE3 BRA HELP65 CONTINUE

NEWMCH JSR PCRLF
 JSR PCRLF
 JSR TESTLN
 BEQ NEWMC1
 LDX #PRMPT ASK FOR NEW MATCH STRING
 JSR PDATA PRINT IT
NEWMC1 CLRB SET COUNTER
 LDX #INBUF
NEWC JSR GETCHR
 CMPA BSP BACKSPACE
 BEQ BACK
 CMPA DEL LINE DELETE
 BEQ NEWMCH
 CMPA #$D END?
 BEQ GOTIT1
 CMPB #8
 BEQ GOTIT1
 STAA 0,X PUT IN BUFFER
 INX
 INCB BUMP POINTERS
 BRA NEWC REPEAT TILL DONE

BACK CMPB #0
 BEQ NEWMCH
 LDAA BE GET BACKSPACE ECHO
 CMPA #8 CHECK TO SEE IF SAME AS BS
 BNE BACK1
 LDAA #$20 SEND OUT A SPACE
 JSR PUTCHR
 LDAA #8 PUT OUT A BACKSPACE
BACK1 JSR PUTCHR
 DEX RESET X
 DECB AND B
 BRA NEWC

GOTIT1 JSR PCRLF
 JMP GOTIT

 INC MATCH SET MATCH FLAG
 LDX #LINEBF POINT TO LINE
HELP8 LDAA 0,X GET CHARACTER
 CMPA #$D END OF LINE?
 BEQ HELP9

 BEQ HELP9

 INX BUMP TO NEXT

*
* PRINT A STRING WITHOUT A CRLF
*

PDATA LDAA 0,X
 CMPA #4
 BEQ DONE
 JSR PUTCHR OUTPUT CHARACTER
 INX
 BRA PDATA

DONE RTS

*
* TEST LINE TO SEE IT MORE THAN 1 LETTER COMMAND
* AND IF SO PRINT LINE INSTEAD OF INTERNAL PROMPT
* X=HELPFILE LINE A=0 IF HELPFILES LINE IS USED
*

TESTLN LDAA 1,X POINT TO FIRST CHAR
 INX BUMP POINTER
 CMPA #$20 SKIP SPACES
 BEQ TESTLN
 CMPA #$D SEE IF NO PROMPT
 BEQ USEOUR USE INTERNAL PROMPT
 CMPA #'* SEE IF COMMENT
 BEQ USEOUR

PDATA1 LDAA 0,X GET HELPFILE CHAR
 CMPA #'* TEST FOR COMMENT
 BEQ DONE1
 CMPA #$D SEE IF END
 BEQ DONE1
 JSR PUTCHR PRINT IT
 INX BUMP POINTER
 BRA PDATA1 REPEAT TILL DONE

DONE1 LDAA #$20 PRINT A SPACE
 JSR PUTCHR
 CLRA CLEAR FLAG
 RTS

USEOUR LDAA #1 SET FLAG
 RTS
