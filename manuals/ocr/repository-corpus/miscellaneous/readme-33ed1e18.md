> Source: `misc/archive-series/disk/DISK20 - Small-C Compiler Source, Libraries, and Examples.zip!DISK20.DSK!README.DOC`  
> Method: FLEX disk extraction

OCR and media-decoding errors may remain.

DGS C USAGE NOTES

THE FILES ON THIS DISKETTE ARE AS FOLLOWS:

	DGSCC.CMD	C COMPILER

	TOTALSRC.TXT	COMPLETE C RUNTIME PACKAGE

	TOTAL2.BIN	RUNTIME PACKAGE ASSEMBLED AT $2000

	TOTAL2.INC	INCLUDE EQU FOR RUNTIME AT $2000

	PRIME.TXT	DEMOSTRATION ROUTINE

	RUN.TOT	SETUP TO ASSEMBLE RUNTIME

	CUTIL.LIB	UTILITIES AND FORMAT I/O

	CRUN.LIB	INTEGER ONLY RUNTIME

	INTONLY.INC	INCLUDES CUTIL.LIB AND CRUN.LIB

PROCEDURE FOR RUNNING IS AS FOLLOWS:

	+++DGSCC
		-----
		-----
		-----
	OUTPUT FILE: outfile.asm
	INPUT FILE:
	INPUT FILE:total2.inc
	INPUT FILE:
	+++ASMB OUTFILE.ASM +LSYG
	+++APPEND OUTFILE.BIN TOTAL2.BIN OUTFILE.CMD

APPEND COMPLETE
	+++

THIS ABOVE PROCEDURE WILL MINIMIZE THE TIME AND SPACE REQUIRED
FOR COMPILING AND ASSEMBLING.

TO CHANGE THE START LOCATION OF THE RUNTIME PERFORM THE FOLLOWING:

	1. EDIT TOTAL2.INC AND CHANGE THE START LOCATIONS.

	C/20/30/100	FOR EXAMPLE $2000 TO $3000
		ALSO CHANGE THE ORG ADDRESS AT THE END TO $2500 ABOVE
		NEW BASE.

	2. EDIT RUN.TOT AND CHANGE THE ORG ADDRESS TO THE NEW BASE.

	3. ASSEMBLE TOTALSRC.TXT USING RUN.TOT

	+++ASMB RUN.TOT TOTALn.BIN +LSYG
	where n = new base 3 for example above.

TO COMPILE ONLY INTEGER ONLY C SOURCE USE INTONLY.INC.
THIS WILL SET UP LIB STATEMENTS FOR CUTIL AND CRUN.
