@THE PRIMARY PURPOSE OF THIS DOCUMENT IS TO OUTLINE THE
FUNCTIONAL REQUIREMENTS FOR A COMPUTER CONTROLED TIME
KEEPING SYSTEM.
.SP2
.SI5
@THE TIME KEEPING SYSTEM MUST FIRST BE CAPABLE OF KEEPING
TIME ACCURATELY.
@IT MUST ALSO PROVIDE THE USER WITH A MEANS OF LOGGING
EMPLOYEE TIME TO A PARTICULAR JOB.
@IN ADDITION TO THE ABOVE REQUIREMENTS, THE USER MUST BE
ABLE TO RETRIEVE SYSTEM FILES TO PRINT REQUIRED
REPORTS.
@THE FINAL REQUIREMENT IS THAT THE SYSTEM SHOULD ALLOW THE
WORKER TO ENTER HIS/HER EMPLOYEE NUMBER AND CURRENT JOB
NUMBER REMOTELY FROM THE COMPUTER.
.SP2
.SI5
@TO ACCOMPLISH THIS, THE FOLLOWING FOUR BASIC PEICES OF
HARDWARE WILL BE REQUIRED.
.IN10
.SP1
 1. ^COMPUTER^
 2. ^REMOTE ENTRY DEVICE^
 3. ^MASS STORAGE^
 4. ^PRINTER^
.SP2
.IN0
.SI5
@THE COMPUTER CHOSEN WILL BE A 6800 BASED ^TRW^ BUILT 2001
CASH REGISTER.
@THE REMOTE ENTRY DEVICE WILL BE ANOTHER 2001.
@MASS STORAGE WILL CONSIST OF A MINI FLOPPY DISK DRIVE
USING A CONTROLLER BUILT BY ^EVCO^ FOR THE 2001.
^I/O^ FOR THE REMOTE DEVICE WILL BE A STANDARD 2001
KEYBOARD FOR INPUT, AND A STANDARD 2001
^CRT^ FOR OUTPUT.
^I/O^ FOR THE OPERATOR WILL BE A FULL FUNCTION ^RS^232^C^
KEYBOARD FOR INPUT, WITH A STANDARD 2001
^CRT^ FOR OUTPUT.
@DATA WILL BE ENTERED BY THE EMPLOYEE THRU THE REMOTE
DEVICE AND ACKNOWLEDGED BY THE REMOTE DEVICE ^CRT^ FOR
ACCEPTANCE BY THE EMPLOYEE.
@WHEN PROPERLY ACKNOWLEDGED, THE DATA WILL BE RECORDED
ON A STANDARD 40 COLUMN 2001 (^LRC^) PRINTER FOR PERMANENT
HARD COPY OF THE TRANSACTION AND TO DISK FOR FURTHER
PROCESSING TO BE PRINTED ON A STANDARD 80/132 COLUMN
^C^ENTRONICS COMPATIBLE PRINTER.
.SP2
.SI5
@TO ACCOMPLISH THIS THERE WILL BE SEVERAL "TASKS" RUNNING
CONCURRENTLY.
@THESE ARE:
.SP1
.IN10
 1. REAL TIME CLOCK FOR TIME KEEPING
 2. DATA LOGGING TO DISK
 3. DATA LOGGING TO ^LRC^ PRINTER
 4. DATA COLLECTION FROM THE REMOTE DEVICE
.SP2
.IN0
.SI5
@WHEN THE USER IS PRINTING FORMATTED REPORTS THE SYSTEM
WILL NOT BE USED TO PERFORM THE TIME KEEPING FUNCTION.
@THAT IS, THE REPORT GENERATION AND FILE MAINTENANCE
WILL BE DONE "OFF LINE".
