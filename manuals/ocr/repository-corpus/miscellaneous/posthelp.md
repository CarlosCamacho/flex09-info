OVERVIEW
	--------

	The	Mail	command	is	the	nucleus	of	the	Intercom (Inter-
Terminal	Communication)	system.	It is invoked by typing 'MAIL' at
the system command level (> level).	With this mail system, one user
can direct	a text message to another user or to the general public.
The recipient can read (or ignore) the message at their leisure.

	Mail	is divided into two sub-systems:	Private mail and Public
mail.	Private	mail	is	used	to	send	a message from one user to
another	user or group of users.	This message is private in that it
is seen	only by those you send it to.	In conrast, a public message
is posted for all to see.	It is directed at the general public, not
sent to	a	particular	user.	Public	messages	are	grouped	into
categories.	Each	category	is	associated	with a single-word name
that	identifies	the	type	of	entry	that	belongs	there	(eg.
ANTIQUES).

	When	reading	messages, whether public or private, the user is
shown	the	header	and	then	asked	if	he	wants	to see the text
(remainder).	The	header consists of two lines of information about
the forthcoming message.	The first identifies who sent this message
and when.	The second tells you the subject line.	This subject line
is entered	by	the	sender	and	should explain what the message is
about.	After	the	user has seen, or decided not to see the text of
this message,	the	header	of	the	next is displayed and the cycle
continues.
