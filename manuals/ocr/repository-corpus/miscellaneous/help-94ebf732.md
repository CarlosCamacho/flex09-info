POINT FDB 0 POINTER TO INPUT LINE BUFFER
MATCH FCB 1 LINE MATCH FLAG FOR ALL COMMANDS
MATCH1 FCB 0 MATCH FLAG FOR SPECIFIC COMMANDS

ENDPT FDB 0 END OF LINE POINTER TO INBUF
STP FDB 0
FOUND FCB 0 FLAG IF HELP FOUND IS >0

 CLRB SET COUNTER TO 0
HELP1 JSR NXTCH GET CHARACTER FROM THE COMMAND LINE

GOTIT STX ENDPT SAVE END POINTER

GOTIT2 CLR MATCH SET '$' FLAG OFF '0'

GOTIT3 LDX #FCB POINT TO FCB

*
* ERROR HANDLER
*

ERROR3 LDAA 1,X GET ERROR NUMBER
 CMPA #8 IS IT EOF?
 BEQ HELP32
 CMPA #4 IS HELPFILE.TXT THERE ?
 BEQ HELP33
ERROR LDAA 1,X GET ERROR TYPE
 JSR RPTERR REPORT ERROR
FLEX JSR FMSCLS CLOSE ALL
 JMP WARMS RETURN TO FLEX

HELP32 JSRPCRLF PRINT CR & LF
 LDAA FOUND SEE IF WE COULD HELP
 CMPA #$0 IF >0 THEN YES
 BNE HELP35
 LDX #SORRY PRINT SORRY MESSAGE
 JSR PDATA
 LDX #INBUF PRINT WHAT WE LOOKED FOR
 JSR PDATA
 JSR PCRLF
 LDX #SORRY1 TELL HIM WE COULDN'T HELP
 JSR PSTRNG
 JSR PCRLF PRINT CR & LF
HELP35 BRA FLEX CLOSE FILE,GOTO FLEX

HELP33 LDX #NOT PRINT CAN'T FIND HELPFILE.TXT
 JSR PSTRNG ON SYSTEM DISK
 BRA FLEX

HELP3 LDX #LINEBF POINT TO LINE FROM HELPFILE
 LDAA 0,X GET FIRST CHARACTER IN LINE FOR TESTING
 CMPA #$20 IS IT A SPACE
 BEQ SPACE
 TST MATCH SEE IF WE WANT TO TEST FOR '$'

*
* GET A YES,NO OR STOP ANSWER
*
YESNO JSR PCRLF
 JSR PCRLF
 JSR TESTLN SEE WHOSE PROMPT TO USE
 BEQ YESNO1 IF A=0 THEN USE HELPFILE'S PROMPT
 LDX #YORN ASK FOR Y OR N CONTINUE
 JSR PDATA
YESNO1 JSR GETCHR GET ANSWER
 ANDA #$5F MAKE UPPERCASE
 PSHA
 JSR PCRLF
 PULA
 CMPA #'S FOR STOP
 BEQ FLEXA

 BEQ DONE3 IF N SET FLAG AND TRY FOR MORE
 CLR MATCH SET PRINT FLAG TO NO PRINT
DONE3 BRA HELP65 CONTINUE

* HANDLE BACKSPACE CHARACTER
*

BACK CMPB #0

* PRINT A STRING WITHOUT A CRLF

PDATA LDAA 0,X

DONE RTS

*
* TEST LINE TO SEE IT MORE THAN 1 LETTER COMMAND
* AND IF SO PRINT LINE INSTEAD OF INTERNAL PROMPT
* X=HELPFILE LINE A=0 IF HELPFILES LINE IS USED
*

TESTLN LDAA 1,X POINT TO FIRST CHAR
 INX BUMP POINTER
 CMPA #$20 SKIP LEADING SPACES
 BEQ TESTLN
 CMPA #$D SEE IF NO PROMPT
 BEQ USEOUR USE INTERNAL PROMPT
 CMPA #'* SEE IF COMMENT
 BEQ USEOUR
* BY NOW ITS A VALID LINE WITH SOMETHING IN IT.
PDATA1 LDAA 0,X GET HELPFILE CHAR
 CMPA #'* TEST FOR COMMENT
 BEQ DONE1
 CMPA #$D SEE IF END
 BEQ DONE1
 JSR PUTCHR PRINT IT
 INX BUMP POINTER
 BRA PDATA1 REPEAT TILL DONE

DONE1 LDAA #$20 PRINT A SPACE AFTER THE LINE
 JSR PUTCHR
 CLRA CLEAR FLAG FOR THEIR PROMPT
 RTS

USEOUR LDAA #1 SET FLAG FOR INTERNAL PROMPT
 RTS
