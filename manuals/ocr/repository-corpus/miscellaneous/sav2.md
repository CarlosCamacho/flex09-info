# SAV2

> Source: `misc/uncategorized/tsc - Bootable FLEX System and Utilities.zip!tsc/Tsc_util_2.dsk!SAV2.DOC`  
> Method: FLEX disk extraction

OCR and media-decoding errors may remain.

SAV2 is a command to save discontiguous blocks of memory.
The command is SAV2 filename.
You are then prompted for each block to be saved -
enter B ssss eeee<cr> for each. To end the process,
use T tttt (for transfer address) or just T<cr>.
