TTL EDCDOC

*
* THIS IS THE NEW IMPROVED VERSION OF THE
* SUPER EDC PROGRAM THAT WILL ALSO SUPPORT
* THE READING AND WRITING OF "COGAR 1500"
* TAPES. THE COMMANDS ARE AS FOLLOWS:
*
*	$01 GET LAST STATUS AND CLEAR
*	$11 READ 2805 FORMAT
*	$21 SKIP A FILE
*	$31 REWIND TAPE
*	$41 SKIP A RECORD (2805 FORMAT)
*	$51 WRITE 2805 FORMAT
*	$61 WRITE EOF (2805 FORMAT)
*	$7F RESET EDC
*
*	$71 NEXT COMMAND IS 1500 FORMAT
*	(THIS PUTS EDC IN 1500 MODE
*	FOR ONE COMMAND).
*
* THE 2805 FORMAT CONSISTS OF A PREAMBLE,
*	AN STX, A BYTE COUNT, VARIABLE LENGTH
*	DATA FEILD, A CRC, AND A POSTAMBLE.
*
* THERE ARE TWO TYPES OF 1500 FORMATS. THE
*	FIRST IS USED AS A BOOT TYPE RECORD, AND
*	THE SECOND IS A NORMAL RECORD TYPE. THEY
*	ARE FORMATTED AS FOLLOWS: THE BOOT TYPE
*	CONSISTS OF A PREAMBLE, DATA, AND A POST-
*	AMBLE, WHILE THE SECOND TYPE CONSISTS OF
*	A PREAMBLE, HEADER (8 BYTES), DATA (128
*	BYTES), A CRC (2 BYTES), AND A POSTAMBLE.
*
*	IN BOTH CASES OF THE 1500 THE PREAMBLE AND
*	POSTAMBLE ARE 3 BYTES EACH. THE DATA FEILD
*	IS ALWAYS 128 BYTES. THE PREAMBLE IS 23 "0"
*	BITS FOLLOWED BY A "1" BIT, AND THE POST-
*	AMBLE IS ONE "1" BIT FOLLOWED BY 23 "0"
*	BITS.
*
