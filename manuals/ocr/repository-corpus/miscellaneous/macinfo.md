====	MAC	====

A HIGH LEVEL LANGUAGE WITH AN INTERPRETER FOR MC 6809
DEVELOPED BY CAD-TEK DATATEKNIK, JARFALLA, SWEDEN.

INTERPRETER CHARACTERISTICS:
	RESIDES IN LOWER RAM (APPR. 6KBYTE)
	LOADS PROGRAM FROM TEXT FILE (COMMEMTS AND MULTIPLE
	SPACES ARE NOT LOADED)
	DYNAMIC MEMORY ALLOCATION FOR VARIABLES IN SUBROUTINES
	AND FUNCTIONS (SPACE USED BY VARIABLES FREED AT EXIT
	FROM SUBROUTINE OR FUNCTION).
	WORKS WITH FLEX V 9 FROM TSC

LANGUAGE CHARACTERISICS:

	- VARIABLES : INTEGERS
	MULTIDIMENSIONAL INTEGER ARRAYS
	STRINGS
	MULTIDIMENSIONAL STRING ARRAYS
	- IDENTIFIERS FOR VARIABLES : SINGLE LETTERS A..Z
	- INTEGER ARITHMETIC, POSTFIX NOTATION
	- RECURSIVE SUBROUTINES WITH LOCAL VARIABLES
	- RECURSIVE FUNCTION CALLS WITH LOCAL VARIABLES
	- PARAMETERS IN SUBROUTINE CALL MAY BE CONSTANTS,VARIABLES,

VARIABLE NAMES,ARRAY NAMES ETC.
	- COMPLETELY STRUCTURED - NO GOTO-STATEMENTS
	- CONSTRUCTS (MULTILEVEL):
	IF - THEN - ELSE
	WHILE - DO
	REPEAT	- UNTIL
	CASE
	FOR - TO - STEP - DO
	BEGIN - END
	- COMMEMTS MAY BE INSERTED FREELY
	- BUILT-IN FUNCTIONS AND PROCEDURES:
	RANDOM GENERATOR
	'SIGN' FUNCTION
	TRACE FACILITY
	ERROR DIAGNOSTICS
	'PEEK' AND 'POKE'
	HEXADECIMAL TO DECIMAL CONVERSION AND VICE VERSA
	CONVERSION TO ABSOLUTE VALUE
	SINGLE CHARACTER (AS WELL AS STRING) INPUT
	PRESETTABLE STRING LENGTH
	STRING CONCATENATE AND EXTRACT
	STRING COMPARE
	OBTAINING STRING LENGTH
	OBTAINING 'VALUE' OF SINGLE ASCII CHARACTER
	CONVERSION FROM INTEGER VALUE TO ASCII CHARACTER

	SHORT FORM DESCRIPTION OF THE 'MAC' LANGUAGE:

	REFERENCING A CONSTANT, A VARIABLE OR THE ADDRESS OF A
	VARIABLE MEANS PUTTING THE CONSTANT, THE VALUE OR THE ADDRESS
	OF A VARIABLE ON THE STACK. OPERATORS REMOVE ONE OR MORE
	ITEMS FROM THE STACK. FUNCTIONS AND SOME OPERATORS LEAVE
	A VALUE ON STACK.
	THERE EXISTS A (GLOBAL) STRING BUFFER. SOME OPERATIONS
	PUT A STRING IN THIS BUFFER (OR RATHER APPEND TO AN ALREADY
	EXISTING STRING IN THE BUFFER). OTHER OPERATIONS CLEAR THE
	BUFFER. THIS BUFFER IS NOT CHANGED WHEN THE SUBROUTINE LEVEL
	IS CHANGED (ENTERING OR EXITING A SUBROUTINE OR A FUNCTION).


	INTEGER VARIABLES

	A B C	..	Z = ADDRESSES OF VARIABLES
	A. B. C.	..	Z. = VALUES OF VARIABLES

	INTEGER ARRAYS
	ARRAYS HAVE TO BE DIMENSIONED BEFORE USE:
	ARRAY NAME (A...Z) + DIM 1 + DIM 2 + ... +DIM N + N + \\
	N = NUMBER OF DIMENSIONS (<=255)
	INDEX = 0 .. 32767	(NOTE: INDEX 0 IS PERMITTED)

	EXAMPLE
	A 2 4 6 3 \\	= DEFINE	ARRAY A(2,4,6)
	1 3 5 A ^	= ADDRESS OF A(1,3,5)
	1 3 5 A ^. = VALUE OF A(1,3,5)

	STRING VARIABLES

	A' B' C'	..	Z'	= ADDRESSES OF STRING VARIABLES
	A'. B'. C'.	..	Z'.	= STRINGS
	

	STRING ARRAYS
	THE RULES FOR DIMENSIONING AND INDEX RANGE APPLY TO
	STRING ARRAYS AS FOR INTEGER ARRAYS.

	A 4 2 6 3 \'	= DEFINE STRING ARRAY A'(4,2,6)
	2 1 5 A' ^ = ADDRESS OF STRING VARIABLE A'(2,1,5)
	2 1 5 A' ^. = STRING	A'(2,1,5)

	STRING CONSTANT
	A STRING CONSTANT IS A SEQUENCE OF PRINTING CHARACTERS,
	INCLUDING SPACE, ENCLOSED IN DOUBLE QUOTATION MARKS:

	"THIS IS A STRING"	(IMPLIED PRINT COMMAND IF NOT ASSIGNED

TO A STRING VARIABLE)
	(EXCLAMATION MARK ! INSIDE THE " .. " MEANS NEW LINE)

	ASSIGNMENTS

	X 25 =	:	X=25	(ASSIGN 25 TO X)
	X B. =	:	X=B	(ASSIGN B. TO X)
	Y A =	:	ASSIGN ADDRESS OF A TO Y
	A'"ABCD"=	:	SET STRING VARIABLE A' = ABCD
	B' A'. =	:	SET STRING VARIABLE B' = STRING A'

	OPERATORS

	THE FOLLOWING DEFINITION IS USED FOR SHORTNESS SAKE:
	CASE N : TOP OF STACK IS ANYTHING BUT THE ADDRESS OF
	A STRING VARIABLE (INCL. STRING ARRAYS)
	CASE SA : TOP OF STACK IS THE ADDRESS OF A STRING
	VARIABLE (INCL. STRING ARRAYS)

	=	CASE N:

ASSIGN VALUE ON TOP OF STACK TO VARIABLE

WITH THE ADDRESS SECOND FROM TOP OF STACK
	=	CASE SA:

ASSIGN STRING IN BUFFER TO THE STRING VARIABLE

WITH THE ADDRESS GIVEN BY THE TOPMOST VALUE ON STACK

(CLEAR BUFFER)
	.	CASE N:

REPLACE ADDRESS OF VARIABLE ON TOP OF STACK WITH

THE VALUE OF THE VARIABLE
	.	CASE SA:

PUT THE STRING, WITH THE ADDRESS GIVEN BY

THE STACK TOP VALUE, IN THE (STRING) BUFFER

(APPEND TO PREVIOUS CONTENT IN BUFFER, IF ANY)

(BUFFER SIZE = 128 CHAR )
	+ - * /	: REPLACE THE TWO ITEMS ON TOP OF STACK WITH THE

RESULT OF THE OPERATION
	"	...	"	CASE N:

PRINT THE STRING BETWEEN THE QUOTATION MARKS
	"	...	"	CASE SA:

APPEND THE STRING BETWEEN THE QUOTATION MARKS TO THE

STRING IN THE BUFFER
	!	(IF BUFFER CLEARED) PRINT THE VALUE ON TOP OF THE STACK
	!	(IF BUFFER NOT EMPTY) PRINT BUFFER (CLEAR BUFFER)
	?	CASE N:

INPUT A DECIMAL VALUE AND PUT ON STACK
	?	CASE SA:

INPUT A STRING (ENDED BY CR) AND APPEND TO BUFFER

	\-FUNCTIONS AND OPERATORS
	\* ......... *\	= COMMENT	(MAY BE SEVERAL LINES)
	\?	= INPUT A SINGLE CHARACTER AND APPEND TO BUFFER
	\=	= STRING COMPARISON: ITEM ON TOP OF STACK IS THE ADDRESS
	OF A STRING (S1), COMPARE THIS STRING WITH STRING (S2)
	IN BUFFER (BUFFER CLEARED). PUT A VALUE ON STACK:
	1 IF THE STRINGS ARE EQUAL, 0 IF S1 > S2,
	-1 IF S1 < S2. ('<' AND '>' HAVE THERE NORMAL
	MEANING FOR STRING COMPARISON)
	TRAILING SPACES,IF ANY, ARE IGNORED.
	\:	REPLACE VALUE ON TOP OF STACK WITH A RANDOM VALUE

BETWEEN 0 AND THAT VALUE
	\A	= REPLACE VALUE ON TOP OF STACK WITH THE ABSOLUTE VALUE
	\C	= GET 7 L.S. BITS OF VALUE ON STACK, CONVERT TO ASCII
	CHARACTER, APPEND TO STRING IN BUFFER
	\D	= CONVERT HEX VALUE IN STRING BUFFER TO DECIMAL AND

PUT ON STACK (CLEAR BUFFER)
	\E	= EXIT TO FLEX
	\H	= CONVERT THE VALUE ON STACK TO HEXADECIMAL STRING

AND PUT IN STRING BUFFER
	\N	= PUT LENGTH OF STRING IN BUFFER ON STACK (CLEAR BUFFER)
	\L	= TRUNCATE STRING IN STRING BUFFER TO THE NUMBER OF

CHARACTERS DEFINED BY THE VALUE ON STACK
	\M	= REPLACE MEMORY ADDRESS ON STACK WITH MEMORY BYTE

(AS THE 8 L.S. BITS)
	\P	= PUT BYTE DEFINED BY L.S. 8 BITS OF THE VALUE ON TOP

OF THE STACK IN THE MEMORY CELL DEFINED BY THE

ADDRESS GIVEN BY THE SECOND ITEM ON STACK
	\R	= USE VALUE ON TOP OF STACK AS SEED FOR RANDOM

GENERATOR
	\S	= SET MAX. STRING LENGTH EQUAL TO VALUE ON TOP OF STACK

(DEFAULT STRING LENGTH IS 32, LENGTH MUST BE SET

BEFORE ANY STRING IS REFERENCED)

(L.T. 256)
	\T	= FLIP TRACE SWITCH (ON/OFF)
	\V	= THE FIRST CHARACTER OF THE STRING IN THE BUFFER IS
	CONVERTED TO THE CORRESPONDING DECIMAL VALUE
	(ASCII VALUE) AND PUT ON STACK. (BUFFER CLEARED)

	CONDITIONAL STATEMENT

	E [ C ]	IF E>0 THEN PERFORM C, ELSE NO ACTION

	LOOP

	(C1	E1\^	C2	E2\^	.. )	PERFORM C1 C2 ETC UNTIL A VALUE E <= 0
		IS ENCOUNTERED. IF A VALUE E1 OR E2 ETC <= 0 IS ENCOUNTERED
		THEN EXIT AT THAT INSTANT FROM THE LOOP AND PROCEED AFTER
		THE ENDING ')'.

	CASE

	E < C1, C2, C3,	... >	IF E <= 0 NO ACTION

IF E = M > 0	SELECT CASE M	(IF M IS OUTSIDE RANGE

THEN NO ACTION)

NOTE : COMMAS ARE THE CASE SEPARATORS. HOWEVER, C1, C2

ETC. MAY BE (OR CONTAIN) MACRO CALLS AND ALSO OTHER

CASE CONSTRUCTS EVEN THOUGH THESE CONTAIN COMMAS THEM-

SELVES.

	SUBROUTINES AND FUNCTIONS	(MACROS)

	SUBROUTINE AND FUNCTION NAMES :	A ... Z
	MACRO CALL:	#M, PAR1, PAR2, ....	;
	PARAMETERS MAY BE CONSTANTS (NUMERIC,STRING), VARIABLES
	(NUMERIC OR STRING), ARRAY NAMES, VARIABLE ADDRESSES
	OR OTHER MACRO CALLS. EXPRESSIONS AND EVEN PROGRAM
	STATEMENTS ARE ALLOWED AS LONG AS THEY DO NOT CONTAIN
	COMMAS (,). (COMMAS ARE PARAMETER SEPARATORS)
	MACROS MAY CALL THEMSELVES (RECURSIVE CALLS)
	MACROS ARE DEFINED AFTER THE MAIN PROGRAM.
	THE FIRST MACRO DEFINITION IMPLIES THE END OF THE MAIN
	PROGRAM.
	MACRO DEFINITIONS:
	$ + MACRO NAME + MACRO BODY + @
	PARAMETERS ARE REFERENCED IN THE ORDER THEY APPEAR IN
	THE MACRO CALL : %A	%B	%C	ETC
		EXAMPLE:	$A %C %A %B-= @
		A CALL TO THIS SUBROUTINE COULD BE:	#A,10,7,X;

THE RESULT WOULD BE THAT X IS ASSIGNED THE VALUE 3

(X=10-7)
		THE @-SIGN, WHICH MEANS EXIT FROM THE MACRO, MAY BE

USED ANY NUMBER OF TIMES IN A MACRO DEFINITION.

A FUNCTION LEAVES A VALUE ON STACK.

EXAMPLE:	$A %A %B- @

CORRESPONDING FUNCTION CALL, E.G. #A,10,7; ,

GENERATES THE VALUE 3 (10-7) ON TOP OF STACK.
		NOTE THAT THE %-SIGN IMPLIES A DIRECT REPLACEMENT
		OF THE DUMMY PARAMETER A, B, ETC WITH EVERYTHING
		BETWEEN THE ENCLOSING COMMAS FOR THE FIRST, THE
		SECOND ETC PARAMETER IN THE MACRO CALL.


		PROGRAM STRUCTURE:

		FIRST: MAIN PROGRAM
		THEN:	MACRO DEFINITIONS
		END WITH: $$

		NOTE:
		A, INTEGER ARRAY A, A', STRING ARRAY A' AND MACRO A
		ARE CONSIDERED AS DIFFERENT IDENTIFIERS BY THE
		MAC INTERPRETER. THE SAME RULE APPLIES TO ALL
		IDENTIFIERS A...Z.
		ALL IDENTIFIERS ARE LOCAL TO THEIR RESPECTIVE
		MACRO (AND TO THE MAIN PROGRAM).


		NESTING:

		CONDITIONAL STATEMENTS, LOOPS AND CASE CONSTRUCTS
		AS WELL AS SUBROUTINES AND FUNCTION CALLS MAY BE
		NESTED.

		TO RUN A PROGRAM (IN THE 'FLEX' ENVIRONMENT):

		TYPE:	MAC PROGR
		MAC.CMD IS THE INTERPRETER, PROGR IS THE FILE NAME OF
		PROGRAM TO BE RUN (DEFAULT EXTENSION IS .TXT).
		TO GENERATE OUTPUT ON LINE PRINTER OR ON FILE:
		USE THE FLEX COMMANDS 'P' AND 'O'.
