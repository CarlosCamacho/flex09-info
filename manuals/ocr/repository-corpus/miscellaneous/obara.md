OBARA	is	a line by line dis-assembler for the 6809.	It is

very	fast,	and	I	use it almost as first choice when I need to

know	what is in memory.	It can't distinguish between real code,

data	and	text,	so	you	need	to	use	it	with	reasonable

intelligence.	It was published in the Japanese magazine I/O, and

has been adapted to run under Flex.
