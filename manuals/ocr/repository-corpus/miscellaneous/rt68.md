*
* THIS IS A TASK DRIVEN OPERATING SYSTEM FOR
* THE 6800 MICROPROCESSOR
*
* THE TASK CONTROL BLOCK FORMAT IS DEFINED
* AS FOLLOWS:
*
* ADDRESS $00FA = SYSTEM STACK POINTER
*		$00FC = CURRENT TCB POINTER
*		$00FE = TCB VALIDATION BYTE ($AA)
*		$00FF = NUMBER OF ENTRIES IN TABLE
*
* ADDRESS $0100 = FIRST BYTE OF FIRST TASK IN TABLE
*
*	TCB FORMAT
*
*	BYTE 0	= TASK I.D.
*	BYTE 1-2	= TASK INITIALIZATION ADDRESS
*	BYTE 3-4	= TASK SCHEDULE ADDRESS
*	BYTE 5-6	= ADDRESS OF TASK SUSPEND SEMAPHORE
*	BYTE 7-8	= TASK STACK POINTER
*	BYTE 9-F	= RESERVED FOR FUTURE ENHANCEMENT
*
