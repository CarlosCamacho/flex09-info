	XARC.COM COMMAND LINE SYNTAX

XARC.COM is called from the SK*DOS prompt as follows:

	SK*DOS:xarc [-l-c-o-k] filename.ext


The command line options can be grouped together on the same line and
perform the following functions:

	-l	list archive directory only
	-c	make filename case sensitive
	-o	extract from archive only the filename

which follows
	
	-k	kill existing destination file


	PROGRAM MESSAGES

During the file extracting process XARC.COM will display various
messages informing the user of such things as actual program size,
stored size, storage method, file date, etc.	Also, self-explanatory
messages may appear during program execution such as whether XARC failed
or passed in extracting a particular file or if an existing destination
filename exists.
