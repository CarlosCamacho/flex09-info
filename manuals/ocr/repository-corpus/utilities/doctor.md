TTL DOCTOR - DISK FIXER
 OPT PAG
 PAG
*
* THIS PROGRAM WILL COPY A DISK SECTOR
* FOR SECTOR WITHOUT REGARD FOR ERRORS.
* READ ERRORS WILL BE REPORTED.
*
BUFFER EQU $0100
WARMS EQU $AD03
GETCHR EQU $AD15
PUTCHR EQU $AD18
INBUFF EQU $AD1B
PSTRNG EQU $AD1E
PCRLF EQU $AD24
OUTHEX EQU $AD3C
INDEC EQU $AD48
READ EQU $BE80
WRITE EQU $BE83
VERIFY EQU $BE86
SELECT EQU $BE8C
*
 ORG $A100
*
START BRA BEGIN
VERS FCB 1
*
ERRCNT FCB 00
XTEMP FDB 0000
TRKPTR FCB 00
SCTPTR FCB 00
MAXTRK FCB 00
MAXSCT FCB 00
FCB FCB $00
 FCB $00
 FCB $00
DRVSAV FCB $00
*
BEGIN LDX #MSG1
 LDAA #$00
 STAA TRKPTR
 STAA SCTPTR
 JSR PSTRNG
 JSR INBUFF
 JSR INDEC GET NUMBER OF TRACKS
 STX XTEMP
 LDAA XTEMP+1
 STAA MAXTRK
 LDX #SIDMSG
 JSR PSTRNG
 JSR INBUFF
 JSR INDEC
 STX XTEMP
 LDAA XTEMP+1
 DECA
 BEQ SSIDED
 LDAA #21
 STAA MAXSCT
 BRA SS1
SSIDED LDAA #11
 STAA MAXSCT
*
B1 LDX #MSG2
 JSR PSTRNG
 JSR GETCHR
 CMPA #'Y
 BNE B1
*
* ALL SET UP SO DO IT
*
SS1 LDX #FCB
 LDAA #$00
 STAA DRVSAV
 JSR SELECT
 LDX #BUFFER
 LDAA TRKPTR
 LDAB SCTPTR
 CLR ERRCNT
*
 JSR READ READ THE SECTOR
 BEQ SS2
 LDX TRKPTR
 CPX #$0001
 BEQ SS3
 JSR ERROR
SS2 LDX #FCB
 LDAA #$01
 STAA DRVSAV
 JSR SELECT
 LDX #BUFFER
 LDAA TRKPTR
 LDAB SCTPTR
 JSR WRITE
 JSR VERIFY
 BEQ SS3
 LDAA ERRCNT
 INCA
 STAA ERRCNT
 CMPA #4
 BNE SS2
 JMP ABORT
*
*
* POINT TO NEXT SECTOR
*
SS3 LDAA SCTPTR
 INCA
 STAA SCTPTR
 CMPA MAXSCT
 BNE SS1
*
 LDAA #1
 STAA SCTPTR
 LDAA TRKPTR
 INCA
 STAA TRKPTR
 CMPA MAXTRK
 BNE SS1
*
* ALL DONE
*
 LDX #DNEMSG
 JSR PSTRNG
 JMP WARMS
*
* ERROR REPORTER
*
ERROR LDX #ERRMSG
 JSR PSTRNG
 LDX #TRKPTR
 JSR OUTHEX
 LDX #SECTOR
 JSR PDATA1
 LDX #SCTPTR
 JSR OUTHEX
 RTS
*
* PRINT STRING WITHOUT PCRLF
*
PDATA1 LDAA 0,X
 CMPA #4
 BEQ PEXIT
 JSR PUTCHR
 INX
 BRA PDATA1
PEXIT RTS
*
DELAY BSR DLY1
DLY1 BSR RTS
RTS RTS
*
ABORT LDX #ABRTMS
 JSR PSTRNG
 JMP WARMS
*

 FCC /PLACE SOUCRE IN DRIVE 0/
 FCC / AND DESTINATION IN DRIVE 1.
 FCB $D,$A
 FCC /	ENTER PASSWORD : /
 FCB 4
*
SIDMSG FCC /HOW MANY SIDES	: /
 FCB 4
*

 FCB 4
*
SECTOR FCC /	SECTOR : /
 FCB 4
*
DNEMSG FCB $D,$A
 FCC /DONE/
 FCB 4
*
