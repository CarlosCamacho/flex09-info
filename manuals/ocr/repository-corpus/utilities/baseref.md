	BASREF - A BASIC Cross Reference Program

	This program is designed to provide the BASIC user with additional inforqmation, besides the listing of the program, to write or make changes to his files.	The output of the program lists each line number in the BASIC program and each line number that referenced that line, possibly with a GOTO or GOSUB instruction.	Additionally, all variables are printed, along with the line number that referenced them.

	To use the BASEREF, simply type BASEREF <DRV. NU.><FILENAME> or
P BASEREF <DRV.NU.><FILENAME> for a hard-copy printout.	.BAS is assumed.
