 TTL DOCTOR
 OPT PAG
 PAG
*
* THE PURPOSE OF THIS PROGRAM IS TO
* HELP REBUILD A BLOWN DIRECTORY.
*
PDATA1 EQU $E07E
FCBLK EQU $A840
READ	EQU $BE80
SELECT EQU $BE8C
WARMS EQU $AD03
PSTRNG EQU $AD1E
PCRLF EQU $AD24
OUTADR EQU $AD45
OUTHEX EQU $AD3C
PUTCHR EQU $AD18
GETCHR EQU $AD15
*
 ORG $A100
*
START BRA BEGIN
VERS	FCB 1
*
CURTRK RMB 1 CURRENT TRACK
CURSCT RMB 1 CURRENT SECTOR
CFCTRK RMB 1 CURRENT FILE CURRENT TRACK
CFCSCT RMB 1 CURRENT FILE CURRENT SECTOR
CFSIZE RMB 1 CURRENT FILE SIZE
CFFTRK RMB 1 CURRENT FILE FIRST TRK
CFFSCT RMB 1 CURRENT FILE FIRST SECTOR
FFREET RMB 1 FIRST FREE TRACK
FFREES RMB 1 FIRST FREE SECTOR
LFREET RMB 1 LAST FREE TRACK
LFREES RMB 1 LAST FREE SECTOR
PASS RMB 1
MAXSCT RMB 1
MAXTRK RMB 1
FLAG1 RMB 1
FLAG2 RMB 1
*
BEGIN CLR PASS
 LDX #SIDMSG
 JSR PDATA1
 JSR GETCHR
 CMPA #'S
 BEQ SINGLE
 CMPA #'D
 BNE BEGIN
DOUBLE LDAA #21
 STAA MAXSCT
 BRA GETTRK
SINGLE LDAA #11
 STAA MAXSCT
GETTRK LDX #TRKMSG
 JSR PDATA1
 JSR BYTE
 STAA MAXTRK
*
GF1 LDX #DMPMSG
 JSR PDATA1
 JSR GETCHR
 CMPA #'Y
 BEQ SF1
 CMPA #'N
 BNE GF1
 CLR FLAG1
 BRA GF2
SF1 LDAA #1
 STAA FLAG1
GF2 LDX #S1MSG
 JSR PDATA1
 JSR GETCHR
 CMPA #'Y
 BEQ SF2
 CMPA #'N
 BNE GF2
 CLR FLAG2
 BRA LOOP
SF2 LDAA #1
 STAA FLAG2
*
LOOP LDAA #1
 LDX #CURTRK
CLRLP STAA 0,X
 INX
 CPX #PASS
 BNE CLRLP
*
 LDX #STRMSG
 JSR PDATA1
 JSR GETCHR
*
 LDX #FCBLK
 LDAA #1
 STAA 3,X
 JSR SELECT
LOOK LDX #FCBLK+64
 LDAA CURTRK
 LDAB CURSCT
 JSR READ
 TST PASS
 BNE DUMP
*
* NOW LOOK FOR FIRST FREE SECTOR
*
 LDX #FCBLK+64
 LDX 2,X
 BNE CHKNXT NOT A FREEBEE
 LDX #FFSMSG
 JSR PSTRNG
 LDX #CURTRK
 JSR OUTHEX
 INX
 LDAA #$20
 JSR PUTCHR
 JSR OUTHEX
 JSR PCRLF
 LDAA #1
 STAA PASS
 BRA LOOP
CHKNXT LDAA CURSCT
 INCA
 STAA CURSCT
 CMPA MAXSCT
 BNE LOOK
 LDAA #1
 STAA CURSCT
 LDAA CURTRK
 INCA
 STAA CURTRK
 CMPA MAXTRK
 BNE LOOK
 TST PASS
 BEQ PFULL
 JMP WARMS
*
* DISK SIZE EXCEEDED....
*
PFULL LDX #FULMSG
 JSR PSTRNG
 JSR PCRLF
 LDAA #1
 STAA PASS
*
 JMP LOOP
*
DUMP TST FLAG1 DUMP LINKS?
 BNE DODUMP YES
 TST FLAG2 DUMP SEQ #1?
 BEQ NODUMP NO
 LDX FCBLK+66 GET SEQ #
 DEX . IS IT SEQ #1
 BNE NODUMP NO
DODUMP LDX #CURTRK
 JSR OUTHEX
 LDAA #$20
 JSR PUTCHR
 INX
 JSR OUTHEX
 LDX #LMSG
 JSR PDATA
 LDX #FCBLK+64
 JSR OUTHEX
 LDAA #$20
 JSR PUTCHR
 INX
 JSR OUTHEX
 LDX #SEQMSG
 JSR PDATA
 LDX #FCBLK+66
 JSR OUTADR
 JSR PCRLF
NODUMP BRA CHKNXT
*
PDATA LDAA 0,X
 CMPA #4
 BEQ PEXIT
 JSR PUTCHR
 INX
 BRA PDATA
PEXIT RTS
*
BYTE BSR INHEX
BYTE1 ASLA
 ASLA
 ASLA
 ASLA
 TAB
 BSR INHEX
 ABA
 RTS
*
INHEX JSR GETCHR
INHEX1 SUBA #$30
 BMI C3
 CMPA #$9
 BLE IN1HG
 CMPA #$11
 BMI C3
 CMPA #$16
 BGT C3
 SUBA #$7
IN1HG RTS
C3 LDAA #$8
 JSR PUTCHR
 LDAA #$20
 JSR PUTCHR
 BRA INHEX

 FCC /THIS DISK IS FULL..../
 FCB 4
*

 FCC / THE FIRST FREE TRACK AND SECTOR IS	/
 FCB 4
*
SEQMSG FCC / SEQ # /
 FCB 4
*
LMSG FCC / LINKS TO /
 FCB 4
*
STRMSG FCB $D,$A
 FCC /INSERT DISK TO BE/
 FCC/ EXAMINED IN DRIVE # 1./
 FCB $D,$A
 FCC /HIT RETURN WHEN READY. /
 FCB $D,$A
 FCB 4
*

 FCC /SINGLE OR DOUBLE SIDED (S OR D)? /
 FCB 4
*
TRKMSG FCB $D,$A
 FCC /ENTER # OF TRACKS (HEX) - /
 FCB 4
*
DMPMSG FCB $D,$A
 FCC /DUMP ALL LINKS (Y OR N)? /
 FCB 4
*
S1MSG FCB $D,$A
 FCC /DUMP ALL SEQUENCE 1 LINKS (Y OR N)? /
 FCB 4

 END START
