CLONE	doesn't	do	very	much by itself - it opens one text

file	for	reading and another for writing, and transfer the text

one	character	at	a	time.	Its mostly used as the basis for a

number	of	other programs.	If you build in a filter between the

"read	a	character" and "write a character" routines, you can do

all	sorts	of	things	to text files. SPACE, STRIP and UNPAD are

examples.
